Oxidation and reduction

Loss of electrons: the oxidation number increases. The substance oxidised is the reductant (reducing agent).

Gain of electrons: the oxidation number decreases. The substance reduced is the oxidant (oxidising agent).

Memory aid: OIL RIG (Oxidation Is Loss, Reduction Is Gain). A conjugate redox pair is an oxidant and the reductant it becomes, e.g. \(\ce{Cu^2+/Cu}\) or \(\ce{MnO4-/Mn^2+}\).

RuleExample
Elements: 0\(\ce{Cu}, \ce{O2}, \ce{Cl2}\) are all 0

H is usually +1 (−1 in metal hydrides)H in \(\ce{NaH}\) is −1

Sum = 0 for a compound, = the charge for an ionMn in \(\ce{MnO4-}\): \(x + 4(-2) = -1 \Rightarrow x = +7\)

Find the oxidation number of (a) Cr in \(\ce{Cr2O7^2-}\), (b) S in \(\ce{S2O3^2-}\), (c) C in \(\ce{CH3OH}\).

(a) \(2x + 7(-2) = -2 \Rightarrow x = +6\). (b) \(2x + 3(-2) = -2 \Rightarrow x = +2\).

(c) \(x + 4(+1) + (-2) = 0 \Rightarrow x = -2\). +6, +2, −2. Carbon's oxidation number rises as it gains bonds to oxygen: \(\ce{CH3OH}\) (−2) → \(\ce{HCHO}\) (0) → \(\ce{HCOOH}\) (+2) → \(\ce{CO2}\) (+4). That's why converting an alcohol to an acid counts as oxidation.

Balancing half-equations in acid: KOHES

  1. Key element: balance the element that changes oxidation number.
  2. Oxygen: balance O by adding \(\ce{H2O}\).
  3. Hydrogen: balance H by adding \(\ce{H+}\).
  4. Electrons: balance charge by adding \(\ce{e-}\) to the more positive side.
  5. States: add them.

Balance \(\ce{MnO4- -> Mn^2+}\) in acidic solution.

K: one Mn each side. O: add 4 \(\ce{H2O}\) on the right. H: add 8 \(\ce{H+}\) on the left.

Charge: left \(= -1 + 8 = +7\); right \(= +2\). Add 5 \(\ce{e-}\) to the left.

\(\ce{MnO4-(aq) + 8H+(aq) + 5e- -> Mn^2+(aq) + 4H2O(l)}\). Check: Mn goes from +7 to +2, a gain of 5 electrons. ✓

Write the half-equation for the oxidation of ethanol to ethanoic acid in acidic solution.

\(\ce{C2H5OH -> CH3COOH}\): C already balanced. O: 1 on the left, 2 on the right, so add \(\ce{H2O}\) to the left.

H: left \(6 + 2 = 8\), right 4, so add 4 \(\ce{H+}\) to the right. Charge: left 0, right +4, so add 4 \(\ce{e-}\) to the right.

\(\ce{C2H5OH(aq) + H2O(l) -> CH3COOH(aq) + 4H+(aq) + 4e-}\). Electrons on the right: it's an oxidation.

Write the overall equation for the reaction of acidified permanganate with iron(II) ions.

Oxidation: \(\ce{Fe^2+ -> Fe^3+ + e-}\). Multiply by 5 so the electrons match the 5 gained by permanganate.

Add: \(\ce{MnO4- + 8H+ + 5e- + 5Fe^2+ -> Mn^2+ + 4H2O + 5Fe^3+ + 5e-}\), then cancel the electrons.

\(\ce{MnO4-(aq) + 8H+(aq) + 5Fe^2+(aq) -> Mn^2+(aq) + 5Fe^3+(aq) + 4H2O(l)}\). Mole ratio \(\ce{MnO4- : Fe^2+} = 1 : 5\). You'll need that for titrations.

Basic (alkaline) conditions

Balance as if in acid, then add the same number of \(\ce{OH-}\) to both sides as there are \(\ce{H+}\). Combine \(\ce{H+ + OH-}\) into \(\ce{H2O}\) and cancel waters.

Write the half-equation for the reduction of O₂ to OH⁻ in alkaline conditions (as in an alkaline fuel cell).

In acid: \(\ce{O2 + 4H+ + 4e- -> 2H2O}\). Add 4 \(\ce{OH-}\) to both sides: \(\ce{O2 + 4H2O + 4e- -> 2H2O + 4OH-}\).

Cancel 2 waters: \(\ce{O2(g) + 2H2O(l) + 4e- -> 4OH-(aq)}\). It appears exactly like this in the electrochemical series.

  • The oxidant is the thing reduced. Students swap these constantly.
  • Electrons must cancel in the overall equation; never leave \(\ce{e-}\) in an overall equation.
  • Spectator ions (\(\ce{K+}\), \(\ce{SO4^2-}\) in acidified permanganate) don't appear in the ionic equation.
  • Check charge as well as atoms; both sides must have the same total charge.

Practice

In \(\ce{Zn(s) + Cu^2+(aq) -> Zn^2+(aq) + Cu(s)}\), the oxidising agent is

  1. Zn
  2. Zn²⁺
  3. Cu²⁺
  4. Cu

Cu²⁺ gains electrons (is reduced), so it's the oxidising agent.

The oxidation number of N in \(\ce{NO3-}\) is

  1. +5
  2. +3
  3. −1
  4. +6

\(x + 3(-2) = -1 \Rightarrow x = +5\).

The balanced half-equation for \(\ce{Cr2O7^2- -> Cr^3+}\) in acid is

  1. \(\ce{Cr2O7^2- + 7H+ + 3e- -> 2Cr^3+ + 7H2O}\)
  2. \(\ce{Cr2O7^2- + 14H+ -> 2Cr^3+ + 7H2O + 6e-}\)
  3. \(\ce{Cr2O7^2- + 14H+ + 3e- -> Cr^3+ + 7H2O}\)
  4. \(\ce{Cr2O7^2- + 14H+ + 6e- -> 2Cr^3+ + 7H2O}\)

Charge: left \(-2 + 14 = +12\), right \(+6\), so 6 e⁻ on the left. Each Cr goes from +6 to +3 (3 e⁻ each, 6 total).

In \(\ce{2H2O2 -> 2H2O + O2}\), hydrogen peroxide is

  1. only oxidised
  2. both oxidised and reduced
  3. only reduced
  4. neither: it isn't a redox reaction

O is −1 in \(\ce{H2O2}\): some goes to −2 (in water: reduced) and some to 0 (in O₂: oxidised). This is called disproportionation.

How many electrons appear in the balanced half-equation for the oxidation of methanol to CO₂ in acid?

  1. 2
  2. 4
  3. 6
  4. 8

\(\ce{CH3OH + H2O -> CO2 + 6H+ + 6e-}\). C goes from −2 to +4: 6 electrons.

Which is not a redox reaction?

  1. \(\ce{AgNO3(aq) + NaCl(aq) -> AgCl(s) + NaNO3(aq)}\)
  2. \(\ce{Mg + 2HCl -> MgCl2 + H2}\)
  3. \(\ce{CH4 + 2O2 -> CO2 + 2H2O}\)
  4. \(\ce{2Na + Cl2 -> 2NaCl}\)

Precipitation: no oxidation numbers change (Ag +1, Cl −1 throughout).

Balance \(\ce{SO2 -> SO4^2-}\) in acidic solution and state whether SO₂ is oxidised or reduced.

\(\ce{SO2(g) + 2H2O(l) -> SO4^2-(aq) + 4H+(aq) + 2e-}\). S goes from +4 to +6: oxidised (SO₂ is the reductant).

Acidified dichromate oxidises ethanol to ethanoic acid. Write the two half-equations and the overall equation.

Reduction: \(\ce{Cr2O7^2- + 14H+ + 6e- -> 2Cr^3+ + 7H2O}\). [1]

Oxidation (× 3 to get 12 e⁻; dichromate × 2): \(\ce{C2H5OH + H2O -> CH3COOH + 4H+ + 4e-}\). [1]

Overall: \(\ce{2Cr2O7^2- + 16H+ + 3C2H5OH -> 4Cr^3+ + 11H2O + 3CH3COOH}\). [1] (Check: H⁺ \(28 - 12 = 16\); H₂O \(14 - 3 = 11\).)

Write the half-equation for the oxidation of methane to carbon dioxide in (a) acidic conditions and (b) alkaline conditions.

(a) \(\ce{CH4(g) + 2H2O(l) -> CO2(g) + 8H+(aq) + 8e-}\). [1]

(b) Add 8 OH⁻ to both sides: \(\ce{CH4 + 2H2O + 8OH- -> CO2 + 8H2O + 8e-}\), which simplifies to \(\ce{CH4(g) + 8OH-(aq) -> CO2(g) + 6H2O(l) + 8e-}\). [2] (In strongly alkaline solution the CO₂ reacts further to carbonate, but this form is accepted unless asked.)

A student balances \(\ce{Fe^3+ + Cu -> Fe^2+ + Cu^2+}\) as written. What's wrong?

Charge isn't balanced (left +3, right +4): Cu loses 2 e⁻ but each Fe³⁺ gains only 1. Correct: \(\ce{2Fe^3+ + Cu -> 2Fe^2+ + Cu^2+}\).

Summary

  • Oxidation: lose e⁻, oxidation number up; reduction: gain e⁻, oxidation number down.
  • KOHES: key element, O with H₂O, H with H⁺, charge with e⁻, states.
  • Basic conditions: add OH⁻ to both sides to cancel H⁺.
  • Overall equation: multiply to match electrons, add, cancel.
