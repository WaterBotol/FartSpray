Dynamic equilibrium

In a closed system, a reversible reaction reaches equilibrium when the forward and reverse rates are equal. Both reactions keep going (it's dynamic), but the concentrations stay constant. They are generally not equal to each other.

The equilibrium expression

For \(a\ce{A} + b\ce{B} \rightleftharpoons c\ce{C} + d\ce{D}\)
\[ K = \frac{[\ce{C}]^c[\ce{D}]^d}{[\ce{A}]^a[\ce{B}]^b} \]

Concentrations in mol L⁻¹ at equilibrium. Include only gases and aqueous species (not solids or liquid water). \(K\) depends only on temperature.

Size of \(K\)Meaning
\(K > 10^4\)Reaction goes almost to completion: products favoured
\(10^{-4} < K < 10^4\)Significant amounts of both reactants and products
\(K < 10^{-4}\)Hardly any products form: reactants favoured

\(K\) tells you the extent of reaction, not the rate. A huge \(K\) can still mean a very slow reaction.

Change to the equationNew \(K\)
Reverse it\(\frac{1}{K}\)
Multiply coefficients by \(n\)\(K^n\) (halving gives \(\sqrt{K}\))

At equilibrium, a 2.0 L vessel contains 0.40 mol N₂, 1.20 mol H₂ and 0.20 mol NH₃. Calculate \(K\) for \(\ce{N2(g) + 3H2(g) <=> 2NH3(g)}\).

Concentrations: \([\ce{N2}] = 0.20\), \([\ce{H2}] = 0.60\), \([\ce{NH3}] = 0.10\ \text{M}\). (Divide by volume first!)

\(K = \dfrac{[\ce{NH3}]^2}{[\ce{N2}][\ce{H2}]^3} = \dfrac{0.10^2}{0.20 \times 0.60^3}\).

\(K = 0.23\ \text{M}^{-2}\). Units: \(\frac{\text{M}^2}{\text{M} \cdot \text{M}^3} = \text{M}^{-2}\).

The reaction quotient Q

\(Q\) has the same form as \(K\) but uses the concentrations at any moment. Compare it with \(K\):

  • \(Q < K\): too few products, so the reaction proceeds forwards (net).
  • \(Q > K\): too many products, so the reaction proceeds backwards (net).
  • \(Q = K\): at equilibrium.

For the ammonia equilibrium above (\(K = 0.23\ \text{M}^{-2}\) at that temperature), a mixture has \([\ce{N2}] = [\ce{H2}] = [\ce{NH3}] = 0.50\ \text{M}\). Predict the direction of net reaction.

\(Q = \frac{0.50^2}{0.50 \times 0.50^3} = \frac{0.25}{0.0625} = 4.0\).

\(Q > K\), so the net reaction goes backwards: NH₃ decomposes until \(Q\) falls to 0.23.

Concentrations (÷ 2.0 L): 0.050, 0.025, 0.15 M.

\(K = \dfrac{0.15^2}{0.050^2 \times 0.025} = \) \(3.6 \times 10^2\ \text{M}^{-1}\).

1.00 mol H₂ and 1.00 mol I₂ are placed in a 1.00 L flask. \(K = 50\) at this temperature for \(\ce{H2(g) + I2(g) <=> 2HI(g)}\). Calculate the equilibrium concentration of HI.

E row: \([\ce{H2}] = [\ce{I2}] = 1.00 - x\), \([\ce{HI}] = 2x\).

\(\frac{(2x)^2}{(1.00 - x)^2} = 50\). Take square roots: \(\frac{2x}{1.00 - x} = 7.07\).

\(2x = 7.07 - 7.07x \Rightarrow x = 0.780\).

\([\ce{HI}] = 1.56\ \text{M}\) (and \([\ce{H2}] = [\ce{I2}] = 0.22\ \text{M}\)). The square-root trick only works because the expression is a perfect square.

  • Use concentrations, not moles, unless the moles on both sides of the expression cancel out exactly.
  • “At equilibrium the concentrations are equal” is false. The rates are equal.
  • Leave out solids and liquid water from \(K\) expressions.
  • \(K\) changes only with temperature. Adding reactant changes \(Q\), not \(K\).
  • Units of \(K\) depend on the equation; recompute them for each expression.

Practice

The equilibrium expression for \(\ce{2NO2(g) <=> N2O4(g)}\) is

  1. \(\frac{[\ce{NO2}]^2}{[\ce{N2O4}]}\)
  2. \(\frac{[\ce{N2O4}]}{[\ce{NO2}]^2}\)
  3. \(\frac{[\ce{N2O4}]}{2[\ce{NO2}]}\)
  4. \([\ce{N2O4}][\ce{NO2}]^2\)

Products over reactants, each raised to its coefficient.

For \(\ce{N2 + 3H2 <=> 2NH3}\), \(K = 0.23\ \text{M}^{-2}\). For \(\ce{2NH3 <=> N2 + 3H2}\) at the same temperature, \(K\) is

  1. 0.23 M²
  2. −0.23 M²
  3. 0.053 M²
  4. 4.3 M²

Reversed: \(\frac{1}{0.23} = 4.3\), with units M².

Which statement about a system at equilibrium is correct?

  1. The forward and reverse reactions are occurring at equal rates
  2. The concentrations of reactants and products are equal
  3. No reactions are occurring
  4. \(K = 1\)

Dynamic equilibrium: both reactions continue at equal rates.

A reaction has \(K = 2.0 \times 10^{-9}\) at 25 °C. At equilibrium the mixture contains

  1. mostly products
  2. equal amounts of reactants and products
  3. mostly reactants
  4. no reactants

A very small \(K\) means the denominator (reactants) dominates.

For \(\ce{A(g) + B(g) <=> 2C(g)}\), \(K = 4.0\). A mixture has [A] = [B] = 1.0 M and [C] = 3.0 M. Which is true?

  1. \(Q = 3.0\); the reaction proceeds forwards
  2. \(Q = 9.0\); the reaction proceeds backwards
  3. \(Q = 9.0\); the reaction proceeds forwards
  4. The system is at equilibrium

\(Q = \frac{3.0^2}{1.0 \times 1.0} = 9.0 > K\): too many products, so net reverse reaction.

For \(\ce{H2(g) + I2(g) <=> 2HI(g)}\), the value of \(K\) calculated using moles instead of concentrations is

  1. larger than the true value
  2. smaller than the true value
  3. impossible to predict
  4. the same as the true value

There are 2 “concentration terms” top and bottom, so the volume cancels: \(\frac{(n/V)^2}{(n/V)(n/V)}\). This is the only kind of case where moles can be used.

Write the equilibrium expression, with units, for \(\ce{CO(g) + 2H2(g) <=> CH3OH(g)}\).

\(K = \dfrac{[\ce{CH3OH}]}{[\ce{CO}][\ce{H2}]^2}\), units M⁻² (or mol⁻² L²).

PCl₅ decomposes: \(\ce{PCl5(g) <=> PCl3(g) + Cl2(g)}\), \(K = 0.040\ \text{M}\). 0.50 mol PCl₅ is placed in a 1.0 L flask. Calculate the equilibrium concentrations.

E: \([\ce{PCl5}] = 0.50 - x\), \([\ce{PCl3}] = [\ce{Cl2}] = x\). [1]

\(\frac{x^2}{0.50 - x} = 0.040 \Rightarrow x^2 + 0.040x - 0.020 = 0\). [1]

Quadratic formula (positive root): \(x = 0.123\). [1]

\([\ce{PCl3}] = [\ce{Cl2}] = 0.12\ \text{M}\), \([\ce{PCl5}] = 0.38\ \text{M}\). [1]

For \(\ce{2SO2 + O2 <=> 2SO3}\), \(K = 360\ \text{M}^{-1}\) at temperature \(T\). (a) Find \(K\) for \(\ce{SO3 <=> SO2 + 1/2O2}\) at \(T\). (b) A mixture at \(T\) has [SO₂] = 0.10 M, [O₂] = 0.050 M and [SO₃] = 0.40 M. Is it at equilibrium? If not, which way will it shift?

(a) Reverse and halve: \(K' = \left(\frac{1}{360}\right)^{1/2} = 0.053\ \text{M}^{1/2}\). [1]

(b) \(Q = \frac{0.40^2}{0.10^2 \times 0.050} = 320\ \text{M}^{-1}\). [1] \(Q < K\), so it isn't at equilibrium; net forward reaction (more SO₃ forms). [1]

A student adds more N₂ to an equilibrium mixture of N₂, H₂ and NH₃ and says the value of \(K\) increases. Explain the error.

\(K\) depends only on temperature. Adding N₂ lowers \(Q\) below \(K\), so the system shifts forward until \(Q = K\) again (same \(K\), new concentrations).

Summary

  • Equilibrium: equal forward and reverse rates; constant (not equal) concentrations.
  • \(K = \frac{[\text{products}]^{\text{coeff}}}{[\text{reactants}]^{\text{coeff}}}\); depends only on temperature.
  • Reverse: \(\frac1K\); multiply by \(n\): \(K^n\).
  • \(Q < K\) → forwards; \(Q > K\) → backwards. ICE tables for calculations.
