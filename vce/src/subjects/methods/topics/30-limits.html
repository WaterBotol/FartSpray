Limits

\(\displaystyle\lim_{x \to a} f(x) = L\) means \(f(x)\) gets as close as we like to \(L\) as \(x\) gets close to \(a\) (from both sides). It doesn't matter what happens at \(x = a\) itself.

Evaluate \(\displaystyle\lim_{x \to 3} \frac{x^2 - 9}{x - 3}\).

Direct substitution gives \(\frac00\): factorise. \(\frac{(x - 3)(x + 3)}{x - 3} = x + 3\) for \(x \ne 3\).

\(\lim = 3 + 3 = 6\). The graph is the line \(y = x + 3\) with a hole at \((3, 6)\).

Limits at infinity: divide top and bottom by the highest power. \(\displaystyle\lim_{x \to \infty}\frac{2x + 1}{x - 3} = \lim_{x \to \infty}\frac{2 + \frac1x}{1 - \frac3x} = 2\): the horizontal asymptote.

The derivative from first principles

Definition of the derivative
\[ f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h} \]

The fraction is the gradient of the secant through \((x, f(x))\) and \((x + h, f(x + h))\). As \(h \to 0\), the secant becomes the tangent.

Use first principles to find the derivative of \(f(x) = x^2 - 3x\).

\(f(x + h) = (x + h)^2 - 3(x + h) = x^2 + 2xh + h^2 - 3x - 3h\).

\(f(x + h) - f(x) = 2xh + h^2 - 3h\), so \(\dfrac{f(x + h) - f(x)}{h} = 2x + h - 3\) (for \(h \ne 0\)).

\(f'(x) = \displaystyle\lim_{h \to 0}(2x + h - 3) = 2x - 3\). Write “\(\lim_{h \to 0}\)” on every line until the last one: examiners deduct marks when it disappears too early.

Continuity

\(f\) is continuous at \(x = a\) if \(f(a)\) is defined and \(\displaystyle\lim_{x \to a} f(x) = f(a)\). In practice: you can draw through \(x = a\) without lifting your pen. For a hybrid function, the left and right rules must give the same value at the join.

Differentiability

\(f\) is differentiable at \(x = a\) if the left and right gradients exist and are equal. A function that is not continuous at a point is not differentiable there. But continuity alone isn't enough:

FeatureContinuous?Differentiable?Example
Jump or holeNoNoHybrid with mismatched pieces
Corner (sharp point)YesNo\(|x|\) at \(x = 0\); \(|x^2 - 4|\) at \(x = \pm2\)
CuspYesNo\(x^{2/3}\) at \(x = 0\)
Vertical tangentYesNo\(x^{1/3}\) at \(x = 0\)
Endpoint of a closed domainYesNo (only one-sided)\(\sqrt{x}\) at \(x = 0\)

VCAA convention: a function is differentiable on an open interval. When asked for the domain of \(f'\), exclude endpoints and every corner, cusp, jump and vertical tangent.

Find \(a\) and \(b\) such that \(f(x) = \begin{cases} ax^2 + b, & x \le 1 \\ 4x - 1, & x > 1 \end{cases}\) is differentiable at \(x = 1\).

Continuous: \(a(1)^2 + b = 4(1) - 1 \Rightarrow a + b = 3\).

Gradients match: left derivative \(2ax\) at \(x = 1\) is \(2a\); right derivative is 4. So \(2a = 4\).

\(a = 2,\ b = 1\). Both conditions are needed. Matching gradients without continuity doesn't make the function differentiable.

State the domain of \(f'\) for \(f: [-3, 3] \to \mathbb{R},\ f(x) = |x^2 - 4|\).

Corners where the graph is reflected: \(x^2 - 4 = 0 \Rightarrow x = \pm2\). Endpoints \(\pm3\) are also excluded.

\((-3, -2) \cup (-2, 2) \cup (2, 3)\).

  • Continuous doesn't mean differentiable. Every corner is continuous.
  • A limit can exist even where \(f(a)\) doesn't (a hole), and \(f(a)\) can exist without the limit (a jump).
  • For hybrid gradients, differentiate each piece separately and compare the values at the join. Don't differentiate across the join.
  • Endpoints: derivatives are only defined on open intervals in VCAA's convention.

Practice

\(\displaystyle\lim_{x \to 2}\frac{x^2 + x - 6}{x - 2}\) equals

  1. 0
  2. does not exist
  3. 5
  4. 3

\(\frac{(x + 3)(x - 2)}{x - 2} = x + 3 \to 5\).

At \(x = 0\), the function \(f(x) = x^{1/3}\) is

  1. continuous but not differentiable
  2. differentiable but not continuous
  3. neither continuous nor differentiable
  4. continuous and differentiable

The graph passes smoothly through the origin but the tangent there is vertical: \(f'(x) = \frac{1}{3x^{2/3}} \to \infty\).

\(\displaystyle\lim_{x \to \infty}\frac{3x^2 - 1}{2x^2 + x}\) equals

  1. 0
  2. \(\infty\)
  3. \(-1\)
  4. \(\frac32\)

Divide by \(x^2\): \(\frac{3 - 1/x^2}{2 + 1/x} \to \frac32\).

For \(f(x) = x^3\), the expression \(\dfrac{f(x + h) - f(x)}{h}\) simplifies to

  1. \(3x^2\)
  2. \(3x^2 + 3xh + h^2\)
  3. \(3x^2 + h^2\)
  4. \(x^2 + xh + h^2\)

\((x + h)^3 - x^3 = 3x^2h + 3xh^2 + h^3\); divide by \(h\). Only after taking the limit do you get \(3x^2\).

\(g(x) = \begin{cases} x^2, & x < 1 \\ 2x - 1, & x \ge 1 \end{cases}\). Which statement is true?

  1. \(g\) is not continuous at \(x = 1\)
  2. \(g\) is continuous but not differentiable at \(x = 1\)
  3. \(g\) is differentiable at \(x = 1\)
  4. \(g'(1) = 1\)

Values: \(1^2 = 1\) and \(2(1) - 1 = 1\) ✓. Gradients: \(2x = 2\) and \(2\) ✓. So it's differentiable with \(g'(1) = 2\). (The line is the tangent to the parabola at \(x = 1\).)

The derivative of \(f(x) = |x - 2| + |x + 1|\) does not exist at

  1. \(x = -1\) and \(x = 2\)
  2. \(x = 2\) only
  3. \(x = \frac12\)
  4. nowhere

Each modulus makes a corner where its inside is zero. As a hybrid: gradient −2, then 0, then 2, which change at \(x = -1\) and \(x = 2\).

Use first principles to show that the derivative of \(f(x) = 5 - 2x^2\) is \(-4x\).

\(f(x + h) - f(x) = 5 - 2(x^2 + 2xh + h^2) - 5 + 2x^2 = -4xh - 2h^2\).

\(f'(x) = \displaystyle\lim_{h \to 0}\frac{-4xh - 2h^2}{h} = \lim_{h \to 0}(-4x - 2h) = -4x\).

Find \(p\) and \(q\) so that \(f(x) = \begin{cases} px^3 + q, & x < 2 \\ 6x - 4, & x \ge 2 \end{cases}\) is differentiable for all real \(x\).

Gradient: \(3px^2 = 6\) at \(x = 2 \Rightarrow 12p = 6 \Rightarrow p = \frac12\). [1]

Continuity: \(\frac12(8) + q = 12 - 4 = 8 \Rightarrow q = 4\). [1]

\(p = \frac12,\ q = 4\). [1]

Let \(f: [0, 2\pi] \to \mathbb{R},\ f(x) = |\sin x|\). State the domain of \(f'\).

Corner at \(x = \pi\) (where \(\sin x\) changes sign) plus the endpoints 0 and \(2\pi\).

\((0, \pi) \cup (\pi, 2\pi)\).

A student says: “\(h(x) = \begin{cases} x^2 + 1, & x < 0 \\ x^2, & x \ge 0 \end{cases}\) has \(h'(x) = 2x\) for both pieces, so \(h\) is differentiable at 0.” Explain the error.

At \(x = 0\) the pieces give 1 and 0: \(h\) is not continuous there (a jump). A function that isn't continuous at a point can't be differentiable there, even if the gradient formulas match.

Summary

  • \(f'(x) = \lim_{h \to 0}\frac{f(x + h) - f(x)}{h}\): expand, cancel \(h\), then let \(h \to 0\).
  • Continuous: no breaks. Differentiable: continuous and no corners, cusps or vertical tangents.
  • Smooth hybrid join: match values and gradients.
