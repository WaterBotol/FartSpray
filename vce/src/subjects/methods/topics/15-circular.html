Radians, exact values and symmetry

\(\pi\) radians \(= 180^\circ\). On the unit circle, the point at angle \(\theta\) is \((\cos\theta, \sin\theta)\), and \(\tan\theta = \frac{\sin\theta}{\cos\theta}\).

Symmetry (quadrants 2, 3, 4)
\[ \sin(\pi - \theta) = \sin\theta \quad \sin(\pi + \theta) = -\sin\theta \quad \sin(2\pi - \theta) = -\sin\theta \]\[ \cos(\pi - \theta) = -\cos\theta \quad \cos(\pi + \theta) = -\cos\theta \quad \cos(2\pi - \theta) = \cos\theta \]\[ \sin\!\left(\tfrac{\pi}{2} - \theta\right) = \cos\theta \qquad \sin^2\theta + \cos^2\theta = 1 \]

Solving trig equations

  1. Isolate the trig function: \(\sin(\ldots) = c\).
  2. Adjust the domain to match the argument (e.g. \(x \in [0, 2\pi] \Rightarrow 2x \in [0, 4\pi]\)).
  3. Find the reference angle from \(|c|\), then use the quadrants for the sign.
  4. List every solution in the adjusted domain, then solve for \(x\).

Solve \(2\cos(2x) + \sqrt2 = 0\) for \(x \in [0, 2\pi]\).

Find the reference angle, use the quadrant rules (the sign of cos) to list angles, and extend the interval to match the argument: if \(x \in [0, 2\pi]\) then \(2x \in [0, 4\pi]\).

\(\cos(2x) = -\frac{\sqrt2}{2}\). Reference angle \(\frac{\pi}{4}\); cosine is negative in quadrants 2 and 3.

\(2x \in [0, 4\pi]\): \(2x = \frac{3\pi}{4}, \frac{5\pi}{4}, \frac{11\pi}{4}, \frac{13\pi}{4}\).

\(x = \frac{3\pi}{8}, \frac{5\pi}{8}, \frac{11\pi}{8}, \frac{13\pi}{8}\). A doubled argument means twice as many solutions. Four, not two.

(a) Solve \(\sin(2x) = \cos(2x)\) for \(x \in [0, \pi]\). (b) Find the general solution of \(\sqrt3\sin(2x) = \cos(2x)\).

When sin and cos of the same angle are equal (or in a fixed ratio), divide to get tan. Tan repeats every \(\pi\), which gives the general solution.

(a) Divide by \(\cos(2x)\): \(\tan(2x) = 1\). \(2x \in [0, 2\pi]\): \(2x = \frac{\pi}{4}, \frac{5\pi}{4}\), so \(x = \frac{\pi}{8}, \frac{5\pi}{8}\).

(b) \(\tan(2x) = \frac{1}{\sqrt3}\), so \(2x = \frac{\pi}{6} + n\pi\), \(n \in \mathbb{Z}\).

(a) \(x = \frac{\pi}{8}, \frac{5\pi}{8}\); (b) \(x = \frac{\pi}{12} + \frac{n\pi}{2},\ n \in \mathbb{Z}\).

General solutions (\(n \in \mathbb{Z}\))
\[ \sin x = a:\ x = 2n\pi + \sin^{-1}a \ \text{ or } \ x = (2n + 1)\pi - \sin^{-1}a \]\[ \cos x = a:\ x = 2n\pi \pm \cos^{-1}a \qquad \tan x = a:\ x = n\pi + \tan^{-1}a \]

Periodic models

The depth of water in a harbour is \(D(t) = 3 + 2\cos\!\left(\frac{\pi t}{6}\right)\) metres, \(t\) hours after midnight. (a) State the maximum and minimum depths and the period. (b) For how long in the first 12 hours is the depth at least 4 m?

For \(k + a\cos(nt)\), the maximum and minimum are \(k \pm |a|\) and the period is \(2\pi/n\). Inequalities are solved like equations, then you pick the intervals where the condition holds.

(a) Max \(3 + 2 = 5\) m, min \(3 - 2 = 1\) m, period \(\frac{2\pi}{\pi/6} = 12\) hours.

(b) \(\cos\!\left(\frac{\pi t}{6}\right) \ge \frac12\) with \(\frac{\pi t}{6} \in [0, 2\pi]\): \(\frac{\pi t}{6} \in \left[0, \frac{\pi}{3}\right] \cup \left[\frac{5\pi}{3}, 2\pi\right]\).

So \(t \in [0, 2] \cup [10, 12]\).

(a) 5 m, 1 m, 12 h. (b) 4 hours in total (midnight to 2 am and 10 am to noon).

  • Adjust the domain for the argument. Forgetting this is the number-one way students lose solutions.
  • \(\sin^2 x = \frac14\) means \(\sin x = \pm\frac12\): four solutions in \([0, 2\pi]\), not two.
  • Endpoints count. \(\sin x = 0\) on \([0, 2\pi]\) has three solutions: \(0, \pi, 2\pi\).
  • Calculator in radians! Degree mode is an instant zero in Methods.
  • Tan's period is \(\frac{\pi}{n}\), not \(\frac{2\pi}{n}\).

  2. \(\frac{\pi}{2}\)

  2. \([-2, 2]\)
  3. \([1, 3]\)
  4. \([-3, 1]\)

\(\cos(3x) \in [-1, 1]\), so \(-2\cos(3x) \in [-2, 2]\), and adding 1 gives \([-1, 3]\).

  2. 2
  3. 3
  4. 4

\(3x \in [0, 3\pi]\): \(3x = \frac{\pi}{6}, \frac{5\pi}{6}, \frac{13\pi}{6}, \frac{17\pi}{6}\), so \(x = \frac{\pi}{18}, \frac{5\pi}{18}, \frac{13\pi}{18}, \frac{17\pi}{18}\).

  2. \(-\frac12\)
  3. \(-\frac{\sqrt3}{2}\)

  2. \(\frac{2\pi}{3}, \frac{5\pi}{3}\)

  1. 1
  2. 2
  3. 4
  4. 8

Solve \(2\sin x = -\sqrt3\) for \(x \in [-\pi, \pi]\).

\(\sin x = -\frac{\sqrt3}{2}\), reference angle \(\frac{\pi}{3}\), negative in quadrants 3 and 4. In \([-\pi, \pi]\) these are \(x = -\frac{\pi}{3}\) and \(x = -\frac{2\pi}{3}\).

A graph with rule \(y = a\sin(bx) + c\) (\(a, b > 0\)) has maximum 5, minimum \(-1\) and period \(\pi\). Find \(a\), \(b\) and \(c\).

\(a = \frac{5 - (-1)}{2} = 3\); \(c = \frac{5 + (-1)}{2} = 2\); \(\frac{2\pi}{b} = \pi \Rightarrow b = 2\).

Find all values of \(k\) for which \(\sin x = k\) has exactly two solutions for \(x \in [0, 2\pi]\).

For \(-1 < k < 1\) a horizontal line usually cuts one full wave twice, but at \(k = 0\) it also hits both endpoints: \(x = 0, \pi, 2\pi\) (three solutions). At \(k = \pm1\) there is one solution.

\(k \in (-1, 0) \cup (0, 1)\).

Solve \(\sqrt3\sin(2x) = \cos(2x)\) for \(x \in [0, 2\pi]\).

\(\tan(2x) = \frac{1}{\sqrt3}\), with \(2x \in [0, 4\pi]\): \(2x = \frac{\pi}{6}, \frac{7\pi}{6}, \frac{13\pi}{6}, \frac{19\pi}{6}\).

\(x = \frac{\pi}{12}, \frac{7\pi}{12}, \frac{13\pi}{12}, \frac{19\pi}{12}\).

The temperature in a greenhouse is \(T(t) = 22 - 6\cos\!\left(\frac{\pi(t - 2)}{12}\right)\) °C, where \(t\) is hours after midnight, \(0 \le t \le 24\). (a) Find the maximum temperature and when it occurs. (b) Find the times when the temperature is 25 °C.

(a) Max when \(\cos(\ldots) = -1\): \(\frac{\pi(t - 2)}{12} = \pi \Rightarrow t = 14\). Max \(28\) °C at 2 pm. [2]

(b) \(\cos\!\left(\frac{\pi(t - 2)}{12}\right) = -\frac12\). With \(\frac{\pi(t - 2)}{12} \in \left[-\frac{\pi}{6}, \frac{11\pi}{6}\right]\): \(= \frac{2\pi}{3}\) or \(\frac{4\pi}{3}\), so \(t - 2 = 8\) or \(16\). [1]

\(t = 10\) and \(t = 18\): 10 am and 6 pm. [1]

Summary

  • \(y = a\sin(n(x - h)) + k\): amplitude \(|a|\), period \(\frac{2\pi}{n}\) (tan: \(\frac{\pi}{n}\)), range \([k - |a|, k + |a|]\).
  • Solve: isolate, adjust the domain for the argument, reference angle, quadrants, then solve for \(x\).
  • General solutions: \(\cos\): \(2n\pi \pm \alpha\); \(\tan\): \(n\pi + \alpha\).
