Exam 1 is 1 hour (plus 15 min reading) for 40 marks: short-answer, tech-free, exact answers. Allow about 1.5 minutes per mark. Do these under those conditions with no CAS or calculator, then mark yourself strictly against the solutions: VCAA awards method marks (M) and answer marks (A) separately. The questions start routine and finish with the kinds that usually have the lowest average scores.

Section 1: routine (aim for full marks)

Q1. Let \(y = x^3\log_e x\). Find \(\dfrac{dy}{dx}\), and evaluate it at \(x = e\).

\(\dfrac{dy}{dx} = 3x^2\log_e x + x^3\cdot\dfrac1x = 3x^2\log_e x + x^2\). [1]

At \(x = e\): \(3e^2 + e^2 = 4e^2\). [1]

Q2. Evaluate \(\displaystyle\int_0^{\pi/6}\cos(3x)\,dx\).

\(\left[\frac13\sin(3x)\right]_0^{\pi/6} = \frac13\sin\frac{\pi}{2} - 0 = \frac13\). [2]

Q3. Solve \(2\log_3 x - \log_3(x + 6) = 1\).

\(\log_3\dfrac{x^2}{x + 6} = 1 \Rightarrow x^2 = 3(x + 6)\). [1]

\(x^2 - 3x - 18 = 0 \Rightarrow (x - 6)(x + 3) = 0\). [1]

\(x = 6\) (reject \(x = -3\), since \(\log_3(-3)\) is undefined). [1]

Q4. Use Newton's method with \(x_0 = 2\) to find \(x_1\) for \(f(x) = x^3 - 5\).

\(f'(x) = 3x^2\). \(x_1 = 2 - \dfrac{8 - 5}{12} = 2 - \dfrac14 = \dfrac74\). [2]

Section 2: standard

Q5. Solve \(2\sin(2x) = \sqrt3\) for \(x \in [-\pi, \pi]\).

\(\sin(2x) = \frac{\sqrt3}{2}\), with \(2x \in [-2\pi, 2\pi]\). [1]

\(2x = \frac{\pi}{3}, \frac{2\pi}{3}, -\frac{5\pi}{3}, -\frac{4\pi}{3}\). [1]

\(x = -\frac{5\pi}{6}, -\frac{2\pi}{3}, \frac{\pi}{6}, \frac{\pi}{3}\). [1]

Q6. Let \(f(x) = x^2e^{-x}\). (a) Show that \(f'(x) = x(2 - x)e^{-x}\). (b) Find the coordinates and nature of the stationary points.

(a) \(f'(x) = 2xe^{-x} - x^2e^{-x} = x(2 - x)e^{-x}\). [1]

(b) \(f'(x) = 0 \Rightarrow x = 0\) or \(x = 2\) (as \(e^{-x} \ne 0\)). [1]

Sign of \(f'\): \(-\), \(+\), \(-\). So \((0, 0)\) is a local minimum [1] and \(\left(2, \frac{4}{e^2}\right)\) is a local maximum. [1]

Q7. \(X \sim \text{Bi}\left(3, \frac13\right)\). Find \(P(X = 2 \mid X \ge 1)\).

\(P(X \ge 1) = 1 - \left(\frac23\right)^3 = \frac{19}{27}\). [1]

\(P(X = 2) = 3\left(\frac13\right)^2\left(\frac23\right) = \frac{6}{27}\). [1]

\(P(X = 2 \mid X \ge 1) = \frac{6/27}{19/27} = \frac{6}{19}\). [1]

Q8. A continuous random variable has pdf \(f(x) = k\sin(\pi x)\) for \(0 \le x \le 1\) (0 elsewhere). Find \(k\) and \(P\left(X < \frac13\right)\).

\(k\left[-\frac{\cos(\pi x)}{\pi}\right]_0^1 = \frac{2k}{\pi} = 1 \Rightarrow k = \frac{\pi}{2}\). [1]

\(P\left(X < \frac13\right) = \frac{\pi}{2}\cdot\frac1\pi\left[-\cos(\pi x)\right]_0^{1/3} = \frac12\left(1 - \frac12\right) = \frac14\). [2]

Q9. Find the total area enclosed between the graph of \(y = x^2 - 2x\) and the \(x\)-axis for \(0 \le x \le 3\).

Intercepts at \(x = 0, 2\); the graph is below the axis on \((0, 2)\). [1]

\(-\int_0^2(x^2 - 2x)\,dx = \frac43\) and \(\int_2^3(x^2 - 2x)\,dx = \left[\frac{x^3}{3} - x^2\right]_2^3 = 0 - \left(-\frac43\right) = \frac43\). [1]

Total \(\frac83\) square units. [1]

Q10. In a random sample of 100 people, 20 are left-handed. Using \(z \approx 2\), find an approximate 95% confidence interval for the proportion of left-handed people.

\(\hat p = 0.2\); SE \(= \sqrt{\frac{0.2 \times 0.8}{100}} = 0.04\). [1]

\(0.2 \pm 2(0.04)\): \((0.12, 0.28)\). [1]

Section 3: the hardest styles

Q11. Find the equation of the tangent to \(y = e^{2x}\) that passes through the origin.

Contact point \((a, e^{2a})\), gradient \(2e^{2a}\). Tangent: \(y - e^{2a} = 2e^{2a}(x - a)\). [1]

Through \((0, 0)\): \(-e^{2a} = -2ae^{2a} \Rightarrow a = \frac12\). [1]

Gradient \(2e\), so the tangent is \(y = 2ex\). [1]

Q12. Let \(f(x) = \sqrt{4 - x}\) (maximal domain) and \(g: [-a, a] \to \mathbb{R},\ g(x) = x^2\). Find the largest value of \(a\) for which \(f \circ g\) exists.

Need \(\text{ran}\, g = [0, a^2] \subseteq \text{dom}\, f = (-\infty, 4]\). [1]

\(a^2 \le 4 \Rightarrow a = 2\). [1]

Q13. Given \(\int_0^2 f(x)\,dx = 5\), the graph of \(y = f(x)\) is transformed by \((x, y) \to (2x - 1,\ 3 - y)\). Find the integral of the image function from \(x = -1\) to \(x = 3\).

Image: \(x' = 2x - 1,\ y' = 3 - y \Rightarrow y' = 3 - f\!\left(\frac{x' + 1}{2}\right)\). [1]

\(\int_{-1}^{3}\left(3 - f\!\left(\frac{x + 1}{2}\right)\right)dx = 3 \times 4 - 2\int_0^2 f(u)\,du\) (the horizontal dilation by 2 doubles the area). [1]

\(= 12 - 10 = 2\). [1]

Q14. Let \(f(x) = x^3 - 3x^2 + k\). (a) Find the values of \(k\) for which \(f(x) = 0\) has three distinct real solutions. (b) For \(k = 4\), factorise \(f(x)\).

(a) \(f'(x) = 3x(x - 2)\); local max \(f(0) = k\), local min \(f(2) = k - 4\). [1] Three solutions need \(k > 0\) and \(k - 4 < 0\): \(0 < k < 4\). [1]

(b) \(k = 4\): \(f(2) = 0\) and \(x = 2\) is a turning point, so \((x - 2)^2\) is a factor. [1] \(x^3 - 3x^2 + 4 = (x - 2)^2(x + 1)\). [1]

Q15. \(f(x) = \begin{cases} ax^2 + bx, & x \le 1 \\ \log_e x + 2, & x > 1\end{cases}\) is differentiable at \(x = 1\). Find \(a\) and \(b\), then find the exact area under \(y = f(x)\) from \(x = 0\) to \(x = 1\).

Continuity: \(a + b = \log_e 1 + 2 = 2\). [1] Gradient: \(2a + b = \frac11 = 1\). [1]

Subtract: \(a = -1\), \(b = 3\). [1]

\(\int_0^1(-x^2 + 3x)\,dx = -\frac13 + \frac32 = \frac76\) (the parabola is positive on \((0, 1]\)). [1]

Marking yourself

Total 43 marks. Roughly: 36+ is an A+ standard for Exam 1, and 28+ is solid. Any Section 1 marks you dropped should be fixed first: those are the cheapest marks in the paper. If Q12–Q15 went badly, revisit composite functions, transformations, polynomials with a parameter and differentiability.
