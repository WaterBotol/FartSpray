Rectangles and trapeziums

Split \([a, b]\) into \(n\) strips of width \(h = \frac{b - a}{n}\), with \(x_0 = a, x_1, \ldots, x_n = b\).

The three estimates
\[ L = h\big[f(x_0) + f(x_1) + \cdots + f(x_{n-1})\big] \qquad R = h\big[f(x_1) + \cdots + f(x_n)\big] \]\[ T = \frac{h}{2}\big[f(x_0) + 2f(x_1) + \cdots + 2f(x_{n-1}) + f(x_n)\big] = \frac{L + R}{2} \]

The trapezium rule is on the formula sheet. \(L\) and \(R\) aren't, but they're easy: left uses every height except the last, right every height except the first.

Estimate \(\int_0^2 x^2\,dx\) with four strips using (a) left rectangles, (b) right rectangles, (c) the trapezium rule. Compare with the exact value.

\(h = 0.5\). Heights at \(x = 0, 0.5, 1, 1.5, 2\): \(0, 0.25, 1, 2.25, 4\).

(a) \(L = 0.5(0 + 0.25 + 1 + 2.25) = 1.75\). (b) \(R = 0.5(0.25 + 1 + 2.25 + 4) = 3.75\).

(c) \(T = \frac{0.5}{2}\big(0 + 2(0.25 + 1 + 2.25) + 4\big) = 0.25 \times 11 = 2.75\).

\(L = 1.75,\ R = 3.75,\ T = 2.75\); exact \(\frac83 \approx 2.667\). \(x^2\) is increasing, so \(L\) under- and \(R\) over-estimates. It's concave up, so the trapeziums sit above the curve and \(T\) is an overestimate.

Over or under?

Decreasingoverunderdepends on concavity
Concave up (\(f'' > 0\))––over
Concave down (\(f'' < 0\))––under

Picture the tops: a trapezium's slanted top is a chord. Chords lie above a concave-up curve and below a concave-down one.

Use the trapezium rule with two strips to estimate \(\int_1^3\frac1x\,dx\). Is it an over- or under-estimate?

\(h = 1\); heights \(f(1) = 1,\ f(2) = \frac12,\ f(3) = \frac13\).

\(T = \frac12\left(1 + 2 \times \frac12 + \frac13\right) = \frac12 \times \frac73 = \frac76 \approx 1.167\).

\(\frac76\), an overestimate: \(\frac1x\) is concave up for \(x > 0\) (\(f''(x) = \frac{2}{x^3} > 0\)). The exact value is \(\log_e 3 \approx 1.099\).

A car's speed (m/s) is recorded every 2 seconds: \(t = 0, 2, 4, 6, 8\); \(v = 0, 6, 10, 12, 13\). Estimate the distance travelled in 8 s using the trapezium rule.

\(h = 2\): \(T = \frac22\big(0 + 2(6 + 10 + 12) + 13\big) = 56 + 13\).

About 69 m. Distance is the area under a speed–time graph.

  • Count strips, not points. Five \(x\)-values make four strips.
  • End heights appear once in the trapezium rule; the middle ones are doubled.
  • Left rectangles don't use the last height, and right rectangles don't use the first.
  • Over/under for a function that changes concavity can't be decided by the table above. Compute both, or compare with the exact value.

Practice

The trapezium rule with strips of width 1 is used to estimate \(\int_0^3 f(x)\,dx\), where \(f(0) = 2,\ f(1) = 3,\ f(2) = 5,\ f(3) = 4\). The estimate is

  1. 14
  2. 11
  3. 10
  4. 22

\(\frac12\big(2 + 2(3 + 5) + 4\big) = \frac12 \times 22 = 11\).

For \(f(x) = e^{-x}\) on \([0, 2]\), the left-endpoint rectangle estimate is

  1. an overestimate, because \(f\) is decreasing
  2. an underestimate, because \(f\) is decreasing
  3. an overestimate, because \(f\) is concave up
  4. exact

For a decreasing function, each left height is the tallest in its strip, so every rectangle sticks out above the curve.

The trapezium rule estimate of \(\int_0^{\pi}\sin x\,dx\) (any number of strips) is

  1. exact
  2. an overestimate
  3. sometimes over, sometimes under
  4. an underestimate

On \([0, \pi]\), \(\sin x\) is concave down (\(f'' = -\sin x \le 0\)), so every chord lies below the curve.

Right-endpoint rectangles of width 1 are used for \(\int_1^4\sqrt{x}\,dx\). The estimate is

  1. \(1 + \sqrt2 + \sqrt3\)
  2. \(1 + \sqrt2 + \sqrt3 + 2\)
  3. \(\sqrt2 + \sqrt3 + 2\)
  4. \(\frac12(1 + 2\sqrt2 + 2\sqrt3 + 2)\)

Heights at the right ends \(x = 2, 3, 4\), each multiplied by width 1. A is the left estimate; D is the trapezium estimate.

A student estimates \(\int_0^2 x^3\,dx\) (exact value 4) with the trapezium rule and 2 strips. Their percentage error is

  1. 12.5%
  2. 25%
  3. 50%
  4. 0%

\(T = \frac12(0 + 2 \times 1 + 8) = 5\). Error \(\frac{5 - 4}{4} = 25\%\).

Use the trapezium rule with 4 strips to estimate \(\int_0^2(4 - x^2)\,dx\). Is it an over- or under-estimate?

Heights \(4, 3.75, 3, 1.75, 0\): \(T = 0.25\big(4 + 2(3.75 + 3 + 1.75) + 0\big) = 0.25 \times 21 = 5.25\).

\(4 - x^2\) is concave down, so it's an underestimate (exact \(\frac{16}{3} \approx 5.33\)).

Find, in terms of \(n\), the left-endpoint rectangle estimate of \(\int_0^1 x\,dx\) using \(n\) equal strips, and show that it approaches the exact value as \(n \to \infty\).

\(h = \frac1n\), left heights \(0, \frac1n, \ldots, \frac{n - 1}{n}\). \(L = \frac1n\cdot\frac{0 + 1 + \cdots + (n - 1)}{n} = \frac{1}{n^2}\cdot\frac{(n - 1)n}{2}\). [2]

\(L = \frac{n - 1}{2n} = \frac12 - \frac{1}{2n} \to \frac12\) as \(n \to \infty\), which is the exact value. [1]

A river is 20 m wide. Depths (m) measured every 5 m across it are 0, 1.8, 3.2, 2.6, 0. (a) Estimate the cross-sectional area using the trapezium rule. (b) If the water flows at 0.8 m/s, estimate the volume passing per second.

(a) \(\frac52\big(0 + 2(1.8 + 3.2 + 2.6) + 0\big) = 2.5 \times 15.2 = 38\) m². [2]

(b) \(38 \times 0.8 = 30.4\) m³/s. [1]

Summary

  • \(T = \frac{h}{2}[\text{ends} + 2(\text{middles})]\); \(T = \frac{L + R}{2}\).
  • Monotonicity decides \(L\) and \(R\); concavity decides \(T\).
  • More strips give a better estimate.
