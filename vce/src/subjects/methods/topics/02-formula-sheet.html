VCAA provides a Methods formula sheet in both exams (mensuration, the derivative and antiderivative rules, and the probability and statistics formulas). Many things you use constantly aren't on it: exact values, log laws, transformations and the discriminant. Treat this page as a revision summary. Always check the current official sheet from the VCAA website before your exam.

Calculus

Derivatives

\[ \tfrac{d}{dx}x^n = nx^{n-1} \quad \tfrac{d}{dx}e^{kx} = ke^{kx} \quad \tfrac{d}{dx}\log_e(kx) = \tfrac1x \]\[ \tfrac{d}{dx}\sin(kx) = k\cos(kx) \quad \tfrac{d}{dx}\cos(kx) = -k\sin(kx) \quad \tfrac{d}{dx}\tan(kx) = \tfrac{k}{\cos^2(kx)} \]

Differentiation rules

Chain, product, quotient

\[ \tfrac{dy}{dx} = \tfrac{dy}{du}\tfrac{du}{dx} \quad (uv)' = u'v + uv' \quad \left(\tfrac{u}{v}\right)' = \tfrac{u'v - uv'}{v^2} \]

Antiderivatives

\[ \int x^n dx = \tfrac{x^{n+1}}{n + 1} + c \quad \int \tfrac1x dx = \log_e|x| + c \quad \int e^{kx} dx = \tfrac1k e^{kx} + c \]\[ \int \sin(kx) dx = -\tfrac1k\cos(kx) + c \quad \int\cos(kx) dx = \tfrac1k\sin(kx) + c \]

Antidifferentiation

Tangents and approximation

\[ y - f(a) = f'(a)(x - a) \qquad m_{\text{normal}} = -\tfrac{1}{f'(a)} \]\[ f(x + h) \approx f(x) + hf'(x) \]

Integrals

Probability and statistics

Probability rules

\[ P(A \cup B) = P(A) + P(B) - P(A \cap B) \]\[ P(A \mid B) = \tfrac{P(A \cap B)}{P(B)} \qquad \text{independent: } P(A \cap B) = P(A)P(B) \]

Probability

Discrete random variables

\[ E(X) = \sum xp(x) \qquad \operatorname{Var}(X) = E(X^2) - \mu^2 \]\[ E(aX + b) = aE(X) + b \qquad \operatorname{Var}(aX + b) = a^2\operatorname{Var}(X) \]

DRVs

Binomial

\[ P(X = x) = \tbinom{n}{x}p^x(1 - p)^{n - x} \qquad E = np \qquad \operatorname{Var} = np(1 - p) \]

Continuous random variables
