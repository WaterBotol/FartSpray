Quotient/product rule for \(\frac{x^2 - x}{e^x}\); product rule for \(\sin(x)e^{2x}\) at \(\frac{\pi}{4}\)

State average for the whole question: 2.9 / 4 (73%).

Find and simplify \(\frac{dy}{dx}\) for \(y = \frac{x^2 - x}{e^x}\)

  • Correct use of the product or quotient rule
  • \(\frac{dy}{dx} = \frac{-x^2 + 3x - 1}{e^x}\)

\((2x - 1)e^{-x} - (x^2 - x)e^{-x} = -(x^2 - 3x + 1)e^{-x}\). Simplify fully.

State average 1.3 / 2 (65%); 42% scored full marks.

Mark distribution: 0: 8% · 1: 50% · 2: 42%

  • \(f^{\prime}(x) = e^{2x}\left(\cos x + 2\sin x\right)\)
  • \(f^{\prime}\left(\frac{\pi}{4}\right) = \frac{3\sqrt2}{2}e^{\pi/2}\)

\(e^{\pi/2}\left(\frac{\sqrt2}{2} + \sqrt2\right) = \frac{3\sqrt2}{2}e^{\pi/2}\)

State average 1.6 / 2 (80%); 65% scored full marks.

Solve \(e^{2x} - 8e^x + 7 = 0\)

  • Factorises: \((e^x - 7)(e^x - 1) = 0\)
  • \(x = 0\) or \(x = \log_e 7\)

Treat as a quadratic in \(e^x\): \(x = 0, \log_e 7\).

State average 1.5 / 2 (75%); 61% scored full marks.

Mark distribution: 0: 14% · 1: 25% · 2: 61%

Largest \(a\) so that \(g\) restricted to \((-\infty, a]\) has an inverse

  • \(g^{\prime}(x) = 2e^{2x} - 8e^x = 2e^x(e^x - 4)\)
  • \(a = \log_e 4\)

The stationary point is at \(x = \log_e 4\), and \(g\) is one-to-one to the left of it, so \(a = \log_e 4\).

State average 1 / 2 (50%); 43% scored full marks.
