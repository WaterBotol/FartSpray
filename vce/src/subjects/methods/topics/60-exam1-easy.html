Questions (40 marks)

Answer all questions in the spaces provided. No calculators. In questions where more than one mark is available, appropriate working must be shown. Unless otherwise indicated, diagrams are not drawn to scale.

Let \(y = x^3 e^{2x}\). Find \(\dfrac{dy}{dx}\).

  • Product rule applied: \(3x^2e^{2x} + x^3 \cdot 2e^{2x}\)
  • Correct answer, e.g. \(x^2e^{2x}(3 + 2x)\)

\(\dfrac{dy}{dx} = 3x^2e^{2x} + 2x^3e^{2x} = x^2e^{2x}(2x + 3)\)

Forgetting the chain-rule factor 2 on \(e^{2x}\) was the most common slip.

Let \(f(x) = \sin(3x)\). Evaluate \(f'\!\left(\frac{\pi}{9}\right)\).

  • \(f'(x) = 3\cos(3x)\)
  • \(f'\!\left(\frac{\pi}{9}\right) = 3\cos\frac{\pi}{3} = \frac32\)

\(f'(x) = 3\cos(3x)\), so \(f'\!\left(\frac{\pi}{9}\right) = 3 \times \frac12 = \frac32\).

Find \(\displaystyle\int \left(6x^2 - \frac{2}{x}\right) dx\), for \(x > 0\).

  • \(2x^3\)
  • \(-2\ln x\) (constant of integration optional here)

\(2x^3 - 2\ln(x) + c\)

Evaluate \(\displaystyle\int_0^1 e^{2x}\, dx\).

  • Antiderivative \(\frac12 e^{2x}\)
  • \(\frac{e^2 - 1}{2}\)

\(\left[\frac12 e^{2x}\right]_0^1 = \frac12 e^2 - \frac12 = \frac{e^2 - 1}{2}\)

Many forgot that \(e^0 = 1\), not 0.

Solve \(e^{2x} - 5e^{x} + 6 = 0\) for \(x\).

  • Recognises a quadratic in \(e^x\): \((e^x - 2)(e^x - 3) = 0\)
  • \(e^x = 2\) or \(e^x = 3\)
  • \(x = \ln 2\) or \(x = \ln 3\)

Let \(u = e^x\): \(u^2 - 5u + 6 = 0\), so \(u = 2\) or \(3\). Therefore \(x = \ln 2\) or \(x = \ln 3\).

Solve \(\log_2(x) + \log_2(x - 2) = 3\) for \(x\).

  • \(x(x - 2) = 8\), so \(x^2 - 2x - 8 = 0\)
  • \(x = 4\) only (\(x = -2\) rejected, as the logs are undefined)

\(\log_2(x(x-2)) = 3\), so \(x^2 - 2x - 8 = 0\) and \((x - 4)(x + 2) = 0\). Since \(x > 2\) is needed, \(x = 4\).

Leaving in \(x = -2\) cost a mark. Always check the domain of a log.

Solve \(2\sin(x) = \sqrt{3}\) for \(x \in [0, 2\pi]\).

  • Reference angle \(\frac{\pi}{3}\)
  • \(x = \frac{\pi}{3}, \frac{2\pi}{3}\)

\(\sin x = \frac{\sqrt3}{2}\), which is positive in quadrants 1 and 2: \(x = \frac{\pi}{3}\) or \(\frac{2\pi}{3}\).

For \(y = 3\cos(2x) + 1\), state the amplitude, the period and the range.

  • Amplitude 3, period \(\pi\)
  • Range \([-2, 4]\)

Amplitude 3; period \(\frac{2\pi}{2} = \pi\); range \([1 - 3, 1 + 3] = [-2, 4]\).

Let \(f(x) = 2x + 1\) and \(g(x) = x^2\), both with domain \(\mathbb{R}\).

Find \(g(f(x))\).

  • \((2x + 1)^2\)

\(g(f(x)) = (2x + 1)^2\)

Find \(f^{-1}(x)\).

  • \(f^{-1}(x) = \frac{x - 1}{2}\)

Swap \(x\) and \(y\): \(x = 2y + 1\), so \(f^{-1}(x) = \frac{x - 1}{2}\).

Let \(h: [0, \infty) \to \mathbb{R}\), \(h(x) = \sqrt{x} + 2\). Find the rule and domain of \(h^{-1}\).

  • Rule: \(h^{-1}(x) = (x - 2)^2\)
  • Domain \([2, \infty)\) (the range of \(h\))

\(x = \sqrt y + 2\), so \(y = (x - 2)^2\). The domain of \(h^{-1}\) is the range of \(h\): \([2, \infty)\).

The rule alone earned only 1 mark. The domain of the inverse is the range of the original function, and it was missing from more than half the scripts.

Let \(f(x) = x^3 - 3x^2 + 2\).

Find the coordinates of the stationary points of the graph of \(f\), and state their nature.

  • \(f'(x) = 3x^2 - 6x = 3x(x - 2)\)
  • Stationary points at \((0, 2)\) and \((2, -2)\)
  • \((0, 2)\) local maximum, \((2, -2)\) local minimum (sign diagram or shape of positive cubic)

\(f'(x) = 3x(x - 2) = 0\) gives \(x = 0\) or \(2\). \(f(0) = 2\) and \(f(2) = -2\). For a positive cubic, \((0, 2)\) is a local maximum and \((2, -2)\) is a local minimum.

Find the equation of the tangent to the graph of \(f\) at \(x = 1\).

  • \(f(1) = 0\) and \(f'(1) = -3\)
  • \(y = -3x + 3\)

\(y - 0 = -3(x - 1)\), so \(y = -3x + 3\).

A discrete random variable \(X\) has \(\Pr(X = 0) = 0.2\), \(\Pr(X = 1) = 0.5\) and \(\Pr(X = 2) = k\).

Find \(k\).

  • \(k = 0.3\)

The probabilities sum to 1: \(k = 1 - 0.7 = 0.3\).

Find \(\text{E}(X)\).

  • \(1.1\)

\(0(0.2) + 1(0.5) + 2(0.3) = 1.1\)

Find \(\text{Var}(X)\).

  • \(\text{E}(X^2) = 0.5 + 1.2 = 1.7\)
  • \(\text{Var}(X) = 1.7 - 1.1^2 = 0.49\)

\(\text{Var}(X) = \text{E}(X^2) - [\text{E}(X)]^2 = 1.7 - 1.21 = 0.49\)

Squaring the probabilities instead of the values of \(X\) was a common error.

Two independent observations of \(X\) are made. Find the probability that their sum is 1.

  • \(2 \times 0.2 \times 0.5 = 0.2\)

Sum = 1 means (0, 1) or (1, 0): \(2 \times 0.2 \times 0.5 = 0.2\).

For events \(A\) and \(B\), \(\Pr(A) = 0.4\), \(\Pr(B) = 0.5\) and \(\Pr(A \cap B) = 0.2\).

Find \(\Pr(A \cup B)\).

  • \(0.7\)

\(0.4 + 0.5 - 0.2 = 0.7\)

Are \(A\) and \(B\) independent? Justify your answer.

  • Yes: \(\Pr(A)\Pr(B) = 0.2 = \Pr(A \cap B)\)

Yes, because \(\Pr(A)\Pr(B) = 0.4 \times 0.5 = 0.2 = \Pr(A \cap B)\).

Find \(\Pr(A \mid B')\).

  • \(\Pr(A \cap B') = 0.4 - 0.2 = 0.2\) and \(\Pr(B') = 0.5\)
  • \(0.4\)

\(\Pr(A \mid B') = \frac{0.2}{0.5} = 0.4\). This equals \(\Pr(A)\), as expected for independent events.

A continuous random variable \(X\) has probability density function \(f(x) = kx\) for \(0 \le x \le 2\), and \(f(x) = 0\) elsewhere.

Show that \(k = \frac12\).

  • \(\int_0^2 kx\,dx = 1\)
  • \(2k = 1\), so \(k = \frac12\)

\(\left[\frac{kx^2}{2}\right]_0^2 = 2k = 1\), so \(k = \frac12\).

A “show that” needs the equation set up and solved. Stating \(k = \frac12\) with no working scores 0.

Find \(\Pr(X < 1)\).

  • \(\frac14\)

\(\int_0^1 \frac{x}{2}\,dx = \frac14\)

Find \(\text{E}(X)\).

  • \(\int_0^2 x \cdot \frac{x}{2}\,dx\)
  • \(\frac43\)

\(\int_0^2 \frac{x^2}{2}\,dx = \left[\frac{x^3}{6}\right]_0^2 = \frac86 = \frac43\)

Assessor’s report

General comments

This paper covered the core Exam 1 skills at a gentler level than VCAA. Every question was a standard routine: product rule, chain rule, a hidden quadratic, a log equation with a domain check, an inverse with its domain, stationary points, a DRV table and a simple pdf. Students who wrote each step clearly lost very few marks.

Where marks were lost

  • Domains. Rejecting \(x = -2\) in the log equation (3b) and giving the domain of \(h^{-1}\) (5c) accounted for more lost marks than any calculus.
  • Chain-rule factors. \(\frac{d}{dx}e^{2x} = 2e^{2x}\) and \(\frac{d}{dx}\sin 3x = 3\cos 3x\). Forgetting the inner derivative is the most common Exam 1 error every year.
  • Exact values. \(\cos\frac{\pi}{3} = \frac12\), \(e^0 = 1\). Know the unit circle cold.
  • “Show that” questions. The given answer is worth nothing on its own. Show the integral set equal to 1.
  • Stating the nature. Stationary points need a reason for the nature: a sign diagram, the second derivative or the cubic’s shape.

Advice

Aim for 34/40 or more. Exam 1 rewards speed and accuracy on routines, so if you ran out of time, drill differentiation and exact values until they are automatic, then try the medium paper.
