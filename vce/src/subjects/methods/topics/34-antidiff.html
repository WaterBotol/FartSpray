Standard antiderivatives

Antidifferentiation reverses differentiation: if \(F'(x) = f(x)\) then \(\int f(x)\,dx = F(x) + c\).

\(f(x)\)\(\int f(x)\,dx\)\(f(x)\)\(\int f(x)\,dx\)
\(x^n,\ n \ne -1\)\(\dfrac{x^{n+1}}{n + 1} + c\)\(e^{kx}\)\(\dfrac1k e^{kx} + c\)
\((ax + b)^n,\ n \ne -1\)\(\dfrac{(ax + b)^{n+1}}{a(n + 1)} + c\)\(\sin(kx)\)\(-\dfrac1k\cos(kx) + c\)
\(\dfrac1x\)\(\log_e|x| + c\)\(\cos(kx)\)\(\dfrac1k\sin(kx) + c\)
\(\dfrac{1}{ax + b}\)\(\dfrac1a\log_e|ax + b| + c\)\(\dfrac{1}{\cos^2(kx)}\)\(\dfrac1k\tan(kx) + c\)

Linear inside, divide by the coefficient of \(x\). That's the reverse chain rule, and it only works when the inside is linear. \(\int e^{x^2}\,dx\) is not \(\frac{e^{x^2}}{2x}\).

Find \(\displaystyle\int\left(6x^2 - \frac{4}{x^3} + \frac{2}{2x + 1} + e^{-3x}\right)dx\).

Antidifferentiate term by term. Rewrite powers of \(x\) in the denominator as negative powers first. Linear inside functions (\(ax + b\) or \(kx\)) divide by the coefficient of \(x\).

Term by term: \(2x^3\); \(-4\cdot\frac{x^{-2}}{-2} = \frac{2}{x^2}\); \(\frac{2}{2}\log_e|2x + 1| = \log_e|2x + 1|\); \(-\frac13e^{-3x}\).

\(2x^3 + \dfrac{2}{x^2} + \log_e|2x + 1| - \dfrac13e^{-3x} + c\).

\(f'(x) = 3x^2 - 4x + 1\) and \(f(1) = 2\). Find \(f(x)\).

Antidifferentiating gives a whole family of curves (the \(+c\)). A known point on the curve picks out the one you want.

\(f(x) = x^3 - 2x^2 + x + c\).

\(f(1) = 1 - 2 + 1 + c = 2 \Rightarrow c = 2\). \(f(x) = x^3 - 2x^2 + x + 2\).

The gradient of a curve is \(\dfrac{dy}{dx} = 2\cos(2x) + \sin x\), and the curve passes through \(\left(\frac{\pi}{2}, 3\right)\). Find \(y\).

Antidifferentiate each trig term, then use the given point to find \(c\). Remember that \(\sin\) goes to \(-\cos\), and that the inside coefficient divides.

\(y = \sin(2x) - \cos x + c\).

\(3 = \sin\pi - \cos\frac{\pi}{2} + c = 0 - 0 + c\).

\(y = \sin(2x) - \cos x + 3\).

Antidifferentiation by recognition

This is an Exam 1 staple: “Differentiate \(g(x)\). Hence find an antiderivative of \(h(x)\).” Differentiate, rearrange so the thing you want is on its own, then antidifferentiate both sides.

Find \(\dfrac{d}{dx}(x\log_e x)\). Hence find \(\displaystyle\int\log_e x\,dx\).

“Hence” questions use antidifferentiation by recognition: if you know \(\frac{d}{dx}F(x) = f(x) + g(x)\), then integrating both sides gives \(F(x) = \int f + \int g\). Rearrange for the integral you want.

Product rule: \(\dfrac{d}{dx}(x\log_e x) = \log_e x + x\cdot\dfrac1x = \log_e x + 1\).

Antidifferentiate both sides: \(x\log_e x = \int\log_e x\,dx + \int 1\,dx\).

\(\displaystyle\int\log_e x\,dx = x\log_e x - x + c\).

Differentiate \(x\sin x\) and hence find an antiderivative of \(x\cos x\).

Differentiate the given function, rearrange so the integrand is on its own, then integrate both sides. The derivative term integrates straight back to the original function.

\(\dfrac{d}{dx}(x\sin x) = \sin x + x\cos x\), so \(x\cos x = \dfrac{d}{dx}(x\sin x) - \sin x\).

\(\displaystyle\int x\cos x\,dx = x\sin x - \int\sin x\,dx = \boldsymbol{x\sin x + \cos x}\) (plus \(c\) if they ask for the general antiderivative).

Graphs of antiderivatives

If you're given the graph of \(f\) and asked to sketch \(F\) (where \(F' = f\)): where \(f\) is positive, \(F\) increases; where \(f\) crosses the axis, \(F\) has a stationary point; turning points of \(f\) are inflection points of \(F\). There's a whole family of possible \(F\) graphs, each a vertical translation of the others.

  • \(\int\frac{1}{x}\,dx \ne \frac{x^0}{0}\). The power rule excludes \(n = -1\); use \(\log_e|x|\).
  • Sign flip for sine: \(\int\sin x\,dx = -\cos x + c\).
  • \(\int\frac{1}{3x}\,dx = \frac13\log_e|x| + c\), which equals \(\frac13\log_e|3x| + c'\): both are correct (the constants differ).
  • Don't forget \(+c\) when a question asks for “the general antiderivative” or “\(\int\ldots dx\)”. When it asks for “an antiderivative”, \(c = 0\) is fine.

Practice

An antiderivative of \(\dfrac{1}{(2x - 1)^3}\) is

  1. \(-\dfrac{1}{4(2x - 1)^2}\)
  2. \(-\dfrac{1}{2(2x - 1)^2}\)
  3. \(\dfrac{1}{4(2x - 1)^4}\)
  4. \(\dfrac{\log_e|2x - 1|}{2}\)

\(\int(2x - 1)^{-3}dx = \frac{(2x - 1)^{-2}}{2\times(-2)} = -\frac{1}{4(2x - 1)^2}\).

\(\displaystyle\int\sin(3x)\,dx\) equals

  1. \(3\cos(3x) + c\)
  2. \(\frac13\cos(3x) + c\)
  3. \(-\frac13\cos(3x) + c\)
  4. \(-3\cos(3x) + c\)

Divide by the coefficient 3 and remember the negative sign.

Which of the following is an antiderivative of \(\dfrac{1}{5x}\), \(x > 0\)?

  1. \(5\log_e x\)
  2. \(\log_e(5x)\)
  3. \(\frac15\log_e(x^5)\)
  4. \(\frac15\log_e(5x)\)

\(\frac{d}{dx}\left[\frac15\log_e(5x)\right] = \frac15\cdot\frac1x = \frac{1}{5x}\) ✓. Option C simplifies to \(\log_e x\) (derivative \(\frac1x\)) ✗. Option B has derivative \(\frac1x\) ✗.

If \(f'(x) = e^{2x}\) and \(f(0) = 1\), then \(f(x)\) is

  1. \(e^{2x}\)
  2. \(\frac12e^{2x} + \frac12\)
  3. \(2e^{2x} - 1\)
  4. \(\frac12e^{2x} + 1\)

\(f(x) = \frac12e^{2x} + c\); \(\frac12 + c = 1 \Rightarrow c = \frac12\).

Given \(\dfrac{d}{dx}\big(xe^{2x}\big) = e^{2x} + 2xe^{2x}\), an antiderivative of \(xe^{2x}\) is

  1. \(\frac12xe^{2x} - \frac14e^{2x}\)
  2. \(\frac12xe^{2x} - \frac12e^{2x}\)
  3. \(xe^{2x} - e^{2x}\)
  4. \(\frac12x^2e^{2x}\)

\(2xe^{2x} = \frac{d}{dx}(xe^{2x}) - e^{2x}\), so \(\int 2xe^{2x}dx = xe^{2x} - \frac12e^{2x}\). Halve it: \(\frac12xe^{2x} - \frac14e^{2x}\).

A student claims \(\displaystyle\int e^{x^2}dx = \frac{e^{x^2}}{2x} + c\). Differentiating their answer gives

  1. \(e^{x^2}\), so they are right
  2. \(2xe^{x^2}\)
  3. something other than \(e^{x^2}\), so they are wrong
  4. 0

Quotient rule on \(\frac{e^{x^2}}{2x}\) gives \(e^{x^2} - \frac{e^{x^2}}{2x^2}\), not \(e^{x^2}\). The reverse chain rule only works for linear insides. (\(e^{x^2}\) has no elementary antiderivative.)

Find \(\displaystyle\int\left(\sqrt{x} + \frac{3}{x}\right)dx\) for \(x > 0\).

\(\frac23x^{3/2} + 3\log_e x + c\).

The gradient of a curve is \(4 - 2x\) and it passes through \((1, 5)\). Find its equation.

\(y = 4x - x^2 + c\); \(5 = 4 - 1 + c \Rightarrow c = 2\). \(y = -x^2 + 4x + 2\).

Let \(f(x) = x^2\log_e x\). Find \(f'(x)\) and hence find \(\displaystyle\int x\log_e x\,dx\).

\(f'(x) = 2x\log_e x + x\). [1]

So \(2x\log_e x = f'(x) - x\), giving \(\int 2x\log_e x\,dx = x^2\log_e x - \frac{x^2}{2}\). [1]

\(\int x\log_e x\,dx = \frac12x^2\log_e x - \frac14x^2 + c\). [1]

The rate at which water flows into a tank is \(\dfrac{dV}{dt} = 20 - 10e^{-0.5t}\) litres per minute. The tank initially holds 50 L. Find \(V(t)\) and the volume after 4 minutes, correct to one decimal place.

\(V = 20t + 20e^{-0.5t} + c\). [1]

\(V(0) = 20 + c = 50 \Rightarrow c = 30\). \(V(t) = 20t + 20e^{-0.5t} + 30\). [1]

\(V(4) = 80 + 20e^{-2} + 30 \approx 112.7\) L. [1]

Summary

  • Reverse each derivative rule; with a linear inside, divide by its coefficient.
  • \(\int\frac1x\,dx = \log_e|x| + c\); \(\int\sin x\,dx = -\cos x + c\).
  • Use a known point to find \(c\).
  • “Hence” questions: differentiate, rearrange, antidifferentiate.
