Combining functions

For \(f + g\), \(f - g\) and \(f \times g\), the domain is the intersection of the two domains: \(\text{dom}(f + g) = \text{dom} f \cap \text{dom} g\). To sketch \(y = f(x) + g(x)\) by addition of ordinates, add the heights of the two graphs at key \(x\)-values (intercepts, asymptotes, where one graph is zero).

Composite functions

Composite
\[ (f \circ g)(x) = f\big(g(x)\big) \]

\(f \circ g\) exists if and only if \(\text{ran}\, g \subseteq \text{dom}\, f\). Then \(\text{dom}(f \circ g) = \text{dom}\, g\).

Think of \(g\) as the first machine and \(f\) as the second. Every output of \(g\) must be an acceptable input for \(f\). If it isn't, restrict the domain of \(g\) until it is.

Let \(f(x) = \sqrt{x}\) (maximal domain) and \(g: \mathbb{R} \to \mathbb{R},\ g(x) = x^2 - 4\). (a) Explain why \(f \circ g\) does not exist. (b) Find the maximal domain of \(g\) for which \(f \circ g\) exists. (c) Does \(g \circ f\) exist? If so, state its rule and domain.

\(f \circ g\) means apply \(g\) first, so every output of \(g\) must be a valid input for \(f\): the range of \(g\) must fit inside the domain of \(f\).

(a) \(\text{ran}\, g = [-4, \infty)\) but \(\text{dom}\, f = [0, \infty)\). Since \([-4, \infty) \not\subseteq [0, \infty)\), \(f \circ g\) does not exist.

(b) Need \(g(x) \ge 0\): \(x^2 \ge 4 \Rightarrow x \le -2\) or \(x \ge 2\).

(c) \(\text{ran}\, f = [0, \infty) \subseteq \mathbb{R} = \text{dom}\, g\), so yes. \(g(f(x)) = (\sqrt{x})^2 - 4 = x - 4\), with domain \(= \text{dom}\, f = [0, \infty)\).

(b) \((-\infty, -2] \cup [2, \infty)\). (c) \(g \circ f(x) = x - 4\), domain \([0, \infty)\). It's not the whole line \(y = x - 4\): it's only the part with \(x \ge 0\).

Inverse functions

Only one-to-one functions have inverse functions. To find \(f^{-1}\): swap \(x\) and \(y\), make \(y\) the subject, and pick the correct branch using the range of \(f^{-1}\).

Inverse facts
\[ \text{dom}\, f^{-1} = \text{ran}\, f \qquad \text{ran}\, f^{-1} = \text{dom}\, f \qquad f\big(f^{-1}(x)\big) = x \]

The graph of \(f^{-1}\) is the reflection of \(f\) in the line \(y = x\).

Let \(f: (-\infty, a] \to \mathbb{R},\ f(x) = (x - 2)^2 - 3\). (a) Find the largest value of \(a\) for which \(f^{-1}\) exists. (b) With this \(a\), find \(f^{-1}\) and its domain.

Only one-to-one functions have inverses, so a parabola must be restricted to one side of its turning point. The inverse's range is the original domain, which tells you which square root to keep.

(a) The turning point is at \(x = 2\). To the left of it, \(f\) is one-to-one (decreasing). So \(a = 2\).

(b) Swap: \(x = (y - 2)^2 - 3 \Rightarrow (y - 2)^2 = x + 3 \Rightarrow y - 2 = \pm\sqrt{x + 3}\).

The range of \(f^{-1}\) is the domain of \(f\): \(y \le 2\). So take the negative root.

\(a = 2\); \(f^{-1}(x) = 2 - \sqrt{x + 3}\), domain \([-3, \infty)\) (the range of \(f\)).

Where does a function meet its inverse?

If \(f\) is increasing, every intersection of \(y = f(x)\) and \(y = f^{-1}(x)\) lies on \(y = x\), so you can solve \(f(x) = x\) instead. That's much easier.

Find all points of intersection of \(f(x) = 1 - x^3\) and \(y = f^{-1}(x)\).

An increasing function meets its inverse only on \(y = x\). A decreasing function can also meet it at pairs of points swapped across \(y = x\), where \(f(a) = b\) and \(f(b) = a\).

Solving \(f(x) = x\): \(1 - x^3 = x\), which has one real solution \(x \approx 0.682\). That's one point, \((0.682, 0.682)\).

But \(f\) is decreasing, so there can be intersections off the line \(y = x\). Look for pairs with \(f(a) = b\) and \(f(b) = a\): \(f(0) = 1\) and \(f(1) = 0\).

Three points: \((0, 1)\), \((1, 0)\) and \((0.682, 0.682)\) (to 3 d.p.). Here \(f^{-1}(x) = \sqrt[3]{1 - x}\), and a CAS solve of \(f(x) = f^{-1}(x)\) confirms all three.

  • \(f^{-1}(x) \ne \frac{1}{f(x)}\). The inverse undoes \(f\); the reciprocal is something else.
  • The domain of a composite comes from the inner function, even if the simplified rule looks as if it's defined everywhere.
  • Check that the range fits inside the domain, value by value. For \(f(x) = \frac{1}{x - 1}\) and \(g(x) = x^2 + 1\), \(\text{ran}\, g = [1, \infty)\) includes 1, which isn't in \(\text{dom}\, f\). So \(f \circ g\) doesn't exist on \(\mathbb{R}\).
  • Choose the right branch when you take a square root, using the range of the inverse.

Practice

If \(f(x) = 2x + 1\) and \(g(x) = x^2\), then \(g(f(x))\) is

  1. \(2x^2 + 1\)
  2. \(2x^2 + 2x\)
  3. \((2x + 1)^2\)
  4. \(4x^2 + 1\)

Apply \(f\) first, then square: \((2x + 1)^2\). A is \(f(g(x))\).

\(f(x) = \log_e x\) and \(g: D \to \mathbb{R},\ g(x) = x - 3\). The largest set \(D\) for which \(f \circ g\) exists is

  1. \(\mathbb{R}\)
  2. \((3, \infty)\)
  3. \([3, \infty)\)
  4. \((0, \infty)\)

Need \(g(x) > 0\), so \(x > 3\).

The inverse of \(f: [0, \infty) \to \mathbb{R},\ f(x) = x^2 + 1\) is

  1. \(f^{-1}: [1, \infty) \to \mathbb{R},\ f^{-1}(x) = \sqrt{x - 1}\)
  2. \(f^{-1}: [0, \infty) \to \mathbb{R},\ f^{-1}(x) = \sqrt{x - 1}\)
  3. \(f^{-1}: [1, \infty) \to \mathbb{R},\ f^{-1}(x) = -\sqrt{x - 1}\)
  4. \(f^{-1}: \mathbb{R} \to \mathbb{R},\ f^{-1}(x) = \frac{1}{x^2 + 1}\)

The domain of \(f^{-1}\) is \(\text{ran}\, f = [1, \infty)\); its range must be \([0, \infty)\), so take the positive root.

The number of points where \(y = 1 - x^3\) meets the graph of its inverse is

  1. 0
  2. 1
  3. 2
  4. 3

One on \(y = x\) (at \(x \approx 0.682\)) plus \((0, 1)\) and \((1, 0)\). Decreasing functions can meet their inverses off the line \(y = x\).

For \(f(x) = x^2 - 4x + 1\), the smallest value of \(a\) for which \(f: [a, \infty) \to \mathbb{R}\) has an inverse function is

  1. 0
  2. \(-3\)
  3. 2
  4. 4

The vertex is at \(x = 2\). Any \(a \ge 2\) works, and the smallest is 2.

If \(f(x) = e^{2x}\) and \(g(x) = \log_e x\), then \(f(g(x))\) equals

  1. \(2x\) for all \(x \in \mathbb{R}\)
  2. \(x^2\) for \(x > 0\)
  3. \(x^2\) for all \(x \in \mathbb{R}\)
  4. \(2\log_e x\) for \(x > 0\)

\(e^{2\log_e x} = e^{\log_e x^2} = x^2\), with the domain of \(g\): \(x > 0\).

\(f(x) = \dfrac{1}{x - 1}\) (maximal domain) and \(g: \mathbb{R} \to \mathbb{R},\ g(x) = x^2 + 1\). Which statement is true?

  1. \(g \circ f\) exists but \(f \circ g\) does not
  2. \(f \circ g\) exists but \(g \circ f\) does not
  3. Both exist
  4. Neither exists

\(\text{ran}\, f = \mathbb{R}\setminus\{0\} \subseteq \mathbb{R}\), so \(g \circ f\) exists. \(\text{ran}\, g = [1, \infty)\) contains 1, which isn't in \(\text{dom}\, f\), so \(f \circ g\) doesn't exist (\(g(0) = 1\) would give \(\frac10\)).

Find the inverse of \(f(x) = \dfrac{2x + 1}{x - 3}\), stating its domain.

Rewrite: \(f(x) = 2 + \dfrac{7}{x - 3}\), so \(\text{ran}\, f = \mathbb{R}\setminus\{2\}\).

Swap: \(x = 2 + \dfrac{7}{y - 3} \Rightarrow y - 3 = \dfrac{7}{x - 2}\).

\(f^{-1}(x) = 3 + \dfrac{7}{x - 2}\), domain \(\mathbb{R}\setminus\{2\}\).

Let \(f: [2, \infty) \to \mathbb{R},\ f(x) = x^2 - 4x + 1\). Find the exact coordinates of the point where \(y = f(x)\) meets \(y = f^{-1}(x)\).

\(f\) is increasing on \([2, \infty)\), so intersections lie on \(y = x\). [1]

\(x^2 - 4x + 1 = x \Rightarrow x^2 - 5x + 1 = 0 \Rightarrow x = \frac{5 \pm \sqrt{21}}{2}\). [1]

Only \(\frac{5 + \sqrt{21}}{2} \approx 4.79\) is in \([2, \infty)\). Point \(\left(\frac{5 + \sqrt{21}}{2}, \frac{5 + \sqrt{21}}{2}\right)\). [1]

Let \(f(x) = e^{x} - 2\) and \(g(x) = \log_e(x + 3)\), each with maximal domain. (a) Show that \(g \circ f\) exists and find its rule. (b) Explain why \(f \circ g\) exists and find its rule and domain.

(a) \(\text{ran}\, f = (-2, \infty)\) and \(\text{dom}\, g = (-3, \infty)\). Since \((-2, \infty) \subseteq (-3, \infty)\), \(g \circ f\) exists. \(g(f(x)) = \log_e(e^x + 1)\), domain \(\mathbb{R}\). [2]

(b) \(\text{ran}\, g = \mathbb{R} = \text{dom}\, f\), so \(f \circ g\) exists. \(f(g(x)) = e^{\log_e(x + 3)} - 2 = x + 1\), domain \((-3, \infty)\). [2]

Show that \(f(x) = \dfrac{x + 3}{x - 1}\) is its own inverse. What does this mean for its graph?

\(f(f(x)) = \dfrac{\frac{x + 3}{x - 1} + 3}{\frac{x + 3}{x - 1} - 1} = \dfrac{x + 3 + 3x - 3}{x + 3 - x + 1} = \dfrac{4x}{4} = x\). So \(f^{-1} = f\).

The graph is symmetric about the line \(y = x\).

Summary

  • \(f \circ g\) exists iff \(\text{ran}\, g \subseteq \text{dom}\, f\); \(\text{dom}(f \circ g) = \text{dom}\, g\).
  • Inverse: one-to-one first; swap, solve, choose the branch; domain and range swap.
  • Increasing \(f\): solve \(f(x) = x\) for intersections with \(f^{-1}\). Decreasing \(f\): check for points off \(y = x\).
