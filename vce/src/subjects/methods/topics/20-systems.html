Two linear equations, two unknowns

Two lines in the plane either cross once (unique solution), are parallel (no solution) or are the same line (infinitely many solutions).

The parameter test
\[ \begin{aligned} ax + by &= e \\ cx + dy &= f \end{aligned} \qquad \text{unique solution} \iff ad - bc \ne 0 \]

If \(ad - bc = 0\) the lines have the same gradient. Then check the constants: if one equation is a multiple of the other, there are infinitely many solutions; otherwise there are none.

\(ad - bc\) is the determinant of the coefficient matrix \(\begin{bmatrix} a & b \\ c & d \end{bmatrix}\). You don't need matrix theory. Just remember “unique ⇔ determinant ≠ 0”, then test the special values by substituting them back in.

Consider \(\begin{aligned} ax + 3y &= 3 \\ x + (a - 2)y &= 1 \end{aligned}\). Find the values of \(a\) for which the system has (a) a unique solution, (b) no solution, (c) infinitely many solutions.

Two linear equations have a unique solution unless their lines are parallel (determinant zero). Then they're either the same line (infinitely many solutions) or distinct parallel lines (no solution).

Determinant: \(a(a - 2) - 3 \cdot 1 = a^2 - 2a - 3 = (a - 3)(a + 1)\). Zero when \(a = 3\) or \(a = -1\).

\(a = 3\): \(3x + 3y = 3\) and \(x + y = 1\). The first is 3 × the second, so they're the same line: infinitely many solutions.

\(a = -1\): \(-x + 3y = 3\) and \(x - 3y = 1\), i.e. \(x - 3y = -3\) and \(x - 3y = 1\). Parallel, different lines: no solution.

(a) \(a \in \mathbb{R}\setminus\{-1, 3\}\); (b) \(a = -1\); (c) \(a = 3\).

Three equations, three unknowns

Use elimination to reduce to two equations in two unknowns, or use CAS in Exam 2 (solve the three equations together). Geometrically each equation is a plane; they may meet at a point, along a line (infinitely many solutions) or not at all.

Solve \(\ x + y + z = 6,\quad 2x - y + z = 3,\quad x + 2y - z = 2\).

Eliminate one variable at a time by adding or subtracting equations, reducing a 3 × 3 system to 2 × 2 and then to one equation.

Add equations 1 and 3: \(2x + 3y = 8\). Add equations 2 and 3: \(3x + y = 5\).

From \(3x + y = 5\): \(y = 5 - 3x\). Substitute: \(2x + 15 - 9x = 8 \Rightarrow x = 1\), so \(y = 2\).

Then \(z = 6 - 1 - 2 = 3\). \((x, y, z) = (1, 2, 3)\). Check in equation 2: \(2 - 2 + 3 = 3\). ✓

For the system \(\ x + y + z = 1,\quad x + 2y + 3z = 2,\quad x + 4y + kz = c\): (a) find \(k\) for which there is no unique solution; (b) for that \(k\), find \(c\) so there are infinitely many solutions and give them in terms of a parameter.

Elimination reduces the system. If two reduced equations have identical left sides, the system has no unique solution: infinitely many if the right sides also agree, none if they don't.

(a) Subtract: (2) − (1) gives \(y + 2z = 1\); (3) − (1) gives \(3y + (k - 1)z = c - 1\).

Triple the first: \(3y + 6z = 3\). The two equations have the same left side when \(k - 1 = 6\), i.e. \(k = 7\).

(b) With \(k = 7\): infinitely many solutions need \(c - 1 = 3\), so \(c = 4\) (otherwise no solution). Let \(z = t\): \(y = 1 - 2t\), \(x = 1 - y - z = t\).

(a) \(k = 7\). (b) \(c = 4\); \((x, y, z) = (t,\ 1 - 2t,\ t),\ t \in \mathbb{R}\).

Lines meeting curves: the discriminant

Substitute the line into the curve to get a quadratic. Its discriminant \(\Delta = b^2 - 4ac\) counts the intersections: \(\Delta > 0\) two, \(\Delta = 0\) one (the line is a tangent), \(\Delta < 0\) none.

Find the values of \(m\) for which the line \(y = mx + 1\) is a tangent to \(y = x^2 + 2x + 2\).

A line meets a parabola where their equations are equal. A tangent touches at exactly one point, so the resulting quadratic has a discriminant of zero.

Equate: \(x^2 + 2x + 2 = mx + 1 \Rightarrow x^2 + (2 - m)x + 1 = 0\).

Tangent ⇔ \(\Delta = 0\): \((2 - m)^2 - 4 = 0 \Rightarrow 2 - m = \pm2\).

\(m = 0\) or \(m = 4\). (Check \(m = 0\): the line \(y = 1\) touches the parabola's vertex at \((-1, 1)\). ✓)

Literal equations

A literal equation has letters as well as the unknown: solve \(ax + b = cx + d\) for \(x\) to get \(x = \frac{d - b}{a - c}\), provided \(a \ne c\). Always state the restriction: that's where the marks for “consider all cases” are.

  • Determinant = 0 doesn't tell you which case you're in. Substitute each value back and test for “same line” vs “parallel”.
  • Dividing by an expression containing a parameter silently assumes it isn't 0. Handle that value separately.
  • “At least one solution” means unique or infinitely many, so it includes the coincident case.
  • For \(x^2\)-coefficient parameters (e.g. \(kx^2 + 4x + 1 = 0\)), check \(k = 0\) separately: the equation becomes linear and has exactly one solution.

Practice

The system \(\ mx + 4y = 8,\quad x + my = 4\ \) has infinitely many solutions when

  1. \(m = -2\)
  2. \(m = \pm2\)
  3. \(m = 2\)
  4. \(m = 4\)

Determinant \(m^2 - 4 = 0 \Rightarrow m = \pm2\). \(m = 2\): \(2x + 4y = 8\) is 2 × \((x + 2y = 4)\), the same line. \(m = -2\): \(-2x + 4y = 8\) and \(x - 2y = 4\), i.e. \(x - 2y = -4\) and \(x - 2y = 4\), parallel (no solution).

The equation \(kx^2 + 4x + 1 = 0\) has exactly one real solution for

  1. \(k = 0\) or \(k = 4\)
  2. \(k = 4\) only
  3. \(k = \pm4\)
  4. \(k < 4\)

Quadratic case: \(\Delta = 16 - 4k = 0 \Rightarrow k = 4\). But when \(k = 0\) the equation is \(4x + 1 = 0\), which also has exactly one solution.

The line \(y = x + c\) does not meet the parabola \(y = x^2\) when

  1. \(c > -\frac14\)
  2. \(c < -\frac14\)
  3. \(c = -\frac14\)
  4. \(c < \frac14\)

\(x^2 - x - c = 0\): \(\Delta = 1 + 4c < 0 \Rightarrow c < -\frac14\).

Solving \(ax - 3 = 2x + b\) for \(x\) gives

  1. \(x = \frac{b + 3}{a + 2}\)
  2. \(x = \frac{b - 3}{a - 2}\)
  3. \(x = \frac{b + 3}{a - 2}\) for all \(a\)
  4. \(x = \frac{b + 3}{a - 2}\), \(a \ne 2\)

\((a - 2)x = b + 3\). Dividing requires \(a \ne 2\).

The system \(\ x + y + z = 1,\ x + 2y + 3z = 2,\ x + 4y + 7z = 5\ \) has

  1. a unique solution
  2. infinitely many solutions
  3. no solution
  4. exactly two solutions

Subtracting gives \(y + 2z = 1\) and \(3y + 6z = 4\), i.e. \(y + 2z = \frac43\): a contradiction. (With the last constant 4 instead of 5 there would be infinitely many.)

The values of \(k\) for which \(y = kx - 2\) meets \(y = x^2 + 2\) at two distinct points are

  1. \(k < -4\) or \(k > 4\)
  2. \(-4 < k < 4\)
  3. \(k = \pm4\)
  4. \(k > 4\) only

\(x^2 - kx + 4 = 0\): \(\Delta = k^2 - 16 > 0 \Rightarrow |k| > 4\).

Solve simultaneously: \(3x - 2y = 12\) and \(x + 4y = -10\).

Double the first: \(6x - 4y = 24\). Add to the second: \(7x = 14 \Rightarrow x = 2\). Then \(4y = -12 \Rightarrow y = -3\).

For what values of \(p\) does \(\ (p + 1)x + 2y = 4,\quad 3x + py = 6\ \) have no solution?

\(\det = p(p + 1) - 6 = p^2 + p - 6 = (p + 3)(p - 2) = 0 \Rightarrow p = -3\) or \(2\). [1]

\(p = 2\): \(3x + 2y = 4\) and \(3x + 2y = 6\): parallel, no solution. [1]

\(p = -3\): \(-2x + 2y = 4\) and \(3x - 3y = 6\), i.e. \(x - y = -2\) and \(x - y = 2\): also no solution. [1] Answer: \(p = -3\) or \(p = 2\).

Find the exact values of \(c\) for which the line \(y = 2x + c\) is a tangent to the curve \(y = \dfrac{1}{x}\), and give the points of contact.

\(\frac{1}{x} = 2x + c \Rightarrow 2x^2 + cx - 1 = 0\) (\(x \ne 0\)). [1]

\(\Delta = c^2 + 8 > 0\) always, so this line is never a tangent: it always cuts the hyperbola twice. [1]

Reason: \(\frac{dy}{dx} = -\frac{1}{x^2} < 0\), so no tangent to \(y = \frac1x\) can have a positive gradient. There are no such values of \(c\). [1]

A student says: “The determinant of \(\ 2x + 6y = 5,\ x + 3y = k\ \) is 0, so there is no solution.” Is that always true?

No. The determinant \(2 \cdot 3 - 6 \cdot 1 = 0\) only means the lines are parallel or coincident. If \(k = \frac52\), the second equation is half the first: infinitely many solutions. For \(k \ne \frac52\) there are none.

Summary

  • Unique solution ⇔ determinant ≠ 0. At determinant = 0, substitute and compare constants.
  • 3 × 3: eliminate to 2 × 2; a parameter family of solutions means planes share a line.
  • Line and curve: substitute, then use the discriminant.
  • Always handle “divide by zero” values of parameters separately.
