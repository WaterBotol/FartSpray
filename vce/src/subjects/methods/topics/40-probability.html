The core rules

Addition, conditional and multiplication rules
\[ P(A \cup B) = P(A) + P(B) - P(A \cap B) \qquad P(A') = 1 - P(A) \]\[ P(A \mid B) = \frac{P(A \cap B)}{P(B)} \qquad P(A \cap B) = P(A \mid B)\,P(B) \]

\(A\) and \(B\) can't both happen: \(P(A \cap B) = 0\), so \(P(A \cup B) = P(A) + P(B)\).

One happening doesn't change the other's probability: \(P(A \mid B) = P(A)\), or equivalently \(P(A \cap B) = P(A)P(B)\).

If \(A\) and \(B\) are mutually exclusive and both have non-zero probability, they're dependent: knowing \(A\) happened tells you \(B\) definitely didn't. \(P(A \cap B) = 0 \ne P(A)P(B)\).

Karnaugh maps (probability tables)

A 2 × 2 table with totals is the fastest tool when there are two events. Fill in what you know; every row and column must add up.

\(A\) and \(B\) are independent, \(P(A) = 0.4\) and \(P(A \cup B) = 0.7\). Find \(P(B)\).

\(P(A \cup B) = P(A) + P(B) - P(A)P(B)\): \(0.7 = 0.4 + p - 0.4p\).

\(0.6p = 0.3\), so \(P(B) = 0.5\).

Tree diagrams and the law of total probability

Law of total probability
\[ P(B) = P(B \mid A)P(A) + P(B \mid A')P(A') \]

Multiply along branches; add the branches that give the outcome you want.

2% of a population has a disease. A test gives a positive result for 95% of people with the disease and for 10% of people without it. A randomly chosen person tests positive. Find the probability that they have the disease, correct to four decimal places.

Tree: \(P(D \cap +) = 0.02 \times 0.95 = 0.019\); \(P(D' \cap +) = 0.98 \times 0.10 = 0.098\).

\(P(+) = 0.019 + 0.098 = 0.117\).

\(P(D \mid +) = \dfrac{P(D \cap +)}{P(+)} = \dfrac{0.019}{0.117}\).

\(\approx 0.1624\). Only about 16% of positives actually have the disease, because the disease is rare and the false positives swamp the true ones. This is the classic “reverse conditional” and the answer surprises most people.

A bag holds 5 red and 3 blue marbles. Two are drawn without replacement. Find the probability of getting one of each colour.

\(P(RB) + P(BR) = \frac58 \times \frac37 + \frac38 \times \frac57\).

\(= \frac{30}{56} = \frac{15}{28}\). Don't forget both orders.

  • \(P(A \mid B) \ne P(B \mid A)\) in general, as the disease example shows.
  • “Given” shrinks the sample space. Divide by the probability of the condition.
  • Independence must be checked with numbers, not intuition.
  • Without replacement: the second-draw probabilities change.

Practice

\(A\) and \(B\) are independent with \(P(A) = 0.3\) and \(P(B) = 0.5\). \(P(A \cup B)\) is

  1. 0.8
  2. 0.65
  3. 0.15
  4. 0.35

\(0.3 + 0.5 - 0.3 \times 0.5 = 0.65\). A would be correct if they were mutually exclusive.

\(A\) and \(B\) are mutually exclusive events with \(P(A) = 0.2\) and \(P(B) = 0.5\). Which statement is true?

  1. \(A\) and \(B\) are independent
  2. \(P(A \cap B) = 0.1\)
  3. \(P(A \mid B) = 0.2\)
  4. \(P(A \mid B) = 0\)

\(P(A \cap B) = 0\), so \(P(A \mid B) = \frac{0}{0.5} = 0\). They are not independent (\(0 \ne 0.1\)).

Two fair dice are rolled. Given that at least one shows a 6, the probability that the sum is 8 is

  1. \(\frac{2}{11}\)
  2. \(\frac{5}{36}\)
  3. \(\frac{1}{18}\)
  4. \(\frac{1}{6}\)

Outcomes with at least one 6: 11. Of these, sum 8: (2, 6) and (6, 2). So \(\frac{2}{11}\).

\(P(A) = 0.6\), \(P(B \mid A) = 0.5\) and \(P(B \mid A') = 0.25\). Then \(P(A \mid B)\) is

  1. 0.5
  2. 0.4
  3. 0.75
  4. 0.3

\(P(A \cap B) = 0.3\); \(P(A' \cap B) = 0.4 \times 0.25 = 0.1\); \(P(B) = 0.4\). \(P(A \mid B) = \frac{0.3}{0.4} = 0.75\).

If it rains one day, the probability it rains the next day is 0.6; if it doesn't rain, the probability of rain the next day is 0.2. It rains on Monday. The probability it rains on Wednesday is

  1. 0.36
  2. 0.44
  3. 0.6
  4. 0.52

Tuesday rain then Wednesday rain: \(0.6 \times 0.6 = 0.36\). Tuesday dry then Wednesday rain: \(0.4 \times 0.2 = 0.08\). Total 0.44.

If \(P(A \mid B) = 0.4\) and \(P(B) = 0.5\), then \(P(A \cap B)\) is

  1. 0.2
  2. 0.8
  3. 0.9
  4. 0.1

\(P(A \cap B) = P(A \mid B)P(B) = 0.2\).

\(P(A) = 0.5\), \(P(B) = 0.4\), \(P(A \cap B) = 0.2\). Which is true?

  1. \(A\) and \(B\) are mutually exclusive
  2. \(P(A \mid B') = 0.3\)
  3. \(A\) and \(B'\) are independent
  4. \(P(A \cup B) = 0.9\)

\(0.5 \times 0.4 = 0.2\), so \(A, B\) are independent, which means \(A, B'\) are too: \(P(A \cap B') = 0.3 = 0.5 \times 0.6\) ✓. \(P(A \mid B') = \frac{0.3}{0.6} = 0.5\), and \(P(A \cup B) = 0.7\).

A class has 30 students: 18 study Chemistry, 12 study Biology and 5 study both. A student is chosen at random. Find the probability that they study Biology given that they study Chemistry.

\(P(B \mid C) = \frac{5}{18}\).

Box 1 holds 3 red and 2 green balls; box 2 holds 1 red and 4 green. A fair coin chooses the box (heads: box 1) and one ball is drawn. Given that the ball is red, find the probability that it came from box 1.

\(P(R) = \frac12 \times \frac35 + \frac12 \times \frac15 = \frac{3}{10} + \frac{1}{10} = \frac25\). [2]

\(P(\text{box 1} \mid R) = \frac{3/10}{2/5} = \frac34\). [1]

For events \(A\) and \(B\), \(P(A) = p\), \(P(B) = 0.5\) and \(P(A \cup B) = 0.8\). (a) Find \(p\) if \(A\) and \(B\) are mutually exclusive. (b) Find \(p\) if \(A\) and \(B\) are independent. (c) Find the range of possible values of \(p\).

(a) \(p + 0.5 = 0.8 \Rightarrow p = 0.3\). [1]

(b) \(p + 0.5 - 0.5p = 0.8 \Rightarrow p = 0.6\). [1]

(c) \(P(A \cap B) = p + 0.5 - 0.8 = p - 0.3\), which must be between 0 and \(\min(p, 0.5)\). So \(p \ge 0.3\) and \(p - 0.3 \le 0.5 \Rightarrow p \le 0.8\). \(p \in [0.3, 0.8]\). [2]

“95% of people who have the disease test positive, so a positive test means a 95% chance of having it.” Using the disease example, explain why this is wrong.

95% is \(P(+ \mid D)\), but the question is about \(P(D \mid +)\), which is only about 0.16 here. Because the disease is rare, most positive results come from the large healthy group (false positives).

Summary

  • \(P(A \mid B) = \frac{P(A \cap B)}{P(B)}\); independent ⇔ \(P(A \cap B) = P(A)P(B)\).
  • Karnaugh maps for two events; trees for multi-stage experiments.
  • Reverse conditionals: build the tree, find the total, then divide.
