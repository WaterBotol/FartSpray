The standard derivatives

\(f(x)\)\(f'(x)\)\(f(x)\)\(f'(x)\)
\(x^n\)\(nx^{n-1}\)\(\sin(kx)\)\(k\cos(kx)\)
\((ax + b)^n\)\(an(ax + b)^{n-1}\)\(\cos(kx)\)\(-k\sin(kx)\)
\(e^{kx}\)\(ke^{kx}\)\(\tan(kx)\)\(\dfrac{k}{\cos^2(kx)} = k\sec^2(kx)\)
\(\log_e(kx)\)\(\dfrac{1}{x}\)\(\log_e(g(x))\)\(\dfrac{g'(x)}{g(x)}\)

Rewrite roots and fractions as powers before differentiating: \(\sqrt{x} = x^{1/2}\) and \(\frac{3}{x^2} = 3x^{-2}\).

The three rules

Chain, product and quotient rules
\[ \frac{dy}{dx} = \frac{dy}{du}\cdot\frac{du}{dx} \qquad (uv)' = u'v + uv' \qquad \left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2} \]

Function notation for the chain rule: \(\big(f(g(x))\big)' = f'(g(x))\cdot g'(x)\).

Decide which rule to use from the outermost structure. \(x^2e^{3x}\) is a product. \(e^{\sin x}\) is a composite (chain). \(\frac{\sin x}{x}\) is a quotient. Many questions need two rules in a row.

Differentiate \(y = x^2e^{3x}\) and fully factorise the result.

\(u = x^2,\ u' = 2x\); \(v = e^{3x},\ v' = 3e^{3x}\).

\(\dfrac{dy}{dx} = 2xe^{3x} + 3x^2e^{3x} = \boldsymbol{xe^{3x}(2 + 3x)}\). Factorised form makes stationary points easy: \(x = 0\) or \(x = -\frac23\).

Find \(\dfrac{dy}{dx}\) for (a) \(y = \log_e(x^2 + 1)\), (b) \(y = \log_e(\cos x)\).

Use \(\dfrac{d}{dx}\log_e(g(x)) = \dfrac{g'(x)}{g(x)}\).

(a) \(\dfrac{2x}{x^2 + 1}\); (b) \(\dfrac{-\sin x}{\cos x} = -\tan x\).

Differentiate \(f(x) = \dfrac{x}{x + 1}\).

\(u = x,\ u' = 1\); \(v = x + 1,\ v' = 1\).

\(f'(x) = \dfrac{1\cdot(x + 1) - x\cdot 1}{(x + 1)^2} = \boldsymbol{\dfrac{1}{(x + 1)^2}}\), which is always positive, so \(f\) is increasing on each branch.

Let \(f(x) = x^2\sin x\). Find \(f'\!\left(\frac{\pi}{2}\right)\).

\(f'(x) = 2x\sin x + x^2\cos x\).

\(f'\!\left(\frac{\pi}{2}\right) = 2\cdot\frac{\pi}{2}\cdot 1 + \frac{\pi^2}{4}\cdot 0 = \boldsymbol{\pi}\).

Find the derivatives of (a) \(f(g(x))\) at \(x = 1\), (b) \(f(x)g(x)\) at \(x = 2\), (c) \([f(x)]^2\) at \(x = 1\).

(a) \(f'(g(1))\cdot g'(1) = f'(2)\cdot 5 = 7 \times 5 = 35\).

(b) \(f'(2)g(2) + f(2)g'(2) = 7(1) + 4(-3) = -5\).

(c) \(2f(1)f'(1) = 2(3)(-2) = -12\).

(a) 35, (b) −5, (c) −12. In (a), \(f'\) is evaluated at \(g(1) = 2\), not at 1. That's the trap.

  • \(\frac{d}{dx}\log_e(2x) = \frac1x\), not \(\frac2x\): the 2 cancels (\(\frac{2}{2x}\)).
  • \(\sin^2 x\) vs \(\sin(x^2)\): \(2\sin x\cos x\) vs \(2x\cos(x^2)\).
  • \(e^{x^2}\) differentiates to \(2xe^{x^2}\), not \(x^2e^{x^2 - 1}\). The power rule doesn't apply to exponentials.
  • The derivative of a constant is 0: \(\frac{d}{dx}e^2 = 0\) and \(\frac{d}{dx}\pi^2 = 0\).
  • Quotient rule sign: it's \(u'v - uv'\) on top, so the order matters.

Practice

If \(y = \sqrt{1 - x^2}\), then \(\dfrac{dy}{dx}\) is

  1. \(\dfrac{1}{2\sqrt{1 - x^2}}\)
  2. \(\dfrac{-x}{\sqrt{1 - x^2}}\)
  3. \(-2x\sqrt{1 - x^2}\)
  4. \(\dfrac{x}{\sqrt{1 - x^2}}\)

\(\frac12(1 - x^2)^{-1/2}\cdot(-2x) = \frac{-x}{\sqrt{1 - x^2}}\).

\(\dfrac{d}{dx}\big[\log_e(5x)\big]\) is

  1. \(\frac{1}{x}\)
  2. \(\frac{5}{x}\)
  3. \(\frac{1}{5x}\)
  4. \(5\log_e x\)

\(\frac{5}{5x} = \frac1x\). Or: \(\log_e(5x) = \log_e 5 + \log_e x\), and \(\log_e 5\) is a constant.

The derivative of \(\tan(2x)\) is

  1. \(\sec^2(2x)\)
  2. \(\dfrac{1}{\cos^2(2x)}\)
  3. \(2\tan(2x)\)
  4. \(\dfrac{2}{\cos^2(2x)}\)

\(\frac{d}{dx}\tan(kx) = \frac{k}{\cos^2(kx)}\) with \(k = 2\).

If \(f(x) = xe^{2x}\), then \(f'(0)\) equals

  1. 0
  2. 2
  3. 1
  4. \(e^2\)

\(f'(x) = e^{2x} + 2xe^{2x}\); \(f'(0) = 1 + 0 = 1\).

If \(y = \sin(x^2)\), then \(\dfrac{dy}{dx}\) is

  1. \(2\sin x\cos x\)
  2. \(2x\cos(x^2)\)
  3. \(\cos(x^2)\)
  4. \(\cos(2x)\)

Chain rule with inner \(x^2\). A is the derivative of \(\sin^2 x\).

Let \(h(x) = e^{\sin x}\). Then \(h'(\pi)\) equals

  1. \(-1\)
  2. \(1\)
  3. \(0\)
  4. \(-e\)

\(h'(x) = \cos x\,e^{\sin x}\); \(h'(\pi) = (-1)e^0 = -1\).

If \(f(x) = [g(x)]^3\), \(g(2) = -1\) and \(g'(2) = 4\), then \(f'(2)\) is

  1. \(-12\)
  2. \(48\)
  3. \(12\)
  4. \(-4\)

\(f'(x) = 3[g(x)]^2g'(x)\): \(3(-1)^2(4) = 12\). The square makes the \(-1\) positive.

Differentiate \(y = \dfrac{\cos x}{x}\).

Quotient rule: \(\dfrac{dy}{dx} = \dfrac{-x\sin x - \cos x}{x^2}\).

Find \(f'(x)\) if \(f(x) = (3x^2 - 1)^5\).

\(f'(x) = 5(3x^2 - 1)^4\cdot 6x = 30x(3x^2 - 1)^4\).

Let \(y = e^{-x}\sin(2x)\). Show that \(\dfrac{dy}{dx} = e^{-x}\big(2\cos(2x) - \sin(2x)\big)\), and find the exact gradient at \(x = \frac{\pi}{4}\).

Product rule: \(-e^{-x}\sin(2x) + e^{-x}\cdot 2\cos(2x) = e^{-x}(2\cos 2x - \sin 2x)\). [2]

At \(\frac{\pi}{4}\): \(e^{-\pi/4}(2\cdot 0 - 1) = -e^{-\pi/4}\). [1]

Let \(f(x) = \log_e(x^2 - 3)\). (a) State the maximal domain. (b) Find \(f'(x)\). (c) Find the value(s) of \(x\) at which the gradient is 4.

(a) \(x^2 > 3\): \((-\infty, -\sqrt3) \cup (\sqrt3, \infty)\). [1]

(b) \(f'(x) = \dfrac{2x}{x^2 - 3}\). [1]

(c) \(2x = 4x^2 - 12 \Rightarrow 2x^2 - x - 6 = 0 \Rightarrow (2x + 3)(x - 2) = 0\), so \(x = 2\) or \(x = -\frac32\). But \(-\frac32\) is not in the domain (\(\frac94 - 3 < 0\)). \(x = 2\) only. [1]

Using the table in the worked example above, a student writes \(\frac{d}{dx}f(g(x))\big|_{x=2} = f'(2)g'(2) = -21\). Find the correct value.

It should be \(f'(g(2))\cdot g'(2) = f'(1)\cdot(-3) = (-2)(-3) = 6\). The outer derivative is evaluated at \(g(2) = 1\), not at 2.

Summary

  • Know the standard derivatives, including \(\tan(kx) \to \frac{k}{\cos^2 kx}\) and \(\log_e g \to \frac{g'}{g}\).
  • Chain: derivative of outside (inside unchanged) × derivative of inside.
  • Product: \(u'v + uv'\). Quotient: \(\frac{u'v - uv'}{v^2}\).
  • Factorise derivatives: you'll usually need \(f'(x) = 0\) next.
