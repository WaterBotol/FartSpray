Relations and functions

A relation is any set of ordered pairs \((x, y)\). A function is a relation where every \(x\)-value has exactly one \(y\)-value.

  • Vertical line test: a graph is a function if no vertical line cuts it more than once.
  • One-to-one: every \(y\)-value comes from exactly one \(x\)-value (passes the horizontal line test too). Examples: \(y = x^3\), \(y = e^x\), \(y = \log_e x\).
  • Many-to-one: some \(y\)-values come from more than one \(x\)-value. Examples: \(y = x^2\), \(y = \cos x\), \(y = |x|\).
Function notation
\[ f: D \to \mathbb{R},\quad f(x) = \ldots \]

\(D\) is the domain (allowed inputs). The range is the set of outputs actually produced. \(\mathbb{R}\) here is the codomain, not the range.

Interval notation: \([a, b]\) includes both ends, \((a, b)\) excludes both, \([a, b)\) includes \(a\) only. \(\mathbb{R}\setminus\{2\}\) means “all reals except 2”; \(\mathbb{R}^+ = (0, \infty)\).

Maximal (implied) domain

If no domain is given, use the largest set of real numbers for which the rule makes sense:

Rule containsCondition
\(\sqrt{g(x)}\)\(g(x) \ge 0\)
\(\dfrac{1}{g(x)}\)\(g(x) \ne 0\)
\(\log_e(g(x))\)\(g(x) > 0\) (strictly)
\(\tan(x)\)\(x \ne \frac{\pi}{2} + k\pi,\ k \in \mathbb{Z}\)

When a rule is a sum or product of pieces, the maximal domain is the intersection of the pieces' domains.

Find the maximal domain of \(f(x) = \sqrt{4 - x} + \dfrac{1}{x + 1}\).

Square root: \(4 - x \ge 0 \Rightarrow x \le 4\).

Fraction: \(x + 1 \ne 0 \Rightarrow x \ne -1\).

\((-\infty, -1) \cup (-1, 4]\), which can also be written \((-\infty, 4]\setminus\{-1\}\).

Finding the range on a restricted domain

Sketch the graph over the domain only, then read off the lowest and highest \(y\)-values. Check three things: turning points inside the domain, the values at the endpoints, and whether each endpoint is included.

Find the range of \(f: [-1, 3) \to \mathbb{R},\ f(x) = x^2 - 2x\).

Turning point: \(f(x) = (x - 1)^2 - 1\), so the minimum is \(-1\) at \(x = 1\), which is in the domain.

Endpoints: \(f(-1) = 1 + 2 = 3\) (included, since \(-1\) is in the domain); \(f(3) = 9 - 6 = 3\) (\(x = 3\) is excluded).

Is 3 in the range? Yes: even though \(x = 3\) is excluded, the value 3 is still produced at \(x = -1\).

Range \(= [-1, 3]\). Many students write \([-1, 3)\) because of the open endpoint. Always check whether the “missing” value is produced somewhere else.

Hybrid (piecewise) functions

A hybrid function uses different rules on different parts of the domain. Sketch each piece only over its own interval, with a closed dot where an endpoint is included and an open dot where it isn't.

A hybrid function is continuous at a join if the pieces give the same value there. Continuity problems usually become “set the two rules equal at the join and solve for the unknown constant”. Differentiability (a smooth join) is on the Limits, continuity & differentiability page.

Find \(a\) so that \(g(x) = \begin{cases} x^2 + a, & x \le 2 \\ 3x - 1, & x > 2 \end{cases}\) is continuous at \(x = 2\).

Both rules must give the same value at \(x = 2\): \(2^2 + a = 3(2) - 1\).

\(4 + a = 5 \Rightarrow a = 1\).

The modulus function

Modulus (absolute value)
\[ |x| = \begin{cases} x, & x \ge 0 \\ -x, & x < 0 \end{cases} \]

\(|x|\) is the distance from 0. The graph of \(y = |f(x)|\) is the graph of \(y = f(x)\) with every part below the \(x\)-axis reflected up.

Solve \(|x^2 - 4| = 3\).

Split into two equations: \(x^2 - 4 = 3\) or \(x^2 - 4 = -3\).

\(x^2 = 7 \Rightarrow x = \pm\sqrt7\); \(x^2 = 1 \Rightarrow x = \pm 1\).

\(x = \pm 1, \pm\sqrt7\) (four solutions: check on the graph, where the line \(y = 3\) cuts the W shape four times).

  • Logs need strictly positive arguments. \(\log_e(x^2)\) has domain \(\mathbb{R}\setminus\{0\}\), but \(2\log_e x\) has domain \((0, \infty)\). They are only equal for \(x > 0\).
  • Open endpoints aren't automatically open in the range (see the worked example above).
  • Asymptotes are never reached. The range of \(y = 3 - \frac{2}{(x - 1)^2}\) is \((-\infty, 3)\), not \((-\infty, 3]\).

Practice

The maximal domain of \(f(x) = \log_e(x^2 - 9)\) is

  1. \((3, \infty)\)
  2. \([-3, 3]\)
  3. \((-\infty, -3) \cup (3, \infty)\)
  4. \(\mathbb{R}\setminus\{-3, 3\}\)

Need \(x^2 - 9 > 0\), i.e. \(x < -3\) or \(x > 3\). D forgets that values between −3 and 3 make the argument negative.

The range of \(f: (-2, 1] \to \mathbb{R},\ f(x) = x^2\) is

  1. \([1, 4)\)
  2. \([0, 4)\)
  3. \((0, 4]\)
  4. \([0, 1]\)

The minimum 0 occurs at \(x = 0\) (in the domain). As \(x \to -2\), \(f(x) \to 4\), but \(x = -2\) is excluded and nothing else in the domain gives 4, so 4 is not reached. Range \([0, 4)\).

Which of these functions (each with maximal domain) is one-to-one?

  1. \(y = x^3 + 1\)
  2. \(y = x^2 - 1\)
  3. \(y = |x|\)
  4. \(y = \cos x\)

\(x^3 + 1\) is strictly increasing, so each \(y\) comes from one \(x\). The others fail the horizontal line test.

The range of \(y = 3 - \dfrac{2}{(x - 1)^2}\) is

  1. \(\mathbb{R}\setminus\{3\}\)
  2. \((3, \infty)\)
  3. \((-\infty, 3]\)
  4. \((-\infty, 3)\)

\(\frac{2}{(x-1)^2} > 0\) for all \(x \ne 1\), so \(y < 3\). It gets arbitrarily close to 3 but never reaches it (horizontal asymptote), and it can be as negative as you like.

For \(h(x) = \begin{cases} 2x + 1, & x < 0 \\ 1 - x^2, & x \ge 0 \end{cases}\), the value of \(h(-1) + h(2)\) is

  1. \(-2\)
  2. \(4\)
  3. \(-4\)
  4. \(0\)

\(h(-1) = 2(-1) + 1 = -1\); \(h(2) = 1 - 4 = -3\). Sum \(= -4\).

The number of solutions of \(|x^2 - 4| = 4\) is

  1. 2
  2. 3
  3. 4
  4. 1

\(x^2 - 4 = 4 \Rightarrow x = \pm 2\sqrt2\); \(x^2 - 4 = -4 \Rightarrow x = 0\). Three solutions: the line \(y = 4\) passes through the peak of the reflected section at \((0, 4)\).

Find the maximal domain of \(g(x) = \log_e(2 - x) + \sqrt{x + 3}\).

\(2 - x > 0 \Rightarrow x < 2\); \(x + 3 \ge 0 \Rightarrow x \ge -3\). Intersection: \([-3, 2)\).

Find all values of \(k\) for which \(f: \mathbb{R} \to \mathbb{R},\ f(x) = x^2 + kx + 4\) has range \([0, \infty)\).

The range is \([0, \infty)\) exactly when the minimum value is 0, i.e. the graph touches the \(x\)-axis: discriminant \(= 0\).

\(k^2 - 16 = 0 \Rightarrow k = \pm 4\).

Let \(f(x) = |x - 1| + |x + 2|\). (a) Write \(f\) as a hybrid function. (b) State the range of \(f\).

(a) Critical points \(x = -2\) and \(x = 1\):

\(f(x) = \begin{cases} -2x - 1, & x < -2 \\ 3, & -2 \le x \le 1 \\ 2x + 1, & x > 1 \end{cases}\) [2]

(b) The graph is flat at 3 between the corners and rises either side: range \([3, \infty)\). [1]

A student says \(\log_e(x^2) = 2\log_e(x)\), so the two functions have the same graph. Explain why this is wrong.

\(\log_e(x^2)\) is defined for all \(x \ne 0\) (since \(x^2 > 0\)), but \(2\log_e(x)\) is only defined for \(x > 0\). The rules agree for \(x > 0\), but \(y = \log_e(x^2)\) also has a mirror-image branch for \(x < 0\). Functions with different domains are different functions.

Summary

  • Function: one output per input. One-to-one: one input per output.
  • Maximal domain: roots \(\ge 0\), denominators \(\ne 0\), log arguments \(> 0\); intersect the conditions.
  • Range on a restricted domain: check turning points, endpoints and whether excluded values are produced elsewhere.
  • Hybrid functions: sketch each piece on its own interval; continuity means the pieces agree at the join.
  • \(|f(x)|\): reflect the negative parts up; corners appear at the \(x\)-intercepts.
