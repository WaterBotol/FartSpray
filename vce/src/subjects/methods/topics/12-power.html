Transformed forms

Hyperbola, truncus and root in transformed form
\[ y = \frac{a}{x - h} + k \qquad y = \frac{a}{(x - h)^2} + k \qquad y = a\sqrt{\pm(x - h)} + k \]

For the hyperbola and truncus: asymptotes \(x = h\) and \(y = k\). For the root: the endpoint is \((h, k)\).

For every sketch, find: (1) asymptotes or endpoint, (2) the \(y\)-intercept (put \(x = 0\)), (3) the \(x\)-intercept(s) (put \(y = 0\)), (4) the domain and range. The sign of \(a\) tells you which way the branches go.

Sketch \(y = \dfrac{2}{x - 1} + 3\), labelling asymptotes and intercepts.

Asymptotes: \(x = 1\) and \(y = 3\).

\(y\)-intercept: \(y = \frac{2}{-1} + 3 = 1\), so \((0, 1)\).

\(x\)-intercept: \(0 = \frac{2}{x - 1} + 3 \Rightarrow x - 1 = -\frac23 \Rightarrow x = \frac13\).

Since \(a = 2 > 0\), the branches sit top-right and bottom-left of the asymptote intersection \((1, 3)\). Asymptotes \(x = 1,\ y = 3\); intercepts \((0, 1)\) and \((\tfrac13, 0)\). Domain \(\mathbb{R}\setminus\{1\}\), range \(\mathbb{R}\setminus\{3\}\).

Find the intercepts, asymptotes and range of \(y = -\dfrac{1}{(x + 2)^2} + 4\).

Asymptotes \(x = -2\), \(y = 4\). \(a < 0\), so both branches are below \(y = 4\).

\(y\)-intercept: \(-\frac14 + 4 = \frac{15}{4}\).

\(x\)-intercepts: \((x + 2)^2 = \frac14 \Rightarrow x + 2 = \pm\frac12 \Rightarrow x = -\frac52, -\frac32\).

Intercepts \((-\tfrac52, 0), (-\tfrac32, 0), (0, \tfrac{15}{4})\); range \((-\infty, 4)\).

Sketch \(y = 2\sqrt{3 - x} - 4\), stating the domain, range and intercepts.

Rewrite as \(y = 2\sqrt{-(x - 3)} - 4\): reflected in the \(y\)-axis, so the graph goes left from the endpoint \((3, -4)\). Domain: \(3 - x \ge 0 \Rightarrow x \le 3\).

\(x\)-intercept: \(\sqrt{3 - x} = 2 \Rightarrow 3 - x = 4 \Rightarrow x = -1\). \(y\)-intercept: \(2\sqrt3 - 4 \approx -0.54\).

Domain \((-\infty, 3]\), range \([-4, \infty)\); intercepts \((-1, 0)\) and \((0, 2\sqrt3 - 4)\).

A truncus has asymptotes \(x = -1\) and \(y = 2\) and passes through \((0, 5)\). Find its rule.

\(y = \dfrac{a}{(x + 1)^2} + 2\). Substitute \((0, 5)\): \(5 = a + 2\).

\(a = 3\), so \(y = \dfrac{3}{(x + 1)^2} + 2\).

  • Cube roots of negatives exist. \(x^{1/3}\) and \(x^{2/3}\) have domain \(\mathbb{R}\). CAS sometimes shows only the \(x \ge 0\) half. Don't trust it blindly.
  • \(x^{2/3} = 4\) has two solutions: \(x^{1/3} = \pm2\), so \(x = \pm8\).
  • Asymptotes are not in the range. \(y = \frac{a}{x - h} + k\) never equals \(k\).
  • \(\sqrt{3 - x}\) goes left, not right. Factor out the negative to see the reflection.

Practice

The asymptotes of \(y = \dfrac{3}{2x - 4} + 1\) are

  1. \(x = 2,\ y = 1\)
  2. \(x = 4,\ y = 1\)
  3. \(x = -2,\ y = 1\)
  4. \(x = 2,\ y = 3\)

The denominator is 0 when \(x = 2\). As \(x \to \pm\infty\) the fraction \(\to 0\), so \(y \to 1\).

For \(0 < x < 1\), which is largest?

  1. \(x^2\)
  2. \(x\)
  3. \(x^{1/3}\)
  4. \(x^{1/2}\)

For numbers between 0 and 1, smaller powers give bigger results: e.g. \(x = 0.064\) gives \(x^{1/3} = 0.4\) but \(x^{1/2} \approx 0.25\).

The range of \(y = -\dfrac{2}{(x + 1)^2} - 3\) is

  1. \(\mathbb{R}\setminus\{-3\}\)
  2. \((-3, \infty)\)
  3. \((-\infty, -3]\)
  4. \((-\infty, -3)\)

\(-\frac{2}{(x + 1)^2} < 0\) always, so \(y < -3\), and \(-3\) is the asymptote (never reached).

The solutions of \(x^{2/3} = 9\) are

  1. \(x = 27\) only
  2. \(x = \pm27\)
  3. \(x = \pm3\)
  4. \(x = 3\sqrt3\) only

\((x^{1/3})^2 = 9 \Rightarrow x^{1/3} = \pm3 \Rightarrow x = \pm27\). The domain of \(x^{2/3}\) is all of \(\mathbb{R}\).

A hyperbola \(y = \dfrac{a}{x - 2} - 1\) passes through \((3, 1)\). The value of \(a\) is

  1. \(-2\)
  2. \(1\)
  3. \(2\)
  4. \(0\)

\(1 = \frac{a}{1} - 1 \Rightarrow a = 2\).

The graphs of \(y = \sqrt{x}\) and \(y = \dfrac{x}{4}\) intersect at

  1. \((0, 0)\) and \((16, 4)\)
  2. \((4, 1)\) only
  3. \((0, 0)\) and \((4, 2)\)
  4. \((16, 4)\) only

\(\sqrt{x} = \frac{x}{4} \Rightarrow 16x = x^2 \Rightarrow x = 0\) or \(16\). Both are valid (check: \(\sqrt{16} = 4 = \frac{16}{4}\)).

The maximal domain of \(y = \sqrt{2x + 6} - 1\) is

  1. \([-6, \infty)\)
  2. \([-3, \infty)\)
  3. \((-3, \infty)\)
  4. \([3, \infty)\)

\(2x + 6 \ge 0 \Rightarrow x \ge -3\). The endpoint is included, because \(\sqrt0 = 0\) is fine.

Sketch \(y = \dfrac{1}{(x - 2)^2} - 1\), labelling asymptotes and intercepts.

Asymptotes \(x = 2\), \(y = -1\). \(y\)-intercept: \(\frac14 - 1 = -\frac34\).

\(x\)-intercepts: \((x - 2)^2 = 1 \Rightarrow x = 1, 3\). Both branches are above \(y = -1\) (since \(a > 0\)); range \((-1, \infty)\).

The graph of \(y = \dfrac{a}{x + b} + c\) has a vertical asymptote at \(x = -3\), a horizontal asymptote at \(y = 2\), and passes through the origin. Find \(a\), \(b\) and \(c\).

Vertical asymptote \(x = -b = -3 \Rightarrow b = 3\). Horizontal asymptote \(c = 2\). [1]

Through \((0, 0)\): \(0 = \frac{a}{3} + 2 \Rightarrow a = -6\). [1]

\(y = -\dfrac{6}{x + 3} + 2\). [1]

A student claims the range of \(f: [1, 4) \to \mathbb{R},\ f(x) = \dfrac{1}{x}\) is \([\tfrac14, 1]\). Correct them.

\(f\) is decreasing, so the largest value is at the left end: \(f(1) = 1\) (included). The smallest value would be at \(x = 4\), which is excluded, so \(\tfrac14\) is not reached.

Range \((\tfrac14, 1]\).

Let \(f(x) = 1 - \sqrt{x + 4}\). (a) State the maximal domain and range. (b) Find the coordinates of the axis intercepts.

(a) Domain \([-4, \infty)\). The square root is \(\ge 0\), so \(f(x) \le 1\): range \((-\infty, 1]\). [1]

(b) \(y\)-intercept: \(f(0) = 1 - 2 = -1\), so \((0, -1)\). [1]

\(x\)-intercept: \(\sqrt{x + 4} = 1 \Rightarrow x = -3\), so \((-3, 0)\). [1]

Summary

  • Hyperbola \(\frac{a}{x - h} + k\) and truncus \(\frac{a}{(x - h)^2} + k\): asymptotes \(x = h\), \(y = k\).
  • Root functions start at an endpoint; factor out a negative inside the root to spot a reflection.
  • \(x^{1/3}\) and \(x^{2/3}\) are defined for all real \(x\).
  • Between 0 and 1 the powers swap order; all pass through \((1, 1)\).
