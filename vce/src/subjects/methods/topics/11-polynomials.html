Division, remainders and factors

Dividing a polynomial \(P(x)\) by \((x - a)\) gives a quotient \(Q(x)\) and a remainder \(R\) (a number):

Division statement
\[ P(x) = (x - a)\,Q(x) + R \]

Substituting \(x = a\) kills the first term, which gives the two theorems you use every week.

Remainder theorem
\[ \text{The remainder when } P(x) \text{ is divided by } (x - a) \text{ is } P(a). \]

For a divisor \((bx - a)\) the remainder is \(P\!\left(\tfrac{a}{b}\right)\).

Factor theorem
\[ (x - a) \text{ is a factor of } P(x) \iff P(a) = 0. \]

To factorise a cubic by hand: try the factors of the constant term (\(\pm1, \pm2, \pm3, \ldots\)) until \(P(a) = 0\), then divide by \((x - a)\) and factorise the quadratic that is left. With a non-monic leading coefficient, also try fractions \(\pm\frac{\text{factor of constant}}{\text{factor of leading coeff}}\).

Factorise \(P(x) = 2x^3 - 3x^2 - 11x + 6\) and solve \(P(x) = 0\).

The factor theorem: if \(P(a) = 0\) then \((x - a)\) is a factor. Test small integer factors of the constant term (divided by factors of the leading coefficient), then divide to reduce the cubic to a quadratic.

Hunt for a root: \(P(1) = -6\), \(P(-1) = 12\), \(P(3) = 54 - 27 - 33 + 6 = 0\). So \((x - 3)\) is a factor.

Divide (or match coefficients): \(2x^3 - 3x^2 - 11x + 6 = (x - 3)(2x^2 + 3x - 2)\).

Factorise the quadratic: \(2x^2 + 3x - 2 = (2x - 1)(x + 2)\).

\(P(x) = (x - 3)(2x - 1)(x + 2)\), so \(x = -2, \tfrac12, 3\).

\(P(x) = x^3 + ax^2 + bx - 6\) has factors \((x - 1)\) and \((x + 2)\). Find \(a\) and \(b\), then fully factorise \(P(x)\).

Each known factor gives an equation: substituting its root into \(P(x)\) must give zero. Two factors give two equations for the two unknowns.

\(P(1) = 0\): \(1 + a + b - 6 = 0 \Rightarrow a + b = 5\).

\(P(-2) = 0\): \(-8 + 4a - 2b - 6 = 0 \Rightarrow 2a - b = 7\).

Add the equations: \(3a = 12\), so \(a = 4,\ b = 1\).

\(a = 4,\ b = 1\) and \(P(x) = x^3 + 4x^2 + x - 6 = (x - 1)(x + 2)(x + 3)\). (The third factor must make the constant term \(-6\): \((-1)(2)(c) = -6 \Rightarrow c = 3\).)

Sum and difference of cubes
\[ a^3 + b^3 = (a + b)(a^2 - ab + b^2) \qquad a^3 - b^3 = (a - b)(a^2 + ab + b^2) \]

The quadratic factor never has real roots, so \(x^3 - 27 = 0\) has only one real solution, \(x = 3\).

Shapes of polynomial graphs

A factor tells you what the graph does at that \(x\)-intercept:

FactorBehaviour at \(x = a\)
\((x - a)\)Cuts straight through the axis
\((x - a)^2\)Touches the axis and turns (a turning point on the axis)
\((x - a)^3\)Flattens out and passes through: a stationary point of inflection

End behaviour depends on the degree and the sign of the leading coefficient. Odd degree, positive: from bottom-left to top-right. Even degree, positive: both ends up. A negative leading coefficient flips everything.

Cubic in “turning point” (inflection) form
\[ y = a(x - h)^3 + k \]

Stationary point of inflection at \((h, k)\). No other turning points.

A cubic touches the \(x\)-axis at \(x = 2\), crosses it at \(x = -1\) and passes through \((0, 8)\). Find its rule.

The shape at each \(x\)-intercept tells you the factor: a crossing gives \((x - p)\), a touch (turning point on the axis) gives \((x - q)^2\). One more point fixes the dilation factor \(a\).

The touch gives a squared factor: \(y = a(x + 1)(x - 2)^2\).

Substitute \((0, 8)\): \(8 = a(1)(4)\), so \(a = 2\).

\(y = 2(x + 1)(x - 2)^2\) (expanded: \(y = 2x^3 - 6x^2 + 8\)).

Solve \(x^4 - 5x^2 + 4 = 0\).

A quartic with only \(x^4\) and \(x^2\) terms is a quadratic in \(x^2\). Substitute \(u = x^2\), solve, then go back to \(x\), rejecting any negative \(u\).

Let \(u = x^2\): \(u^2 - 5u + 4 = 0 \Rightarrow (u - 1)(u - 4) = 0\), so \(u = 1\) or \(u = 4\).

\(x = \pm1, \pm2\). Don't stop at \(u\): the question asked for \(x\).

How many solutions? Polynomials with a parameter

Exam 2 loves “find the values of \(k\) for which the equation has exactly one / two / three solutions”. Rewrite so the parameter sits alone, then think of it as a horizontal line \(y = k\) moving up and down against a fixed graph.

Find the values of \(k\) for which \(x^3 - 3x + k = 0\) has (a) exactly three, (b) exactly two, (c) exactly one real solution.

The number of solutions of \(f(x) = c\) equals the number of times the horizontal line \(y = c\) meets \(y = f(x)\). The turning points mark where that count changes.

Rearrange: \(-k = x^3 - 3x\). Count intersections of \(y = x^3 - 3x\) with the horizontal line \(y = -k\).

\(y = x^3 - 3x\) has turning points where \(3x^2 - 3 = 0\), i.e. \(x = \pm1\): a local max at \((-1, 2)\) and a local min at \((1, -2)\).

The line cuts three times when it is strictly between the turning points: \(-2 < -k < 2\), i.e. \(-2 < k < 2\). It touches a turning point (two solutions) when \(-k = \pm2\).

(a) \(-2 < k < 2\); (b) \(k = \pm2\); (c) \(k < -2\) or \(k > 2\). Check (b): \(k = 2\) gives \(x^3 - 3x + 2 = (x - 1)^2(x + 2)\), two distinct solutions.

  • “Solutions” means distinct solutions. \((x - 1)^2(x + 2) = 0\) has two solutions, not three.
  • A factor isn't always a root you can see. If \((x - 1)\) is a factor of \(x^3 + x - 2\), the other factor \(x^2 + x + 2\) has a negative discriminant, so the graph has only one \(x\)-intercept.
  • Remainder with \((x + a)\): substitute \(x = -a\), not \(x = a\).
  • The turning point at a double root isn't always a minimum. For \(y = (x + 1)^2(x - 3)\) (positive leading coefficient) the double root is on the left, so it's a local maximum.

Practice

The remainder when \(x^4 - 3x + 1\) is divided by \((x + 1)\) is

  1. \(-1\)
  2. \(5\)
  3. \(3\)
  4. \(-3\)

\(P(-1) = 1 + 3 + 1 = 5\). Option A comes from substituting \(x = 1\).

\(x^3 + 8\) factorises as

  1. \((x + 2)^3\)
  2. \((x + 2)(x^2 + 2x + 4)\)
  3. \((x - 2)(x^2 + 2x + 4)\)
  4. \((x + 2)(x^2 - 2x + 4)\)

Sum of cubes with \(a = x,\ b = 2\): \((a + b)(a^2 - ab + b^2)\).

The graph of \(y = (x + 1)^2(x - 3)\) has

  1. a local maximum at \((-1, 0)\)
  2. a local minimum at \((-1, 0)\)
  3. a stationary point of inflection at \((-1, 0)\)
  4. no stationary point at \(x = -1\)

Positive cubic: it rises from the bottom left, touches the axis at \(x = -1\) and turns back down, then turns up again (local min at \(x = \tfrac53\)) before cutting at \(x = 3\). So \((-1, 0)\) is a local maximum.

When \(2x^3 - 3x^2 + 4\) is divided by \((x - 2)\), the quotient and remainder are

  1. \(2x^2 - 7x + 14\), remainder \(-24\)
  2. \(2x^2 + x + 2\), remainder 0
  3. \(2x^2 + x + 2\), remainder 8
  4. \(2x^2 - x - 2\), remainder 0

\((x - 2)(2x^2 + x + 2) = 2x^3 - 3x^2 - 4\), and adding 8 gives the original. Quick check on the remainder: \(P(2) = 16 - 12 + 4 = 8\).

\(P(x) = x^3 + kx^2 + x - 2\) has \((x - 1)\) as a factor. The number of \(x\)-intercepts of \(y = P(x)\) is

  1. 0
  2. 1
  3. 2
  4. 3

\(P(1) = 1 + k + 1 - 2 = 0 \Rightarrow k = 0\). Then \(P(x) = (x - 1)(x^2 + x + 2)\), and \(x^2 + x + 2\) has discriminant \(1 - 8 < 0\). Only one intercept, at \(x = 1\).

How many stationary points does \(y = (x - 2)^3 + 1\) have?

  1. 0
  2. 2
  3. 1
  4. 3

\(\frac{dy}{dx} = 3(x - 2)^2 = 0\) only at \(x = 2\): one stationary point, and it's a point of inflection at \((2, 1)\). It is not a turning point.

The equation \(x^3 - x^2 - 8x + 12 = 0\) has solutions

  1. \(x = 2, -3\) and one other irrational solution
  2. \(x = -2, 3\) only
  3. \(x = 1, 2, -3\)
  4. \(x = 2, -3\) only

\(P(2) = 8 - 4 - 16 + 12 = 0\). Dividing gives \(x^2 + x - 6 = (x + 3)(x - 2)\), so \(P(x) = (x - 2)^2(x + 3)\). Two distinct solutions.

When \(x^3 + ax^2 - 5x + 2\) is divided by \((x - 2)\) the remainder is 4. Find \(a\).

\(P(2) = 8 + 4a - 10 + 2 = 4\), so \(4a = 4\) and \(a = 1\).

Solve \(x^3 - 2x^2 - 5x + 6 \ge 0\).

\(P(1) = 0\), and dividing gives \(P(x) = (x - 1)(x + 2)(x - 3)\). It's a positive cubic, so it's above the axis between the first two roots and after the last one.

\(x \in [-2, 1] \cup [3, \infty)\).

Sketch \(y = x^4 - 10x^2 + 9\), labelling all intercepts, and state the values of \(c\) for which \(x^4 - 10x^2 + 9 = c\) has exactly four solutions.

\(x^4 - 10x^2 + 9 = (x^2 - 1)(x^2 - 9) = (x - 1)(x + 1)(x - 3)(x + 3)\): \(x\)-intercepts \(\pm1, \pm3\), \(y\)-intercept 9. [1]

Stationary points: \(4x^3 - 20x = 0 \Rightarrow x = 0, \pm\sqrt5\). Local max \((0, 9)\); minima at \(x = \pm\sqrt5\) where \(y = 25 - 50 + 9 = -16\). [1]

A horizontal line \(y = c\) cuts the W shape four times when it is between the minima and the local max: \(-16 < c < 9\). [1]

Let \(f(x) = x^3 - 3x^2 + p\). Find the values of \(p\) for which \(f(x) = 0\) has exactly one real solution.

\(f'(x) = 3x^2 - 6x = 3x(x - 2)\), so turning points at \(x = 0\) (local max, \(f = p\)) and \(x = 2\) (local min, \(f = p - 4\)). [1]

Three solutions need the max above the axis and the min below: \(p > 0\) and \(p - 4 < 0\). Exactly one solution needs both turning points on the same side of the axis. [1]

\(p < 0\) or \(p > 4\). [1] (At \(p = 0\) or \(p = 4\) there are two solutions.)

How many real solutions does \(8x^3 + 1 = 0\) have? Give them.

\(8x^3 + 1 = (2x + 1)(4x^2 - 2x + 1)\). The quadratic has discriminant \(4 - 16 < 0\), so there is only one real solution: \(x = -\tfrac12\).

Summary

  • Remainder of \(P(x) \div (x - a)\) is \(P(a)\); \((x - a)\) is a factor iff \(P(a) = 0\).
  • Single factor: cut. Squared: touch and turn. Cubed: stationary point of inflection.
  • Counting solutions with a parameter: isolate the parameter and slide a horizontal line past the turning points.
  • Watch for quadratic factors with negative discriminants: they add no \(x\)-intercepts.
