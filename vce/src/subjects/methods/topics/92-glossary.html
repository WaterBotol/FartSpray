Definitions written the way VCAA uses them. Click the link after each for the full explanation.

A–F

Absolute maximum/minimum
The greatest/least value of a function over its whole domain; on a closed interval it may occur at an endpoint. Optimisation
Asymptote
A line the graph approaches but never reaches (as \(x\) or \(y\) grows without bound). Power functions
Average rate of change
\(\frac{f(b) - f(a)}{b - a}\): the gradient of the secant over \([a, b]\). Applications of differentiation
Average value
\(\frac{1}{b - a}\int_a^b f(x)\,dx\). Integration
Bernoulli trial
A single trial with two outcomes (success with probability \(p\), failure with \(1 - p\)). Binomial
Bias
A systematic tendency of a sampling method to over- or under-estimate a parameter. Sampling
Binomial distribution
The number of successes in \(n\) independent Bernoulli trials with constant \(p\): \(X \sim \text{Bi}(n, p)\). Binomial
Bisection method
Repeatedly halving an interval on which \(f\) changes sign to trap a root. Newton's method
Composite function
\((f \circ g)(x) = f(g(x))\); exists iff \(\text{ran}\, g \subseteq \text{dom}\, f\). Composite & inverse
Concave up/down
\(f''(x) > 0\) (gradient increasing) / \(f''(x) < 0\) (gradient decreasing). Applications of differentiation
Conditional probability
\(P(A \mid B) = \frac{P(A \cap B)}{P(B)}\): the probability of \(A\) given \(B\) has occurred. Probability
Confidence interval
An interval estimate of a parameter; about 95% of 95% intervals built this way contain the true value. Confidence intervals
Continuous (function)
No breaks at \(x = a\): \(\lim_{x \to a} f(x) = f(a)\). Limits
Continuous random variable
A random variable taking any value in an interval, described by a pdf. CRVs
Differentiable
The derivative exists: continuous with no corners, cusps or vertical tangents. Limits
Dilation from the \(x\)-axis
A vertical stretch \((x, y) \to (x, ay)\). Transformations
Discriminant
\(\Delta = b^2 - 4ac\); its sign gives the number of real roots of a quadratic. Systems
Domain
The set of allowed input values. Functions
Even function
\(f(-x) = f(x)\): symmetric in the \(y\)-axis. Functional equations
Expected value
The long-run mean of a random variable: \(\sum xp(x)\) or \(\int xf(x)\,dx\). DRVs
Function
A relation in which each input has exactly one output. Functions

G–O

General solution
All solutions of a trig equation, written using an integer parameter \(n\). Circular functions
Hybrid function
A function defined by different rules on different parts of its domain. Functions
Independent events
\(P(A \cap B) = P(A)P(B)\): one occurring doesn't change the probability of the other. Probability
Inflection point
A point where the concavity changes. Applications of differentiation
Instantaneous rate of change
\(f'(a)\): the gradient of the tangent at \(x = a\). Applications of differentiation
Inverse function
\(f^{-1}\) undoes \(f\); exists only if \(f\) is one-to-one. Its graph is the reflection in \(y = x\). Composite & inverse
Margin of error
Half the width of a confidence interval: \(z\sqrt{\hat p(1 - \hat p)/n}\). Confidence intervals
Maximal (implied) domain
The largest set of real numbers for which a rule is defined. Functions
Median (CRV)
The value \(m\) with \(\int_{-\infty}^m f(x)\,dx = \frac12\). CRVs
Modulus function
\(|x|\): the distance of \(x\) from 0. Functions
Mutually exclusive
Events that can't occur together: \(P(A \cap B) = 0\). Probability
Newton's method
An iterative root-finding method: \(x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}\). Newton's method
Normal distribution
The symmetric bell-shaped distribution \(\text{N}(\mu, \sigma^2)\). Normal
Odd function
\(f(-x) = -f(x)\): rotational symmetry about the origin. Functional equations
One-to-one
Each output comes from exactly one input (passes the horizontal line test). Functions

P–Z

Parameter (statistics)
A number describing a population, such as \(p\). Sampling
Percentile
The value below which a given percentage of the distribution lies. Normal
Probability density function (pdf)
A function \(f \ge 0\) with total area 1; probabilities are areas under it. CRVs
Pseudocode
A structured, language-neutral description of an algorithm. Algorithms
Range
The set of output values a function actually produces. Functions
Sample proportion
\(\hat p = \frac{x}{n}\): the proportion of successes in a sample; a random variable. Sampling
Signed area
The value of a definite integral: area above the axis minus area below. Integration
Standard deviation
\(\sqrt{\operatorname{Var}(X)}\): the typical distance of values from the mean. DRVs
Stationary point
A point where \(f'(x) = 0\): a local max, local min or stationary point of inflection. Applications of differentiation
Statistic
A number calculated from a sample, such as \(\hat p\). Sampling
Strictly increasing
\(a < b \Rightarrow f(a) < f(b)\). VCAA includes the endpoints of such intervals. Applications of differentiation
Tangent
The line touching a curve at a point with the same gradient as the curve there. Applications of differentiation
Trapezium rule
Estimating an integral with trapeziums: \(\frac{h}{2}[\text{ends} + 2(\text{middles})]\). Numerical integration
Variance
\(E[(X - \mu)^2] = E(X^2) - \mu^2\). DRVs
\(z\)-score
\(\frac{x - \mu}{\sigma}\): the number of standard deviations from the mean. Normal
