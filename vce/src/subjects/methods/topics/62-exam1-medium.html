Questions (40 marks)

Answer all questions in the spaces provided. No calculators. In questions where more than one mark is available, appropriate working must be shown.

Let \(y = \dfrac{2x + 1}{x - 3}\). Find \(\dfrac{dy}{dx}\) in simplest form.

  • Quotient rule: \(\frac{2(x - 3) - (2x + 1)}{(x - 3)^2}\)
  • \(-\frac{7}{(x - 3)^2}\)

\(\dfrac{dy}{dx} = \dfrac{2(x - 3) - 1(2x + 1)}{(x - 3)^2} = -\dfrac{7}{(x - 3)^2}\)

Let \(f(x) = e^{-x}\sin(2x)\). Evaluate \(f'(0)\).

  • \(f'(x) = -e^{-x}\sin 2x + 2e^{-x}\cos 2x\)
  • \(f'(0) = 2\)

\(f'(0) = -1 \times 0 + 2 \times 1 \times 1 = 2\)

Evaluate \(\displaystyle\int_1^e \left(\frac{2}{x} + 1\right) dx\).

  • \(\left[2\ln x + x\right]_1^e\)
  • \(e + 1\)

\((2 + e) - (0 + 1) = e + 1\)

Given that \(\dfrac{d}{dx}(x\ln x) = \ln x + 1\), find \(\displaystyle\int \ln x\, dx\).

  • \(\int(\ln x + 1)\,dx = x\ln x\), so \(\int \ln x\,dx = x\ln x - \int 1\,dx\)
  • \(x\ln x - x + c\)

Integrate both sides: \(x\ln x = \int \ln x\,dx + x\), so \(\int \ln x\,dx = x\ln x - x + c\).

Integration by recognition appears every year. Integrate the given derivative, then rearrange.

Solve \(2\log_3(x) - \log_3(x + 6) = 1\) for \(x\).

  • Log laws: \(\log_3\frac{x^2}{x + 6} = 1\)
  • \(x^2 = 3x + 18\), so \((x - 6)(x + 3) = 0\)
  • \(x = 6\) only (\(x = -3\) rejected)

\(\frac{x^2}{x + 6} = 3\), so \(x^2 - 3x - 18 = 0\) and \(x = 6\) or \(-3\). The log requires \(x > 0\), so \(x = 6\).

Solve \(2\cos(2x) + 1 = 0\) for \(x \in [0, \pi]\).

  • \(\cos 2x = -\frac12\), with \(2x \in [0, 2\pi]\)
  • \(2x = \frac{2\pi}{3}, \frac{4\pi}{3}\)
  • \(x = \frac{\pi}{3}, \frac{2\pi}{3}\)

\(2x = \frac{2\pi}{3}\) or \(\frac{4\pi}{3}\) (quadrants 2 and 3), so \(x = \frac{\pi}{3}\) or \(\frac{2\pi}{3}\).

Adjust the domain for \(2x\) first. Students who solved for \(x\) directly usually lost one solution.

Let \(f: \mathbb{R} \to \mathbb{R}\), \(f(x) = 2e^{x - 1} + 3\).

State the range of \(f\).

  • \((3, \infty)\)

\((3, \infty)\)

Find the rule and domain of \(f^{-1}\).

  • \(f^{-1}(x) = 1 + \ln\left(\frac{x - 3}{2}\right)\)
  • Domain \((3, \infty)\)

\(x = 2e^{y - 1} + 3\), so \(y = 1 + \ln\frac{x - 3}{2}\), with domain \((3, \infty)\).

Let \(h(x) = \ln(x - 5)\). Find the maximal domain of \(h(f(x))\).

  • Need \(f(x) > 5\): \(2e^{x - 1} > 2\)
  • \(x > 1\), i.e. \((1, \infty)\)

\(h(f(x))\) requires \(f(x) > 5\), so \(e^{x - 1} > 1\) and \(x > 1\). The domain is \((1, \infty)\).

Let \(y = xe^{-x}\).

Find the coordinates of the stationary point, and show that it is a local maximum.

  • \(\frac{dy}{dx} = e^{-x}(1 - x)\)
  • Stationary point \(\left(1, \frac1e\right)\)
  • Gradient changes from positive (\(x < 1\)) to negative (\(x > 1\)), since \(e^{-x} > 0\): a local maximum

'\(y' = e^{-x} - xe^{-x} = e^{-x}(1 - x) = 0\) at \(x = 1\), where \(y = \frac1e\). Since \(e^{-x} > 0\), the sign of \(y'\) is the sign of \(1 - x\): positive then negative, so it is a maximum.

Find the equation of the normal to the curve at the origin.

  • Tangent gradient at \(x = 0\) is 1, so the normal gradient is \(-1\)
  • \(y = -x\)

\(y = -x\)

A bag contains 3 red balls and 2 blue balls. Two balls are drawn at random without replacement. Let X be the number of red balls drawn.

Complete the probability distribution of \(X\).

  • \(\Pr(X = 0) = \frac{1}{10}\), \(\Pr(X = 2) = \frac{3}{10}\)
  • \(\Pr(X = 1) = \frac{6}{10}\)

\(\Pr(0) = \frac25 \cdot \frac14 = \frac1{10}\); \(\Pr(2) = \frac35 \cdot \frac24 = \frac3{10}\); \(\Pr(1) = 1 - \frac4{10} = \frac6{10}\).

Treating the draws as independent (with replacement) gave \(\frac9{25}\) for two reds. That is the key error in without-replacement problems.

Find \(\text{E}(X)\).

  • \(\frac{6}{5}\)

\(0 + \frac{6}{10} + \frac{6}{10} = \frac65\)

Given that at least one red ball is drawn, find the probability that both are red.

  • \(\frac{\Pr(X = 2)}{\Pr(X \ge 1)}\)
  • \(\frac{3/10}{9/10} = \frac13\)

\(\frac{3/10}{9/10} = \frac13\)

A continuous random variable \(X\) has probability density function \(f(x) = k(4 - x^2)\) for \(0 \le x \le 2\), and 0 elsewhere.

Find \(k\).

  • \(k\int_0^2 (4 - x^2)\,dx = \frac{16k}{3} = 1\)
  • \(k = \frac{3}{16}\)

\(k\left[4x - \frac{x^3}{3}\right]_0^2 = \frac{16k}{3} = 1\), so \(k = \frac{3}{16}\).

Find \(\Pr(X < 1)\).

  • \(\frac{3}{16}\left[4x - \frac{x^3}{3}\right]_0^1\)
  • \(\frac{11}{16}\)

\(\frac{3}{16} \times \frac{11}{3} = \frac{11}{16}\)

Is the median of \(X\) less than 1? Justify your answer.

  • Yes: \(\Pr(X < 1) = \frac{11}{16} > \frac12\)

Yes. More than half the probability lies below 1, so the median is less than 1.

In a large population, 20% of people are left-handed. Random samples of 100 people are taken, and \(\hat P\) is the sample proportion of left-handers.

Find the mean and standard deviation of \(\hat P\).

  • \(\text{E}(\hat P) = 0.2\)
  • \(\text{sd}(\hat P) = \sqrt{\frac{0.2 \times 0.8}{100}} = 0.04\)

Mean 0.2; standard deviation \(\sqrt{0.0016} = 0.04\).

Using a normal approximation, estimate \(\Pr(\hat P > 0.28)\).

  • 0.28 is 2 standard deviations above the mean, so \(\approx 0.025\)

\(\frac{0.28 - 0.2}{0.04} = 2\), so \(\Pr \approx \frac{1 - 0.95}{2} = 0.025\).

Find the area of the region enclosed by the graphs of \(y = x^2\) and \(y = 2x\).

  • Intersections at \(x = 0\) and \(x = 2\)
  • \(\int_0^2 (2x - x^2)\,dx\) (line above the parabola)
  • \(\frac43\)

\(\int_0^2 (2x - x^2)\,dx = 4 - \frac83 = \frac43\)

Assessor’s report

General comments

This paper matched a typical VCAA Exam 1. Each question had one step that separated the students who understood the idea from those running a memorised routine: the domain of a composite, rejecting a log solution, adjusting the domain for \(2x\), recognising without replacement.

Question-type patterns

  • Integration by recognition (2b). Integrate the given derivative result, then rearrange. It is examined almost every year.
  • Composite domains (5c). For \(h(f(x))\), the range of \(f\) must fit inside the domain of \(h\). Write the inequality \(f(x) > 5\) and solve it.
  • Justifying the nature of a stationary point (6a). The factor \(e^{-x} > 0\) is what makes the sign argument work. Say so.
  • Conditional probability (7c). The condition goes in the denominator. Write the fraction with probability notation first.
  • Sample proportions (9). Tech-free questions use the 68–95–99.7 rule. Know it.

Common errors

  • Sign errors in the quotient rule. Write \(\frac{vu' - uv'}{v^2}\) before substituting.
  • Keeping \(x = -3\) in the log equation.
  • Using the tangent gradient for the normal.
  • Forgetting \(k\) when calculating a probability from the pdf.

Advice

32/40 or more is a strong result at this level. The top students finished with 10 minutes to spare and used it to check domains and signs.
