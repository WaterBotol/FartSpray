Questions (40 marks)

Answer all questions in the spaces provided. No calculators. In questions where more than one mark is available, appropriate working must be shown.

Differentiate \(y = \sqrt{1 + e^{2x}}\) with respect to \(x\).

  • Chain rule: \(\frac12(1 + e^{2x})^{-1/2} \times 2e^{2x}\)
  • \(\frac{e^{2x}}{\sqrt{1 + e^{2x}}}\)

\(\dfrac{dy}{dx} = \dfrac{e^{2x}}{\sqrt{1 + e^{2x}}}\)

Let \(g(x) = \dfrac{\sin x}{1 + \cos x}\). Show that \(g'(x) = \dfrac{1}{1 + \cos x}\).

  • Quotient rule: \(\frac{\cos x(1 + \cos x) + \sin^2 x}{(1 + \cos x)^2}\)
  • Uses \(\sin^2 x + \cos^2 x = 1\) to simplify to \(\frac{1 + \cos x}{(1 + \cos x)^2} = \frac{1}{1 + \cos x}\)

\(g'(x) = \dfrac{\cos x + \cos^2 x + \sin^2 x}{(1 + \cos x)^2} = \dfrac{1 + \cos x}{(1 + \cos x)^2} = \dfrac{1}{1 + \cos x}\)

Most students applied the quotient rule correctly but didn’t spot the Pythagorean identity. In a “show that” question, the given answer tells you what to aim for.

Find \(\displaystyle\int \frac{1}{(2x - 1)^2}\,dx\).

  • Writes it as \((2x - 1)^{-2}\) and divides by the inner derivative, 2
  • \(-\frac{1}{2(2x - 1)} + c\)

\(\frac{(2x - 1)^{-1}}{-1 \times 2} + c = -\frac{1}{2(2x - 1)} + c\)

Writing \(\ln(2x - 1)^2\) was a very common error. The log rule only applies to \(\frac{1}{ax + b}\).

Find \(a > 0\) such that \(\int_0^a (2x + 1)\,dx = 6\).

  • \(a^2 + a = 6\), so \(a = 2\)

\(a^2 + a - 6 = 0\), so \(a = 2\) (reject \(-3\)).

Given \(\int_1^3 f(x)\,dx = 4\), evaluate \(\int_1^3 (3 - 2f(x))\,dx + \int_3^1 f(x)\,dx\).

  • \(\int_1^3 (3 - 2f)\,dx = 6 - 8 = -2\)
  • \(\int_3^1 f\,dx = -4\), total \(-6\)

\((6 - 8) + (-4) = -6\)

Solve \(3^{2x} - 3^{x + 1} - 10 = 0\) for \(x\).

  • \((3^x)^2 - 3 \cdot 3^x - 10 = 0\), so \((3^x - 5)(3^x + 2) = 0\)
  • \(x = \log_3 5\) (as \(3^x = -2\) has no solution)

Let \(u = 3^x\): \(u^2 - 3u - 10 = 0\), so \(u = 5\) or \(-2\). Since \(3^x > 0\), \(x = \log_3 5\).

Spotting \(3^{x + 1} = 3 \cdot 3^x\) was the key step.

Solve \(2\ln(x) = \ln(x + 2) + \ln 3\) for \(x\).

  • \(x^2 = 3(x + 2)\), so \(x^2 - 3x - 6 = 0\)
  • \(x = \frac{3 + \sqrt{33}}{2}\) only

\(x = \frac{3 \pm \sqrt{33}}{2}\). The negative root is rejected because \(\ln x\) needs \(x > 0\), so \(x = \frac{3 + \sqrt{33}}{2}\).

Solve \(\sin(2x) = \sqrt3\cos(2x)\) for \(x \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]\).

  • \(\tan(2x) = \sqrt3\), with \(2x \in [-\pi, \pi]\)
  • \(2x = \frac{\pi}{3}\) or \(2x = \frac{\pi}{3} - \pi = -\frac{2\pi}{3}\)
  • \(x = \frac{\pi}{6}, -\frac{\pi}{3}\)

\(\tan 2x = \sqrt3\), so \(2x = \frac{\pi}{3} + k\pi\). For \(2x \in [-\pi, \pi]\): \(2x = -\frac{2\pi}{3}, \frac{\pi}{3}\), so \(x = -\frac{\pi}{3}, \frac{\pi}{6}\).

Find the sum of the solutions in part a.

  • \(-\frac{\pi}{6}\)

\(\frac{\pi}{6} - \frac{\pi}{3} = -\frac{\pi}{6}\)

Let \(f: (-\infty, a] \to \mathbb{R}\), \(f(x) = (x - 1)^2 - 4\).

Find the largest value of \(a\) for which \(f\) has an inverse function.

  • \(a = 1\)

\(f\) is one-to-one to the left of its turning point, so \(a = 1\).

Let \(a = 1\). Find the rule and domain of \(f^{-1}\).

  • \(f^{-1}(x) = 1 - \sqrt{x + 4}\) (negative root, since \(f^{-1}(x) \le 1\))
  • Domain \([-4, \infty)\)

\(x = (y - 1)^2 - 4\), so \(y = 1 \pm \sqrt{x + 4}\). The range of \(f^{-1}\) is \((-\infty, 1]\), so take the negative root: \(f^{-1}(x) = 1 - \sqrt{x + 4}\), \(x \ge -4\).

Taking the positive root was the most common error. The range of the inverse decides the sign.

Find the coordinates of the point of intersection of the graphs of \(f\) and \(f^{-1}\).

  • Solves \(f(x) = x\) on the line \(y = x\): \(x^2 - 3x - 3 = 0\)
  • \(x = \frac{3 - \sqrt{21}}{2}\) (the other root exceeds 1): point \(\left(\frac{3 - \sqrt{21}}{2}, \frac{3 - \sqrt{21}}{2}\right)\)

\(x = \frac{3 \pm \sqrt{21}}{2}\), and only \(\frac{3 - \sqrt{21}}{2}\) is in the domain. (For a decreasing function, intersections off the line \(y = x\) are possible in general. Here the only other candidate lies outside the domain.)

The tangent to the curve \(y = x^3\) at the point where \(x = a\) passes through the point \((0, -2)\). Find \(a\) and the equation of the tangent.

  • Tangent: \(y = 3a^2(x - a) + a^3 = 3a^2x - 2a^3\)
  • Substitutes \((0, -2)\): \(-2a^3 = -2\), so \(a = 1\)
  • \(y = 3x - 2\)

The tangent at \(x = a\) is \(y = 3a^2x - 2a^3\). Through \((0, -2)\): \(a^3 = 1\), so \(a = 1\) and the tangent is \(y = 3x - 2\).

Many tried to use \((0, -2)\) as the point of tangency. It isn’t on the curve. Write the general tangent first.

Find the coordinates of the other point where this tangent meets the curve.

  • \(x^3 - 3x + 2 = 0\), which has a double root at \(x = 1\): \((x - 1)^2(x + 2) = 0\)
  • \((-2, -8)\)

Since the tangent touches at \(x = 1\), \((x - 1)^2\) is a factor: \((x - 1)^2(x + 2) = 0\). The point is \((-2, -8)\).

A discrete random variable \(X\) has \(\Pr(X = x) = k(x + 1)\) for \(x \in \{0, 1, 2, 3\}\).

Find \(k\).

  • \(k = \frac{1}{10}\)

\(k(1 + 2 + 3 + 4) = 1\), so \(k = \frac1{10}\).

Find \(\text{E}(X)\).

  • 2

\(\frac{0 + 2 + 6 + 12}{10} = 2\)

Find \(\text{Var}(X)\).

  • 1

\(\text{E}(X^2) = \frac{0 + 2 + 12 + 36}{10} = 5\), so \(\text{Var}(X) = 5 - 4 = 1\).

Two independent observations \(X_1\) and \(X_2\) are taken. Find \(\Pr(X_1 > X_2)\).

  • \(\Pr(X_1 = X_2) = \frac{1 + 4 + 9 + 16}{100} = \frac{30}{100}\)
  • By symmetry, \(\Pr(X_1 > X_2) = \frac{1 - 0.3}{2} = 0.35\)

\(\Pr(X_1 = X_2) = 0.3\), and by symmetry the remaining 0.7 is split equally: \(0.35\).

The symmetry argument saves listing ten cases. The top students spotted it.

Let \(f(x) = \frac12\sin(x)\) for \(0 \le x \le \pi\), and \(f(x) = 0\) elsewhere.

Show that \(f\) is a probability density function.

  • \(f(x) \ge 0\) on \([0, \pi]\), and \(\int_0^\pi \frac12\sin x\,dx = \frac12[-\cos x]_0^\pi = 1\)

\(\sin x \ge 0\) on \([0, \pi]\), and \(\frac12[-\cos x]_0^\pi = \frac12(1 + 1) = 1\).

Both conditions (non-negative, and total area 1) are needed for the mark.

Find \(\Pr\left(X \le \frac{\pi}{3}\right)\).

  • \(\frac12\left[-\cos x\right]_0^{\pi/3}\)
  • \(\frac14\)

\(\frac12\left(1 - \frac12\right) = \frac14\)

Find \(a\) such that \(\Pr(X > a) = \frac14\).

  • \(\frac12(1 + \cos a) = \frac14\), so \(\cos a = -\frac12\)
  • \(a = \frac{2\pi}{3}\)

\(\frac12[-\cos x]_a^\pi = \frac12(1 + \cos a) = \frac14\), so \(\cos a = -\frac12\) and \(a = \frac{2\pi}{3}\). This matches the symmetry of the pdf about \(\frac{\pi}{2}\).

An approximate 95% confidence interval for a population proportion \(p\), calculated from a random sample, is \((0.35, 0.45)\).

State the sample proportion \(\hat p\).

  • 0.4

0.4, the midpoint of the interval.

Taking \(z \approx 2\), find the sample size.

  • \(2\sqrt{\frac{0.4 \times 0.6}{n}} = 0.05\)
  • \(n = 384\)

\(\sqrt{\frac{0.24}{n}} = 0.025\), so \(\frac{0.24}{n} = 0.000625\) and \(n = 384\).

Assessor’s report

General comments

This paper was pitched above a typical Exam 1. The techniques were all standard, but most questions needed an idea on top: a Pythagorean identity to finish a “show that”, a disguised quadratic in \(3^x\), a general tangent through an external point, a symmetry argument in probability. A median of about 24/40 is expected. 30+ is excellent.

What separated the top scripts

  • Working in general before substituting. In Question 6a, the students who wrote the tangent at a general point \(x = a\) solved it in three lines. Those who guessed points ran out of time.
  • Domain discipline. The sign of the root in \(f^{-1}\) (5b), rejecting negative log arguments (3b) and the adjusted interval for \(2x\) (4a) were all decided by domains.
  • Using structure. The double root at the point of tangency (6b), symmetry in 7d and the symmetric pdf in 8c each turned long calculations into short ones.

Common errors

  • \(\int (2x - 1)^{-2}\,dx\) written as a logarithm.
  • Reversing the limits of an integral without changing its sign (2c).
  • \(3^{x + 1}\) treated as \(3^x + 1\).
  • Giving only the solution in the first quadrant for \(\tan 2x = \sqrt3\).
  • Showing only one of the two pdf conditions in 8a.

Advice

If you scored under 20, return to the medium paper and aim for 34/40. If you scored 28+, you are ready for the hardest Exam 1 questions VCAA sets. Keep your speed up with 20-minute mixed drills.
