Queueing-time pdf \(f(t) = kt(16 - t^2)\) on [0, 4]: find k, E(T), and a conditional probability

State average for the whole question: 1.9 / 6 (32%).

Show that \(k = \frac{1}{64}\)

  • \(k\int_0^4 (16t - t^3)\,dt = 64k = 1\)

\(k\left[8t^2 - \frac{t^4}{4}\right]_0^4 = 64k = 1\)

State average 0.4 / 1 (40%); 43% scored full marks.

Mark distribution: 0: 57% · 1: 43%

E(T)

  • \(\frac{1}{64}\int_0^4 (16t^2 - t^4)\,dt\)
  • \(= \frac{32}{15}\)

\(\frac{1}{64}\left(\frac{1024}{3} - \frac{1024}{5}\right) = \frac{32}{15}\)

State average 0.8 / 2 (40%); 26% scored full marks.

Mark distribution: 0: 50% · 1: 24% · 2: 26%

\(\Pr(T > 2 \mid T > 1)\)

  • \(\Pr(T > 2) = \frac{9}{16}\)
  • \(\Pr(T > 1) = \frac{225}{256}\)
  • Ratio \(= \frac{16}{25}\)

\(\frac{9/16}{225/256} = \frac{16}{25}\)

State average 0.7 / 3 (23%); 11% scored full marks.

Mark distribution: 0: 63% · 1: 13% · 2: 13% · 3: 11%

2024 VCAA Exam 1 · Question 6 Open in the exam PDF (p. 1) ↗

Solve \(2\log_3(x-4) + \log_3(x) = 2\)

State average for the whole question: 1.5 / 4 (38%).

Solve for x

  • Combines: \(\log_3\left(x(x-4)^2\right) = 2\)
  • \(x^3 - 8x^2 + 16x - 9 = 0\)
  • Factorises: \((x-1)(x^2 - 7x + 9) = 0\)
  • Only \(x = \frac{7 + \sqrt{13}}{2}\) satisfies \(x > 4\)

\(x = \frac{7 + \sqrt{13}}{2}\). Reject \(x = 1\) and \(\frac{7 - \sqrt{13}}{2}\) because the log needs x > 4.

State average 1.5 / 4 (38%); 9% scored full marks.

Mark distribution: 0: 18% · 1: 52% · 2: 8% · 3: 13% · 4: 9%

2024 VCAA Exam 1 · Question 7 Open in the exam PDF (p. 8) ↗

\(f(x) = x\sin(x)\): trapezium approximation, the range of \(f^{\prime}\) on an interval, a stationary point, sketching \(f^{\prime}\)

State average for the whole question: 3.8 / 9 (42%).

Trapezium rule, step \(\frac{\pi}{3}\), on \([0, \pi]\)

  • Values: \(f(0) = 0,\ f\left(\frac{\pi}{3}\right) = \frac{\sqrt3\pi}{6},\ f\left(\frac{2\pi}{3}\right) = \frac{\sqrt3\pi}{3},\ f(\pi) = 0\)
  • Correct trapezium formula applied
  • \(\frac{\sqrt3\pi^2}{6}\)

\(\frac{\pi}{6}\left[0 + 2\left(\frac{\sqrt3\pi}{6} + \frac{\sqrt3\pi}{3}\right) + 0\right] = \frac{\sqrt3\pi^2}{6}\)

State average 1.5 / 3 (50%); 30% scored full marks.

Mark distribution: 0: 28% · 1: 31% · 2: 11% · 3: 30%

Find \(f^{\prime}(x)\)

  • \(\sin(x) + x\cos(x)\)

\(f^{\prime}(x) = \sin(x) + x\cos(x)\)

State average 0.9 / 1 (90%); 84% scored full marks.

Mark distribution: 0: 16% · 1: 84%

Range of \(f^{\prime}\) over \(\left[\frac{\pi}{2}, \frac{2\pi}{3}\right]\)

  • \(\left[\frac{\sqrt3}{2} - \frac{\pi}{3},\ 1\right]\)

\(f^{\prime}\left(\frac{\pi}{2}\right) = 1\) and \(f^{\prime}\left(\frac{2\pi}{3}\right) = \frac{\sqrt3}{2} - \frac{\pi}{3}\) (decreasing between them).

State average 0.2 / 1 (20%); 20% scored full marks.

Mark distribution: 0: 80% · 1: 20%

Hence verify a stationary point in that interval

  • \(f^{\prime}\) is continuous and changes sign (1 > 0 and \(\frac{\sqrt3}{2} - \frac{\pi}{3} < 0\)), so \(f^{\prime}(x) = 0\) somewhere in the interval

The range contains 0 and f′ is continuous, so it must hit zero. Only 12% got this.

State average 0.1 / 1 (10%); 12% scored full marks.

Mark distribution: 0: 88% · 1: 12%

Sketch \(y = f^{\prime}(x)\) on \([-\pi, \pi]\) with endpoints

  • Endpoints \((-\pi, \pi)\) and \((\pi, -\pi)\)
  • Odd-function shape through the origin with the given min (−1.1, −1.4) and max (1.1, 1.4)
  • x-intercepts where f has turning points (≈ ±2.03)

An odd curve from \((-\pi, \pi)\) down through ≈ −2 to the minimum, up through O to the maximum, then down through ≈ 2 to \((\pi, -\pi)\).

State average 1.1 / 3 (37%); 15% scored full marks.

Mark distribution: 0: 45% · 1: 16% · 2: 24% · 3: 15%

2024 VCAA Exam 1 · Question 8 Open in the exam PDF (p. 10) ↗

Cube-root function \(g(x) = \sqrt[3]{x-k} + m\): y-intercept, gradient there, through the origin, a second point with equal gradient

State average for the whole question: 2.4 / 7 (34%).

Coordinates of the y-intercept P

  • \(\left(0,\ m - \sqrt[3]{k}\right)\)

\(P = \left(0, m - \sqrt[3]{k}\right)\) (the cube root of −k is \(-\sqrt[3]{k}\)).

State average 0.6 / 1 (60%); 61% scored full marks.

Mark distribution: 0: 39% · 1: 61%

Gradient of g at P in terms of k

  • \(g^{\prime}(x) = \frac13(x-k)^{-2/3}\)
  • \(g^{\prime}(0) = \frac{1}{3k^{2/3}}\)

\(\frac{1}{3\sqrt[3]{k^2}}\). Keep it positive: \((-k)^{2/3} = k^{2/3}\).

State average 0.8 / 2 (40%); 32% scored full marks.

Mark distribution: 0: 55% · 1: 13% · 2: 32%

k in terms of m if the graph passes through the origin

  • \(k = m^3\)

\(m - \sqrt[3]{k} = 0 \Rightarrow k = m^3\)

State average 0.5 / 1 (50%); 47% scored full marks.

Mark distribution: 0: 53% · 1: 47%

Coordinates of Q (≠ P) with the same gradient, graph through the origin

  • \((x-k)^{2/3} = k^{2/3} \Rightarrow x - k = \pm k\)
  • \(x = 2k\) (x = 0 is P)
  • \(Q = (2m^3, 2m)\)

By the symmetry of the cube root about its inflection point \((k, m)\): \(Q = (2m^3, 2m)\). The state averaged 0.5/3.

State average 0.5 / 3 (17%); 9% scored full marks.

Mark distribution: 0: 74% · 1: 15% · 2: 2% · 3: 9%

2025 VCAA Exam 1 · Question 8 Open in the exam PDF (p. 10) ↗

Continuous pdf: find k with Pr(X > k) = 9/16; integral of a transformed pdf

State average for the whole question: 2.2 / 5 (44%).

Find \(k\) such that \(\Pr(X > k) = \frac{9}{16}\)

  • Sets up \(\int_k^{4/3}\tfrac38(4 - 3x)\,dx = \frac{9}{16}\) (or the complement)
  • Gets \(9k^2 - 24k + 7 = 0\)
  • \(k = \frac13\) (rejects \(\frac73\), outside the domain)

\(k = \frac13\). The other root \(\frac73\) is outside \(\left[0, \frac43\right]\).

State average 1.4 / 3 (47%); 24% scored full marks.

Mark distribution: 0: 30% · 1: 23% · 2: 23% · 3: 24%

\(\int_0^{4/3} h(x)\,dx\) for \(h(x) = mf(x) + n\)

  • Uses \(\int_0^{4/3} f(x)\,dx = 1\)
  • \(m + \frac{4n}{3}\)

\(m \cdot 1 + n \cdot \frac43 = m + \frac{4n}{3}\)

State average 0.8 / 2 (40%); 27% scored full marks.

Mark distribution: 0: 51% · 1: 22% · 2: 27%

2025 VCAA Exam 1 · Question 9 Open in the exam PDF (p. 12) ↗

Solving \(\frac{w^2}{(x-1)^2} = (x-w)^2\); the minimum of \((x-1)(x-w)\); when there are exactly three solutions

State average for the whole question: 1.9 / 7 (27%).

Four solutions when w = −3

  • Reduces to \((x+3)(x-1) = \pm 3\)
  • \(+3\): \(x^2 + 2x - 6 = 0 \Rightarrow x = -1 \pm \sqrt7\)
  • \(-3\): \(x^2 + 2x = 0 \Rightarrow x = 0, -2\)

\(x = -2, 0, -1 \pm \sqrt7\)

State average 1 / 3 (33%); 19% scored full marks.

Mark distribution: 0: 47% · 1: 25% · 2: 10% · 3: 19%

Minimum point of \(y = (x-1)(x-w)\), \(w > 0\)

  • \(x = \frac{w+1}{2}\)
  • \(y = -\frac{(w-1)^2}{4}\)

\(\left(\frac{w+1}{2}, -\frac{(w-1)^2}{4}\right)\)

State average 0.8 / 2 (40%); 22% scored full marks.

Mark distribution: 0: 43% · 1: 34% · 2: 22%

Positive \(w\) giving exactly three solutions

  • \((x-1)(x-w) = w\) always gives 2 solutions, so \((x-1)(x-w) = -w\) must touch the minimum: \(-w = -\frac{(w-1)^2}{4}\)
  • \(w^2 - 6w + 1 = 0 \Rightarrow w = 3 \pm 2\sqrt2\)

\(w = 3 \pm 2\sqrt2\). The state averaged 0.1/2.

State average 0.1 / 2 (5%); 4% scored full marks.

Mark distribution: 0: 94% · 1: 3% · 2: 4%
