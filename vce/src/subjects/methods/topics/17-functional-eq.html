What's a functional equation?

A functional equation describes a property a function has for all inputs, such as \(f(x + y) = f(x)f(y)\). VCAA usually asks “which function satisfies…” in multiple choice, or “show that \(f\) satisfies…” in short answer.

Property (for all \(x, y\) in the domain)Satisfied byWhy
\(f(x + y) = f(x) + f(y)\)\(f(x) = kx\)\(k(x + y) = kx + ky\)
\(f(x + y) = f(x)\,f(y)\)\(f(x) = e^{kx}\) (or \(a^x\))index law \(a^{x + y} = a^x a^y\)
\(f(xy) = f(x) + f(y)\)\(f(x) = k\log_e x\)log law \(\log(xy) = \log x + \log y\)
\(f(xy) = f(x)\,f(y)\)\(f(x) = x^n\)\((xy)^n = x^n y^n\)
\(f(2x) = 2f(x)\)\(f(x) = kx\)\(k(2x) = 2(kx)\)
\(f(-x) = f(x)\)even: \(x^2, |x|, \cos x, e^x + e^{-x}\)symmetric in the \(y\)-axis
\(f(-x) = -f(x)\)odd: \(x^3, \sin x, \tan x, \frac1x\)point symmetry about the origin
\(f(f(x)) = x\)self-inverse: \(\frac1x\), \(c - x\), some hyperbolasgraph symmetric in \(y = x\)

In multiple choice, don't do algebra first. Pick easy values (\(x = 1,\ y = 2\), or \(x = y = 0\)) and test each option. Usually three options fail on the first test. Then prove the survivor in your head.

Which one of \(f(x) = 3x\), \(f(x) = x^3\), \(f(x) = e^{3x}\), \(f(x) = \log_e(3x)\) satisfies \(f(x + y) = f(x)f(y)\) for all real \(x, y\)?

Test \(x = y = 0\): we need \(f(0) = f(0)^2\), so \(f(0) = 0\) or 1. \(\log_e(0)\) is undefined, so D is out.

Test \(x = y = 1\): \(3x\) gives \(6\) vs \(9\) ✗; \(x^3\) gives \(8\) vs \(1\) ✗; \(e^{3x}\) gives \(e^6\) vs \(e^3 \cdot e^3 = e^6\) ✓.

\(f(x) = e^{3x}\): \(e^{3(x + y)} = e^{3x}e^{3y}\) for all \(x, y\).

\(f(x) = e^{kx}\) satisfies \(f(x + 1) = 2f(x)\) for all \(x\). Find \(k\).

\(e^{k(x + 1)} = e^{kx}e^k\), so the condition is \(e^{kx}e^k = 2e^{kx}\).

Divide by \(e^{kx}\) (never 0): \(e^k = 2\), so \(k = \log_e 2\).

Let \(f(x) = x^2 - 2x\). Show that \(f(1 + h) = f(1 - h)\) for all \(h\), and interpret this.

\(f(1 + h) = (1 + h)^2 - 2(1 + h) = 1 + 2h + h^2 - 2 - 2h = h^2 - 1\).

\(f(1 - h) = (1 - h)^2 - 2(1 - h) = 1 - 2h + h^2 - 2 + 2h = h^2 - 1\). Equal. ✓

Points the same distance either side of \(x = 1\) have the same height: the graph is symmetric about the line \(x = 1\) (its axis of symmetry).

Find all linear functions \(f(x) = ax + b\) such that \(f(f(x)) = 4x + 3\) for all \(x\).

\(f(f(x)) = a(ax + b) + b = a^2x + ab + b\).

Equate coefficients: \(a^2 = 4\) and \(b(a + 1) = 3\).

\(a = 2 \Rightarrow b = 1\); \(a = -2 \Rightarrow -b = 3 \Rightarrow b = -3\). \(f(x) = 2x + 1\) or \(f(x) = -2x - 3\). Most students miss the second one.

  • “For all \(x\)” means one counter-example kills an option, but one success doesn't prove it.
  • Watch the domain. \(f(x) = \log_e x\) satisfies \(f(xy) = f(x) + f(y)\) only for \(x, y > 0\).
  • Neither odd nor even is the usual case. \(e^x\), \(x^2 + x\) and \(\log_e x\) are neither.
  • A function can be odd and still have \(f(0)\) undefined (e.g. \(\frac1x\)). If an odd function is defined at 0, then \(f(0) = 0\).

Practice

Which function is odd?

  1. \(f(x) = x^2 + x\)
  2. \(f(x) = \cos x\)
  3. \(f(x) = e^{-x}\)
  4. \(f(x) = x^3 - x\)

\(f(-x) = -x^3 + x = -(x^3 - x) = -f(x)\).

Which function satisfies \(f(xy) = f(x) + f(y)\) for all \(x, y > 0\)?

  1. \(f(x) = e^x\)
  2. \(f(x) = 5\log_e x\)
  3. \(f(x) = x + 1\)
  4. \(f(x) = \sqrt{x}\)

\(5\log_e(xy) = 5\log_e x + 5\log_e y\).

If \(f(x) = 2^x\), then \(f(x + 2)\) equals

  1. \(4f(x)\)
  2. \(f(x) + 4\)
  3. \(2f(x)\)
  4. \(f(x) + 2\)

\(2^{x + 2} = 2^x \cdot 2^2 = 4f(x)\).

Which function satisfies \(f(2x) = 2f(x)\) for all real \(x\)?

  1. \(f(x) = x^2\)
  2. \(f(x) = x + 2\)
  3. \(f(x) = -3x\)
  4. \(f(x) = \log_e|x|\)

\(-3(2x) = 2(-3x)\) ✓. \(x^2\) gives \(4x^2\); \(x + 2\) gives \(2x + 2 \ne 2x + 4\); \(\log_e|2x| = \log_e 2 + \log_e|x|\) (and it's undefined at 0 anyway).

Which function is even?

  1. \(f(x) = \sin x\)
  2. \(f(x) = e^x + e^{-x}\)
  3. \(f(x) = e^x - e^{-x}\)
  4. \(f(x) = (x + 1)^2\)

\(f(-x) = e^{-x} + e^x = f(x)\). C is odd; D is symmetric about \(x = -1\), not the \(y\)-axis.

\(f(x) = kx^2\) satisfies \(f(x + 1) - f(x) = 6x + 3\) for all \(x\). The value of \(k\) is

  1. 6
  2. 1
  3. 2
  4. 3

\(k(x + 1)^2 - kx^2 = k(2x + 1) = 6x + 3 \Rightarrow k = 3\).

Which function satisfies \(f(f(x)) = x\) for all \(x\) in its domain?

  1. \(f(x) = 5 - x\)
  2. \(f(x) = x^3\)
  3. \(f(x) = 2x\)
  4. \(f(x) = e^x\)

\(f(f(x)) = 5 - (5 - x) = x\). Its graph is a line perpendicular to \(y = x\), so reflecting it in \(y = x\) gives the same line.

Show that \(f(x) = x\sin x\) is even.

\(f(-x) = (-x)\sin(-x) = (-x)(-\sin x) = x\sin x = f(x)\). An odd function times an odd function is even.

Let \(g(x) = \log_e x\). Show that \(g(x^2) - 2g(x) = 0\) for \(x > 0\). Why does the result fail for \(x < 0\)?

\(g(x^2) = \log_e x^2 = 2\log_e x = 2g(x)\) for \(x > 0\).

For \(x < 0\), \(g(x^2)\) is defined but \(g(x)\) is not, so the equation has no meaning there.

A function satisfies \(f(x + y) = f(x) + f(y)\) for all real \(x\) and \(y\). Show that (a) \(f(0) = 0\), and (b) \(f\) is odd.

(a) Let \(x = y = 0\): \(f(0) = 2f(0) \Rightarrow f(0) = 0\). [1]

(b) Let \(y = -x\): \(f(0) = f(x) + f(-x)\), so \(0 = f(x) + f(-x)\) and \(f(-x) = -f(x)\). [2]

Let \(h(x) = \dfrac{e^x - e^{-x}}{2}\). (a) Show that \(h\) is odd. (b) Show that \(h(2x) = 2h(x)\sqrt{1 + h(x)^2}\) when \(x = 0\) and \(x = \log_e 2\).

(a) \(h(-x) = \frac{e^{-x} - e^x}{2} = -h(x)\). [1]

(b) \(x = 0\): both sides are 0. \(x = \log_e 2\): \(h(\log_e 2) = \frac{2 - \frac12}{2} = \frac34\), and \(h(2\log_e 2) = h(\log_e 4) = \frac{4 - \frac14}{2} = \frac{15}{8}\). [1]

RHS \(= 2 \cdot \frac34 \sqrt{1 + \frac{9}{16}} = \frac32 \cdot \frac54 = \frac{15}{8}\). ✓ [1]

Summary

  • Sums inside → products outside: exponential. Products inside → sums outside: log. Products → products: power.
  • Even: \(f(-x) = f(x)\). Odd: \(f(-x) = -f(x)\).
  • Multiple choice: test numbers first; \(x = y = 0\) and \(x = y = 1\) are your friends.
