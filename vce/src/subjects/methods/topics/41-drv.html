Distributions

A discrete random variable \(X\) takes separate values \(x_1, x_2, \ldots\) with probabilities \(p_1, p_2, \ldots\). Every probability satisfies \(0 \le p_i \le 1\), and together they sum to 1.

Find \(E(X)\), \(\operatorname{Var}(X)\), \(\operatorname{sd}(X)\), and the mean and standard deviation of \(Y = 3X - 2\).

\(E(X) = 0 + 0.3 + 0.8 + 0.6 = 1.7\).

\(E(X^2) = 0 + 0.3 + 1.6 + 1.8 = 3.7\), so \(\operatorname{Var}(X) = 3.7 - 1.7^2 = 0.81\) and \(\operatorname{sd}(X) = 0.9\).

\(E(Y) = 3(1.7) - 2 = 3.1\); \(\operatorname{Var}(Y) = 9 \times 0.81 = 7.29\), so \(\operatorname{sd}(Y) = 2.7\).

\(E(X) = 1.7,\ \operatorname{Var}(X) = 0.81,\ \operatorname{sd}(X) = 0.9\); \(E(Y) = 3.1,\ \operatorname{sd}(Y) = 2.7\). The \(-2\) shifts the mean but doesn't change the spread.

\(P(X = x) = kx\) for \(x = 1, 2, 3, 4\). Find \(k\), \(E(X)\) and \(P(X > E(X))\).

\(k(1 + 2 + 3 + 4) = 1 \Rightarrow k = 0.1\). Probabilities: 0.1, 0.2, 0.3, 0.4.

\(E(X) = 0.1 + 0.4 + 0.9 + 1.6 = 3\).

\(k = 0.1\), \(E(X) = 3\), \(P(X > 3) = P(X = 4) = 0.4\). “Greater than” is strict: don't include \(X = 3\).

Two balls are drawn without replacement from a bag with 3 red and 2 blue balls. \(X\) is the number of red balls drawn. Find the distribution of \(X\) and \(E(X)\).

\(P(X = 0) = \frac25 \cdot \frac14 = \frac{1}{10}\); \(P(X = 2) = \frac35 \cdot \frac24 = \frac{3}{10}\).

\(P(X = 1) = 1 - \frac{1}{10} - \frac{3}{10} = \frac{6}{10}\) (or \(2 \times \frac35 \times \frac24\)).

\(E(X) = 0.6 + 0.6 = 1.2\) (which is \(2 \times \frac35\), as intuition says).

It costs $5 to play a game: roll a fair die; a 6 pays $20, a 5 pays $5, anything else pays nothing. Find the expected profit per game.

Let \(W\) = amount won. \(E(W) = 20 \cdot \frac16 + 5 \cdot \frac16 + 0 \cdot \frac46 = \frac{25}{6} \approx 4.17\).

Profit \(= W - 5\), so \(E(\text{profit}) = \frac{25}{6} - 5 = -\frac56\).

About −$0.83 per game, so the game is unfair to the player. A fair game has expected profit 0.

  • \(\operatorname{Var}(aX + b) = a^2\operatorname{Var}(X)\). A negative \(a\) still makes the variance bigger: \(\operatorname{Var}(-2X) = 4\operatorname{Var}(X)\).
  • \(E(X^2) \ne [E(X)]^2\). Their difference is the variance.
  • sd scales by \(|a|\), variance by \(a^2\).
  • The expected value needn't be a possible value (1.7 children…).

  2. 0.2
  3. 0.3
  4. 0.7

\(0.2 + a + 0.5 = 1 \Rightarrow a = 0.3\).

If \(\operatorname{Var}(X) = 4\), then \(\operatorname{Var}(5 - 3X)\) equals

  1. \(-7\)
  2. 36
  3. \(-12\)
  4. 41

\((-3)^2 \times 4 = 36\). The 5 has no effect on spread.

If \(E(X) = 2\) and \(E(X^2) = 7\), then \(\operatorname{sd}(X)\) is

  1. \(\sqrt3\)
  2. 3
  3. \(\sqrt5\)
  4. 5

\(\operatorname{Var} = 7 - 4 = 3\), so \(\operatorname{sd} = \sqrt3\).

\(X\) is the number of heads when two fair coins are tossed. \(E(X)\) and \(\operatorname{Var}(X)\) are

  1. 1 and 1
  2. 1 and 0.25
  3. 0.5 and 0.5
  4. 1 and 0.5

Distribution 0.25, 0.5, 0.25. \(E(X) = 1\); \(E(X^2) = 0.5 + 1 = 1.5\); \(\operatorname{Var} = 0.5\).

\(X\) takes values 0 and \(a\) with \(P(X = a) = 0.25\). If \(\operatorname{Var}(X) = 3\), then \(a\) (with \(a > 0\)) is

  1. 2
  2. 3
  3. 4
  4. \(\sqrt{12}\)

\(E(X) = 0.25a\), \(E(X^2) = 0.25a^2\). \(\operatorname{Var} = 0.25a^2 - 0.0625a^2 = 0.1875a^2 = 3 \Rightarrow a^2 = 16 \Rightarrow a = 4\).

A player wins $10 with probability 0.3 and loses $4 otherwise. How many games must they expect to play to be ahead by $20 on average?

  1. 2
  2. 100
  3. They never will
  4. 10

\(E(\text{gain}) = 10(0.3) - 4(0.7) = 3 - 2.8 = 0.2\) per game. \(\frac{20}{0.2} = 100\) games.

\(P(X = 0) = 0.4,\ P(X = 1) = 0.35,\ P(X = 2) = 0.25\). Find \(E(X)\) and \(\operatorname{Var}(X)\).

\(E(X) = 0.35 + 0.5 = 0.85\). \(E(X^2) = 0.35 + 1 = 1.35\). \(\operatorname{Var}(X) = 1.35 - 0.7225 = 0.6275\).

A café sells 0, 1, 2 or 3 cakes per hour with probabilities 0.1, 0.4, 0.3, 0.2. Each cake makes $6 profit, and the café pays a fixed $4 per hour to display them. (a) Find the expected number of cakes sold per hour. (b) Find the mean and standard deviation of the hourly profit \(P = 6X - 4\).

(a) \(E(X) = 0.4 + 0.6 + 0.6 = 1.6\). [1]

(b) \(E(P) = 6(1.6) - 4 = \$5.60\). [1] \(E(X^2) = 0.4 + 1.2 + 1.8 = 3.4\), \(\operatorname{Var}(X) = 3.4 - 2.56 = 0.84\). [1] \(\operatorname{sd}(P) = 6\sqrt{0.84} \approx \$5.50\). [1]

A student computes \(\operatorname{Var}(X) = E(X^2) - E(X)^2\) and gets \(-0.4\). What does this tell you?

They've made an arithmetic error. Variance is an average of squared deviations, so it can never be negative. (Common causes: probabilities that don't sum to 1, or using \(E(X)\) instead of \(E(X^2)\).)

Summary

  • Probabilities sum to 1; \(E(X) = \sum xp\); \(\operatorname{Var} = E(X^2) - \mu^2\).
  • \(E(aX + b) = aE(X) + b\); \(\operatorname{Var}(aX + b) = a^2\operatorname{Var}(X)\).
  • Fair game: expected profit 0.
