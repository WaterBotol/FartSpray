Command words in Methods

PhraseWhat it means
Find / determineGet the answer; show enough working for method marks if it's worth more than 1 mark.
Show thatThe answer is given. Every step from the starting point to that answer must be written, with no jumps. A CAS “it's true” is worth 0.
HenceYou must use the previous part. Another method gets no marks.
Hence, or otherwiseThe previous part is the quickest route, but any valid method is fine.
Exact valueNo decimals: surds, \(\pi\), \(e\), logs and fractions stay as they are.
Correct to \(n\) decimal placesRound only the final answer, and use exactly \(n\) places (including trailing zeros: 0.50, not 0.5).
SketchCorrect shape plus labelled key features (intercepts, turning points, asymptotes, endpoints with open/closed circles).
State / write downNo working needed.

Setting out for method marks

  • Write the setup before the answer. For example: “Solve \(f'(x) = 0\) for \(x\)” or “\(P(X > 180)\) where \(X \sim \text{N}(170, 8^2)\)”. In Exam 2, a correct setup often earns the first mark even if the final answer is wrong.
  • Use correct notation. \(f'(x)\), not \(f'\) or \(\frac{d}{dx}\) floating without an expression. Write \(\int_0^2(x^2 + 1)\,dx\) with brackets and \(dx\). Use \(=\) only between things that really are equal.
  • Define your variables in modelling and probability questions: “Let \(X\) be the number of faulty items, \(X \sim \text{Bi}(20, 0.1)\).”
  • Don't round intermediate values. Carry full precision; round the final answer only.
  • State domains for inverses, composites and derivatives, and for optimisation variables.

Exam 1 (tech-free) habits

  • Know your exact values (\(\sin\frac{\pi}{3}\) and so on), log and index laws, and the derivative and antiderivative table without thinking.
  • Factorise derivatives before solving \(= 0\).
  • Check solutions against domains, especially for log equations and trig equations over restricted intervals.
  • Simplify at the end (\(\log_e 9 - \log_e 3 = \log_e 3\)), but don't waste time making it “prettier” than needed.

Exam 2 (CAS) habits

  • Define functions on CAS (e.g. define f(x) = …) so you can reuse them for derivatives, integrals and solve commands.
  • Check the mode: radians, and approximate vs exact as needed.
  • Restrict solves to the domain (e.g. solve(f(x)=0, x) | 0≤x≤2π) to avoid extra solutions.
  • Sketch what CAS gives you and sanity-check it (range of a probability, sign of an area, sensible units).
  • Watch cube roots of negatives and \(x^{2/3}\): some CAS settings return complex values or only the \(x \ge 0\) branch.

Multiple choice strategy

  • Eliminate options by testing numbers (for functional equations, transformations, domains).
  • For “which is true” questions, check every option: two can look right until you simplify.
  • Never leave one blank: there's no penalty for wrong answers.
  • Watch strict vs non-strict inequalities and open vs closed endpoints. These are the most common MCQ traps.

Your bound reference

  • Organise it by topic with tabs. Include worked examples of the question types you find hard, not a copy of the textbook.
  • Include the CAS syntax you use for: inverse normal, binomial cdf, solving with a domain, defining piecewise functions, and Newton's method.
  • Add a page of your personal mistakes. Reading it during reading time is worth more than any formula.

Errors examiners' reports mention every year

  • Giving a decimal when an exact answer was asked for (or vice versa).
  • “Show that” answers that skip steps or work backwards from the answer.
  • Confusing “dilation from the \(x\)-axis” with “from the \(y\)-axis”.
  • Missing open/closed circles, asymptote labels or endpoint coordinates on sketches.
  • Not rejecting invalid solutions (negative lengths, logs of negatives, values outside the domain).
  • Using \(\text{N}(\mu, \sigma^2)\) with the variance as the standard deviation.
  • Off-by-one errors in binomial inequalities (\(P(X > 3)\) vs \(P(X \ge 3)\)).
  • Calculating signed area when “area” was asked for.
  • Writing the answer to a different question: \(x\) instead of the maximum value, or the probability instead of the expected number.

Reading time plan (15 minutes)

  1. Skim the whole paper. Mark each question as easy, medium or hard.
  2. For Exam 2 Section B, read the stem of each question and note which topic(s) it tests.
  3. Plan your order: bank the easy marks first, but don't skip the start of a long question, since part (a) is usually quick.
  4. Mentally set up the first few MCQs, so you start writing fast.
