Section A – Multiple-choice questions

Answer all questions. Choose the response that is correct for the question. A correct answer scores 1; an incorrect answer scores 0. No marks are deducted for incorrect answers.

  2. a dilation by a factor of 2 from the \(y\)-axis, then a translation 4 units right

The system \(kx + y = 2\), \(4x + ky = 4\) has no solution when \(k\) equals

  1. 2
  2. −2
  3. ±2
  4. 0

Let \(f: [1, \infty) \to \mathbb{R}\), \(f(x) = (x - 1)^2 + 2\). The inverse function is

  1. \(f^{-1}(x) = 1 + \sqrt{x - 2}\), \(x \ge 2\)
  2. \(f^{-1}(x) = 1 - \sqrt{x - 2}\), \(x \ge 2\)
  3. \(f^{-1}(x) = 1 + \sqrt{x - 2}\), \(x \ge 1\)

Find \(C'(t)\).

  • Product rule applied
  • \(C'(t) = 20e^{-0.5t}(1 - 0.5t)\) (or equivalent, e.g. \(10(2 - t)e^{-0.5t}\))

\(C'(t) = 20e^{-0.5t} - 10te^{-0.5t} = 10(2 - t)e^{-0.5t}\)

Assessor’s report

General comments

This paper was at the standard of a typical VCAA Exam 2. Each extended question climbed from routine to demanding, finishing with a part that needed a model or an idea rather than a button press: the second dose, the lagging Ferris-wheel car, the tangent meeting the cubic again.

Question-type patterns

  • Maximum rate of change. “Decreasing most rapidly” (1d) means the minimum of \(C'\), found where \(C'' = 0\).
  • Superposition. A second dose adds a shifted copy of the model (1f). Define the new function before using CAS.
  • Trig inequalities. Solve the equation, then use the graph to pick the interval (2d). Give durations as a fraction of the period.
  • Parameters. Question 4 kept \(a\) general. CAS handles it, but you must write answers in terms of \(a\) and check the conditions (\(a > 0\)).
  • Conditional normal probability (3b). The same fraction method as for discrete variables.

Common errors

  • Solving \(C = 10\) and giving only one time.
  • Stating the lagging car meets the first at \(t = 5\) without solving.
  • Integrating the pdf from \(-\infty\) in 3f. It is zero for \(w < 0\).
  • Reversing the order of transformations in MC 3.

Advice

60/80 or more is a strong result. If you lost marks on setup lines rather than on the mathematics, practise writing “Solve … for t” or “\(\int_0^6 \dots\)” before every CAS answer.
