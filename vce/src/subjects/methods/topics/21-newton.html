Newton's method

Start with a guess \(x_0\) near a root. Draw the tangent at \((x_0, f(x_0))\); where it hits the \(x\)-axis is the next, usually better, estimate. Repeat.

Newton's method
\[ x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)} \]

Derivation: the tangent \(y - f(x_n) = f'(x_n)(x - x_n)\) crosses \(y = 0\) at \(x = x_n - \frac{f(x_n)}{f'(x_n)}\).

Use Newton's method with \(x_0 = 2\) to find \(x_2\) for \(f(x) = x^3 - 2x - 5\). Give \(x_2\) correct to four decimal places.

\(f'(x) = 3x^2 - 2\). \(f(2) = 8 - 4 - 5 = -1\), \(f'(2) = 10\). So \(x_1 = 2 - \frac{-1}{10} = 2.1\).

\(f(2.1) = 9.261 - 4.2 - 5 = 0.061\), \(f'(2.1) = 13.23 - 2 = 11.23\). So \(x_2 = 2.1 - \frac{0.061}{11.23} = 2.09457\ldots\)

\(x_2 \approx 2.0946\). (The true root is 2.094551…: two steps already give four correct decimal places.)

Use Newton's method on \(f(x) = x^2 - 2\) with \(x_0 = 1\) to find \(x_1\), \(x_2\) and \(x_3\).

\(x_{n+1} = x_n - \frac{x_n^2 - 2}{2x_n}\). \(x_1 = 1 - \frac{-1}{2} = 1.5\).

\(x_2 = 1.5 - \frac{0.25}{3} = 1.41\overline{6}\); \(x_3 = 1.41667 - \frac{0.0069444}{2.83333} \approx 1.414216\).

\(x_1 = 1.5,\ x_2 \approx 1.416667,\ x_3 \approx 1.414216\). The number of correct digits roughly doubles each step.

CyclingEstimates bounce between values forever\(x^3 - 2x + 2\) with \(x_0 = 0\): 0, 1, 0, 1, …

Show that Newton's method applied to \(f(x) = x^3 - 2x + 2\) with \(x_0 = 0\) does not converge.

\(f'(x) = 3x^2 - 2\). \(x_1 = 0 - \frac{2}{-2} = 1\).

\(x_2 = 1 - \frac{1 - 2 + 2}{3 - 2} = 1 - 1 = 0\).

The estimates alternate 0, 1, 0, 1, … and never approach the actual root (which is near \(x \approx -1.77\)).

The bisection method

If \(f\) is continuous and \(f(a)\) and \(f(b)\) have opposite signs, there's a root in \([a, b]\). Evaluate the midpoint \(m = \frac{a + b}{2}\) and keep the half where the sign still changes. It's slow but reliable: after \(n\) steps the interval width is \(\frac{b - a}{2^n}\).

Pseudocode, VCAA style

VCAA exams show algorithms in a simple pseudocode and ask you to trace them (fill in a table of values), find an output, or complete a missing line. The conventions: ← means “assign”, define creates a function, and loops are for … end for and while … end while.

define f(x)
    return x^3 - 2x - 5
define df(x)
    return 3x^2 - 2

x ← 2
for i from 1 to 3
    x ← x - f(x) / df(x)
end for
print x

This prints \(x_3 \approx 2.094551\) (three iterations of Newton's method from \(x_0 = 2\)).

Trace this algorithm and state the output.

a ← 1
b ← 2
while b - a > 0.2
    m ← (a + b) / 2
    if m^2 - 2 < 0 then
        a ← m
    else
        b ← m
    end if
end while
print a, b

It's bisection on \(x^2 - 2\). Start \(a = 1, b = 2\) (width 1).

\(m = 1.5\): \(2.25 - 2 > 0\), so \(b = 1.5\). \(m = 1.25\): \(1.5625 - 2 < 0\), so \(a = 1.25\). Width now \(0.25 > 0.2\): continue.

\(m = 1.375\): \(1.890625 - 2 < 0\), so \(a = 1.375\). Width \(0.125 \le 0.2\): stop.

Output: 1.375, 1.5 (an interval containing \(\sqrt2 \approx 1.414\)).

  • Count loop iterations carefully. for i from 1 to 3 runs 3 times; a while loop checks its condition before each pass.
  • Use the updated value. Once x ← … runs, every later line uses the new \(x\).
  • Newton needs \(f'\), bisection needs a sign change. Don't mix up the input requirements.
  • Keep full precision in the calculator between iterations; round only the final answer.

Practice

Newton's method is used to solve \(\cos x = x\) with \(x_0 = 1\). The value of \(x_1\), correct to three decimal places, is

  1. 0.739
  2. 0.750
  3. 0.540
  4. 1.000

\(f(x) = \cos x - x\), \(f'(x) = -\sin x - 1\). \(x_1 = 1 - \frac{\cos 1 - 1}{-\sin 1 - 1} = 1 - \frac{-0.4597}{-1.8415} \approx 0.750\). (0.739 is the actual root, reached after two more steps.)

Newton's method applied to \(f(x) = x^2 - 4x + 5\) will fail from any starting value because

  1. \(f'(x) = 0\) at \(x = 2\)
  2. the method always cycles for quadratics
  3. \(f\) is not continuous
  4. \(f\) has no real roots

\(\Delta = 16 - 20 < 0\), so there's nothing to converge to. (A is true, but it only causes trouble if you start at \(x = 2\).)

For \(f(x) = x^2 - 2\), Newton's method fails immediately when \(x_0 =\)

  1. 0
  2. 1
  3. \(\sqrt2\)
  4. 2

\(f'(0) = 0\): the tangent is horizontal and never crosses the \(x\)-axis.

Starting from \([0, 4]\), how many bisection steps are needed before the interval containing the root has width at most 0.1?

  1. 4
  2. 5
  3. 6
  4. 40

Width after \(n\) steps is \(\frac{4}{2^n}\). \(\frac{4}{2^5} = 0.125 > 0.1\) and \(\frac{4}{2^6} = 0.0625 \le 0.1\). So 6.

For \(f(x) = x^3 - 3x + 1\), the starting value most likely to send Newton's method far from all the roots is

  1. \(x_0 = 1.01\)
  2. \(x_0 = 0.4\)
  3. \(x_0 = 1.6\)
  4. \(x_0 = -2\)

\(f'(x) = 3x^2 - 3 = 0\) at \(x = \pm1\). At \(x_0 = 1.01\) the tangent is almost flat, so \(x_1 = 1.01 - \frac{f(1.01)}{f'(1.01)} \approx 1.01 - \frac{-0.9997}{0.0603} \approx 17.6\).

\(x_{n+1} = x_n - \dfrac{e^{x_n} - 3x_n}{e^{x_n} - 3}\).

Let \(f(x) = x^3 - 6x^2 + 9x + 1\). (a) Find the stationary points of \(f\). (b) Explain why \(x_0 = 3\) and \(x_0 = 1\) are poor choices for Newton's method. (c) Using \(x_0 = -0.5\), find \(x_1\) and \(x_2\) correct to three decimal places.

(a) \(f'(x) = 3x^2 - 12x + 9 = 3(x - 1)(x - 3)\): stationary points \((1, 5)\) and \((3, 1)\). [1]

(b) \(f'(1) = f'(3) = 0\), so the formula divides by zero (horizontal tangents). [1]

(c) \(f(-0.5) = -0.125 - 1.5 - 4.5 + 1 = -5.125\), \(f'(-0.5) = 0.75 + 6 + 9 = 15.75\): \(x_1 = -0.5 + \frac{5.125}{15.75} \approx -0.175\). [1]

\(f(-0.1746) \approx -0.7597\), \(f'(-0.1746) \approx 11.187\): \(x_2 \approx -0.1746 + 0.0679 \approx -0.107\). [1] (The root is \(x \approx -0.1038\).)

Summary

  • \(x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}\): fast, but it can fail near stationary points, cycle, or find a different root.
  • Bisection: halve the interval while keeping a sign change. Slow but always works.
  • Pseudocode: trace line by line, update variables immediately, and count loop passes carefully.
