Laws you must know cold

Index laws
\[ a^m a^n = a^{m+n} \quad \frac{a^m}{a^n} = a^{m-n} \quad (a^m)^n = a^{mn} \quad a^0 = 1 \quad a^{-n} = \frac{1}{a^n} \]
Log laws (\(a, x, y > 0,\ a \ne 1\))
\[ \log_a(xy) = \log_a x + \log_a y \quad \log_a\!\frac{x}{y} = \log_a x - \log_a y \quad \log_a x^n = n\log_a x \]
Definition and inverse pair
\[ y = a^x \iff x = \log_a y \qquad e^{\log_e x} = x\ (x > 0) \qquad \log_e(e^x) = x \]

\(\log_e\) is written \(\ln\) on most calculators. Change of base: \(\log_a x = \dfrac{\log_e x}{\log_e a}\).

Graphs

For \(y = 2\log_e(3 - x)\), state the maximal domain and the asymptote, and find the axis intercepts.

Need \(3 - x > 0\): domain \((-\infty, 3)\), asymptote \(x = 3\). It's reflected in the \(y\)-axis, so the graph rises to the left.

\(x\)-intercept: \(\log_e(3 - x) = 0 \Rightarrow 3 - x = 1 \Rightarrow x = 2\).

Domain \((-\infty, 3)\), asymptote \(x = 3\), intercepts \((2, 0)\) and \((0, 2\log_e 3)\).

Solving equations

Solve \(e^{2x} - 5e^x + 6 = 0\).

Let \(u = e^x\), so \(e^{2x} = u^2\): \(u^2 - 5u + 6 = 0 \Rightarrow (u - 2)(u - 3) = 0\).

\(e^x = 2\) or \(e^x = 3\).

\(x = \log_e 2\) or \(x = \log_e 3\). (If a factor gave \(e^x = -1\), you'd reject it: \(e^x > 0\).)

Solve \(\log_2 x + \log_2(x - 2) = 3\).

Combine: \(\log_2\big(x(x - 2)\big) = 3 \Rightarrow x^2 - 2x = 2^3 = 8\).

\(x^2 - 2x - 8 = 0 \Rightarrow (x - 4)(x + 2) = 0\), so \(x = 4\) or \(x = -2\).

\(x = 4\) only. \(x = -2\) makes \(\log_2 x\) undefined in the original equation. Checking the original equation is worth a mark.

Solve \(2^x = 3^{x - 1}\), giving an exact answer.

Take \(\log_e\) of both sides: \(x\log_e 2 = (x - 1)\log_e 3\).

\(x(\log_e 3 - \log_e 2) = \log_e 3\).

\(x = \dfrac{\log_e 3}{\log_e\!\left(\frac32\right)} \approx 2.71\).

Find the inverse of \(f(x) = 2e^{x - 1} + 3\), stating its domain.

Swap: \(x = 2e^{y - 1} + 3 \Rightarrow e^{y - 1} = \dfrac{x - 3}{2}\).

\(y - 1 = \log_e\!\left(\dfrac{x - 3}{2}\right)\).

\(f^{-1}(x) = \log_e\!\left(\dfrac{x - 3}{2}\right) + 1\), with domain = range of \(f\) = \((3, \infty)\).

Growth and decay models

Exponential model
\[ A = A_0 e^{kt} \]

\(k > 0\): growth; \(k < 0\): decay. Half-life (decay) \(= \dfrac{\log_e 2}{|k|}\).

A cup of coffee cools according to \(T = 20 + 70e^{-kt}\) (°C, \(t\) in minutes). After 10 minutes it is 55 °C. (a) Find \(k\) exactly. (b) How long until it reaches 30 °C?

(a) \(55 = 20 + 70e^{-10k} \Rightarrow e^{-10k} = \frac12 \Rightarrow k = \dfrac{\log_e 2}{10}\).

(b) \(30 = 20 + 70e^{-kt} \Rightarrow e^{-kt} = \frac17 \Rightarrow t = \dfrac{\log_e 7}{k} = \dfrac{10\log_e 7}{\log_e 2}\).

(a) \(k = \frac{\log_e 2}{10} \approx 0.0693\); (b) \(t \approx 28.1\) minutes. The long-run temperature is 20 °C (room temperature), the horizontal asymptote.

  • \(e^x = 0\) has no solution. In \(e^{2x} = 3e^x\), divide by \(e^x\) (it's never 0): \(x = \log_e 3\) only.
  • \(\log_e(x^2) = 2\) has two solutions (\(x = \pm e\)), but \(2\log_e x = 2\) has one (\(x = e\)). Log laws quietly change domains.
  • \(\log_e(a + b) \ne \log_e a + \log_e b\). The product law is for products only.
  • \(\log_e(2x) = \log_e 2 + \log_e x\): a horizontal dilation of a log graph is the same as a vertical translation.

Practice

\(\log_2 8 + \log_3\!\left(\frac19\right)\) equals

  1. \(1\)
  2. \(5\)
  3. \(-1\)
  4. \(\log_6\!\frac89\)

\(\log_2 8 = 3\) and \(\log_3 3^{-2} = -2\). Total 1.

The solution set of \(e^{2x} = 3e^x\) is

  1. \(\{0, \log_e 3\}\)
  2. \(\{\log_e 3, -\log_e 3\}\)
  3. \(\{\log_e 3\}\)
  4. \(\{3\}\)

\(e^x(e^x - 3) = 0\). \(e^x = 0\) is impossible, so \(e^x = 3\). Option A comes from treating \(e^x = 0\) like \(x = 0\).

The range of \(y = 3 - 2e^{-x}\) is

  1. \((3, \infty)\)
  2. \((-\infty, 1)\)
  3. \(\mathbb{R}\)
  4. \((-\infty, 3)\)

\(2e^{-x} > 0\), so \(y < 3\), and \(y\) can be arbitrarily negative (as \(x \to -\infty\)).

The inverse of \(y = e^{2x} + 1\) is

  1. \(y = \log_e(2x - 1)\)
  2. \(y = \frac12\log_e(x - 1)\)
  3. \(y = \frac12\log_e x - 1\)
  4. \(y = 2\log_e(x - 1)\)

\(x = e^{2y} + 1 \Rightarrow 2y = \log_e(x - 1)\).

The solutions of \(\log_e(x^2) = 2\) are

  1. \(x = \pm e\)
  2. \(x = e\) only
  3. \(x = \pm\sqrt{e}\)
  4. \(x = e^2\)

\(x^2 = e^2 \Rightarrow x = \pm e\), and both make \(x^2 > 0\). Writing \(2\log_e x = 2\) first loses the negative solution.

A substance decays according to \(A = 100e^{-0.2t}\). Its half-life, correct to two decimal places, is

  1. 2.50
  2. 0.35
  3. 3.47
  4. 5.00

\(e^{-0.2t} = \frac12 \Rightarrow t = \frac{\log_e 2}{0.2} \approx 3.47\). The half-life doesn't depend on the starting amount.

The graph of \(y = \log_e(2x)\) can be obtained from \(y = \log_e x\) by

  1. a translation of 2 units up
  2. a translation of \(\log_e 2\) units up
  3. a dilation by factor 2 from the \(x\)-axis
  4. a translation of 2 units left

\(\log_e(2x) = \log_e 2 + \log_e x\). (It is also a dilation by factor \(\frac12\) from the \(y\)-axis, but that's not an option.)

Solve \(2 \times 4^x - 5 \times 2^x + 2 = 0\).

Let \(u = 2^x\), so \(4^x = u^2\): \(2u^2 - 5u + 2 = 0 \Rightarrow (2u - 1)(u - 2) = 0\).

\(2^x = \frac12 \Rightarrow x = -1\); \(2^x = 2 \Rightarrow x = 1\).

Solve \(\log_3(x + 1) - \log_3(x - 1) = 1\).

\(\log_3\frac{x + 1}{x - 1} = 1 \Rightarrow \frac{x + 1}{x - 1} = 3 \Rightarrow x + 1 = 3x - 3 \Rightarrow x = 2\). Check: both logs are defined at \(x = 2\). ✓

Solve \(\log_e x + \log_e(x + 1) = \log_e 6\).

\(x(x + 1) = 6 \Rightarrow x^2 + x - 6 = 0 \Rightarrow x = 2\) or \(x = -3\).

Reject \(x = -3\) (\(\log_e(-3)\) is undefined). \(x = 2\).

Sketch \(y = \log_e(x - 1) + 2\), showing the asymptote and the exact \(x\)-intercept. Does it have a \(y\)-intercept?

Asymptote \(x = 1\); domain \((1, \infty)\). [1]

\(x\)-intercept: \(\log_e(x - 1) = -2 \Rightarrow x = 1 + e^{-2}\). [1]

No \(y\)-intercept: \(x = 0\) is not in the domain. [1]

A bacteria population is modelled by \(P = 500e^{kt}\), \(t\) in hours. The population triples in 4 hours. (a) Find \(k\). (b) Find when the population reaches 10 000, to the nearest tenth of an hour.

(a) \(1500 = 500e^{4k} \Rightarrow e^{4k} = 3 \Rightarrow k = \frac{\log_e 3}{4} \approx 0.2747\). [2]

(b) \(e^{kt} = 20 \Rightarrow t = \frac{4\log_e 20}{\log_e 3} \approx 10.9\) hours. [2]

Summary

  • \(e^x\) and \(\log_e x\) are inverses: domain and range swap; asymptotes \(y = 0\) and \(x = 0\) swap.
  • Hidden quadratics: let \(u = e^x\) (or \(2^x\)), solve, reject impossible values.
  • After combining logs, check every solution in the original equation.
  • Models: find \(k\) from one data point, then use it.
