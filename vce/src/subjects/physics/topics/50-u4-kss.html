Use the “If [IV change] then [DV change] because [physics reason]” structure. It must be testable and name both variables. “The magnet will affect the coil” gets no marks.

The measurement vocabulary

These definitions (from the VCAA study design) are examined almost every year, often as a two-mark “explain the difference between…” question. Learn them precisely.

True value
The value that would be obtained in an ideal measurement with no errors. It can never be known exactly.
Accuracy
How close a measurement (or the mean of measurements) is to the true value.
Precision
How closely a set of repeated measurements agree with each other (small spread). Says nothing about closeness to the true value.
Repeatability
How closely results agree when the same experimenter repeats the measurement with the same method, equipment and conditions over a short time.
Reproducibility
How closely results agree when the measurement is repeated under changed conditions: a different experimenter, method, equipment, location or time.
Resolution
The smallest change in a quantity that an instrument can detect (e.g. 1 mm for a ruler, 0.01 s for a digital timer).
Validity
Whether the experiment actually investigates what it claims to (a fair test, measuring the right quantity, controlling other variables). Valid conclusions follow from valid data.
Random error
Unpredictable variations that scatter readings above and below the true value (e.g. reaction time, small fluctuations). Reduced by repeating and averaging. Affects precision.
Systematic error
An error that shifts every reading in the same direction by a consistent amount (e.g. a zero error, an uncalibrated instrument, always reading a scale from above). Not reduced by repeating. Affects accuracy.
Personal error (mistake)
Errors such as misreading a scale or recording a number wrongly. These are not “experimental error”: the data should be excluded and the measurement repeated.
Outlier
A reading that lies well away from the pattern of the others. Investigate it; exclude it only with a justified reason, and say so.
Uncertainty
The range within which the true value is expected to lie, written as value ± uncertainty. Every measurement has one.
  • Never write “human error” as a source of error. Name the specific error (e.g. “reaction time in starting and stopping the stopwatch introduces random error”).
  • Repeating measurements and averaging reduces the effect of random errors. It does nothing for systematic errors: ten readings from a mis-zeroed scale are all wrong by the same amount.
  • Using an instrument with better resolution improves precision, not accuracy, if the instrument is badly calibrated.

Uncertainty

  • Reading an analogue scale: uncertainty is usually ± half the smallest division (a ruler marked in mm: ±0.5 mm).
  • Digital instrument: ± 1 in the last digit displayed (a timer reading 2.47 s: ±0.01 s).
  • Repeated measurements: use the mean as the best estimate and ± half the range as the uncertainty.

Five measurements of the time for a trolley to travel down a ramp are 2.31 s, 2.28 s, 2.35 s, 2.30 s and 2.26 s. State the best estimate with its absolute uncertainty, and the percentage uncertainty.

The mean is the best estimate of a repeated measurement. Half the range estimates the uncertainty from random error; percentage uncertainty compares that uncertainty with the size of the value.

Mean: \((2.31 + 2.28 + 2.35 + 2.30 + 2.26)/5 = 11.50/5 = 2.30\ \text{s}\).

Uncertainty = half the range: \((2.35 - 2.26)/2 = 0.045 \approx 0.05\ \text{s}\).

Percentage uncertainty: \(0.05/2.30 \times 100 = 2\%\).

\(t = 2.30 \pm 0.05\ \text{s}\) (±2%). Uncertainties are usually quoted to one significant figure, and the value is rounded to the same decimal place.

When quantities are added or subtracted, add their absolute uncertainties. When multiplied or divided, add their percentage uncertainties. When a quantity is squared, double its percentage uncertainty. E.g. \(v = d/t\) with \(d\) ±1% and \(t\) ±2% gives \(v\) ±3%, and \(E_k = \tfrac12 mv^2\) then has about ±6% from \(v\) alone. VCAA may ask you to identify which measurement contributes most uncertainty.

Significant figures and units

  • Give answers to the same number of significant figures as the least precise data given (usually 2 or 3 in VCE). Don't round in intermediate steps.
  • Use SI units and scientific notation: \(4.2\times10^{-7}\ \text{m}\), not 0.00000042 m.
  • “Show that” questions: give your answer to one more significant figure than the value shown, so the examiner can see you didn't just copy it.

Safety and ethics

  • Risk assessment before any practical: identify hazards (lasers, high voltages, mains power, projectiles, hot equipment, strong magnets near electronics or pacemakers) and controls.
  • Lasers: never look into the beam or its reflections; use low-power (Class 2) lasers; keep beams below eye level.
  • Ethics: report all data honestly, including results that don't fit; don't invent or selectively delete data; acknowledge sources and collaborators.

Practice

A student measures the acceleration due to gravity five times: 9.51, 9.50, 9.52, 9.51, 9.50 m s⁻². The accepted value is 9.80 m s⁻². The results are best described as:

  1. accurate and precise
  2. precise but not accurate
  3. accurate but not precise
  4. neither accurate nor precise

The readings agree closely (precise) but are all well below the true value (not accurate), suggesting a systematic error.

Which of the following will reduce the effect of random errors?

  1. re-calibrating the instrument
  2. correcting for a zero error
  3. using a different experimenter
  4. repeating the measurement and averaging

Averaging several readings reduces the scatter from random errors. Calibration and zero corrections address systematic errors.

A second class at another school repeats a student's experiment with their own equipment and gets very similar results. This demonstrates the experiment's:

  1. reproducibility
  2. repeatability
  3. resolution
  4. accuracy

Different people, equipment and location: reproducibility. Repeatability is the same person, same equipment, same conditions.

A metre ruler is marked in millimetres. The resolution of the ruler is:

  1. 0.5 mm
  2. 1 cm
  3. 1 mm
  4. 1 m

Resolution is the smallest change the instrument can show: 1 mm. The reading uncertainty is usually taken as ±0.5 mm, which is a different idea.

Every length measured with a steel tape is 2 mm too long because the tape's end hook is bent. This is:

  1. a random error that reduces precision
  2. a systematic error that reduces accuracy
  3. a personal error that should be ignored
  4. a random error that can be removed by averaging

A consistent offset in one direction is systematic. It shifts all results away from the true value (accuracy) without spreading them out.

Explain the difference between accuracy and precision, using an example from a physics experiment.

Accuracy is how close a measurement is to the true value; precision is how close repeated measurements are to each other.

Example: if repeated measurements of \(g\) are 9.51, 9.50 and 9.52 m s⁻², they are precise (close together) but not accurate (true value 9.80 m s⁻²).

Students investigate how the release height of a trolley on a ramp affects its speed at the bottom, measuring the speed with a stopwatch over the final 50 cm. (a) Identify the independent, dependent and one controlled variable. (b) Identify one random and one systematic error, and suggest how to reduce each.

(a) IV: release height. DV: speed at the bottom. Controlled: same trolley (mass), same ramp surface and angle, same timing distance. [1]

(b) Random: reaction time starting and stopping the stopwatch, reduced by using light gates or repeating trials and averaging. [1] Systematic: friction and air resistance always reduce the speed below the ideal value (or a timing distance measured incorrectly), reduced by using a low-friction track or measuring the distance carefully from the correct points. [1] Repeating measurements does not reduce the systematic error. [1]

Summary

  • IV (changed), DV (measured), controlled (kept the same). Hypothesis: if… then… because…
  • Accuracy = close to true value; precision = close to each other.
  • Repeatability = same everything; reproducibility = changed conditions.
  • Random errors scatter (average them); systematic errors shift (calibrate, redesign). No “human error”.
