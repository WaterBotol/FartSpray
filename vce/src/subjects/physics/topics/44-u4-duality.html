Two models, two sets of evidence

Evidence for the wave modelEvidence for the particle (photon) model
Interference (Young's double slit)The photoelectric effect (threshold frequency, instant emission, \(E_k\) depends on \(f\))
Diffraction through narrow gapsLight arriving at a detector as individual, localised “clicks” or dots
Polarisation (transverse waves)Photon momentum (light pressure, Compton scattering)

Neither model on its own explains everything. Light shows wave behaviour when it travels and interferes, and particle behaviour when it is emitted, absorbed or detected.

Photon momentum

Although photons have no mass, they carry momentum. This is what pushes a solar sail and what bounces electrons in Compton scattering.

Momentum of a photon
\[ p = \frac{h}{\lambda} = \frac{E}{c} \]

\(p\) in kg m s⁻¹, \(h = 6.63\times10^{-34}\ \text{J s}\), \(\lambda\) in m. Shorter wavelength → more momentum (and more energy).

Find the momentum of (a) a 500 nm photon and (b) a 0.10 nm X-ray photon.

(a) \(p = h/\lambda = 6.63\times10^{-34}/5.00\times10^{-7} = 1.3\times10^{-27}\ \text{kg m s}^{-1}\).

(b) \(p = 6.63\times10^{-34}/1.0\times10^{-10} = 6.6\times10^{-24}\ \text{kg m s}^{-1}\), 5000 times larger.

(a) \(1.3\times10^{-27}\ \text{kg m s}^{-1}\) (b) \(6.6\times10^{-24}\ \text{kg m s}^{-1}\). Tiny, but a mirror-like sail reflecting sunlight for months builds up real speed.

A photon has no rest mass and always moves at \(c\), so \(p = mv\) doesn't apply. Use \(p = h/\lambda\) (or \(E/c\)). The same formula, read the other way, gives the de Broglie wavelength of matter: \(\lambda = h/p\) (next page).

Single-photon interference

What happens in Young's experiment if the light is so dim that only one photon at a time passes through the apparatus?

  1. Each photon arrives at the screen (or detector) as a single dot at one place. That's particle behaviour.
  2. The position of each dot is unpredictable. But where dots land is not random: they never land where the dark fringes would be.
  3. After many thousands of photons, the dots build up the familiar interference pattern. That's wave behaviour.

A single photon can't “interfere with another photon” here, because there is only one in the apparatus at a time. The wave describes the probability of where each photon will be detected: the photon's wave passes through both slits and interferes with itself, and the intensity of that wave at any point gives the chance of the photon being found there. Bright fringes = high probability; dark fringes = zero.

If you try to find out which slit each photon went through (by placing a detector at the slits), the interference pattern disappears and you get two bands. Measuring particle-like information destroys the wave-like behaviour.

Wave–particle duality

Wave–particle duality: light (and, as we'll see, matter) has both wave-like and particle-like properties. Which properties show up depends on the experiment. Neither the wave model nor the particle model is complete on its own; they are complementary descriptions of the same thing.

Avoid saying light “switches” between being a wave and a particle. Say that light exhibits wave properties (interference, diffraction) in some experiments and particle properties (photoelectric effect, localised detection) in others, and that a complete description requires both models.

The dot point linking single-slit diffraction to Heisenberg's uncertainty principle was removed from the current study design, so it won't be examined. The idea is still a neat link between diffraction and duality: narrowing a slit pins down a photon's sideways position more precisely, but the diffraction pattern spreads out more, so its sideways momentum becomes less certain.

Practice

In a double slit experiment, light is made so dim that only one photon is in the apparatus at a time. After a long exposure, the screen shows:

  1. no pattern, because single photons can't interfere
  2. two bright bands, one behind each slit
  3. an interference pattern built up from individual dots
  4. a uniform glow with no dots

Each photon is detected as a dot (particle-like), but their distribution builds up the interference pattern (wave-like). Each photon's probability wave passes through both slits.

Which photon has the greatest momentum?

  1. a gamma-ray photon
  2. an ultraviolet photon
  3. a visible photon
  4. a radio photon

\(p = h/\lambda\): gamma rays have the shortest wavelength, so the largest momentum.

Which observation is evidence for the particle nature of light?

  1. diffraction through a narrow slit
  2. interference fringes in Young's experiment
  3. polarisation by a filter
  4. a threshold frequency in the photoelectric effect

A threshold frequency means energy arrives in packets of \(hf\): a photon (particle) property. The others are wave properties.

In the single-photon double slit experiment, a detector is added to record which slit each photon passes through. The pattern on the screen becomes:

  1. brighter interference fringes
  2. two bands with no interference fringes
  3. fringes that are twice as far apart
  4. completely dark

Determining which slit the photon used forces particle-like behaviour, and the interference pattern disappears.

A photon has a momentum of \(2.2\times10^{-27}\ \text{kg m s}^{-1}\). Find its wavelength and energy (in eV).

\(\lambda = h/p = 6.63\times10^{-34}/2.2\times10^{-27} = 3.0\times10^{-7}\ \text{m}\) (300 nm, UV).

\(E = pc = 2.2\times10^{-27} \times 3.0\times10^8 = 6.6\times10^{-19}\ \text{J} = 4.1\ \text{eV}\).

Explain how the results of the single-photon double slit experiment support the idea that light has a dual nature.

Each photon is detected at a single, specific point on the screen, like a particle. [1]

Over time, the individual detections form an interference pattern with bright and dark fringes, which can only be explained by wave interference. [1]

Since only one photon is present at a time, each photon's wave must pass through both slits and interfere with itself; the wave determines the probability of where the photon is detected. [1]

So light shows particle properties (localised detection) and wave properties (interference) in the same experiment: neither model alone is sufficient. [1]

Summary

  • Photon momentum: \(p = h/\lambda = E/c\).
  • Single photons arrive as dots, but build an interference pattern: evidence for duality.
  • Light shows wave properties in propagation and interference, particle properties in emission, absorption and detection.
