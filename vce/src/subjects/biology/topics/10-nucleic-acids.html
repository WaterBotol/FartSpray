Nucleotides: the building blocks

Nucleic acids are polymers of nucleotides. Each nucleotide has a phosphate, a five-carbon sugar and a nitrogenous base. Nucleotides join by condensation reactions between the phosphate of one and the sugar of the next, forming a sugar–phosphate backbone.

  • Complementary base pairing: A pairs with T (two hydrogen bonds) and G pairs with C (three hydrogen bonds). In RNA, A pairs with U.
  • Antiparallel: the two DNA strands run in opposite directions (one 5′→3′, the other 3′→5′).
  • The base sequence carries the information; the backbone is the same everywhere.

The genetic code

  • Triplet: each codon (three mRNA bases) codes for one amino acid. \(4^3 = 64\) codons for 20 amino acids.
  • Degenerate (redundant): most amino acids have more than one codon (e.g. GGU, GGC, GGA and GGG all code for glycine).
  • Universal: almost all organisms use the same code. That's why a human gene can be expressed in bacteria.
  • Start codon AUG (methionine) begins translation; stop codons UAA, UAG, UGA code for no amino acid and end it.
  • Non-overlapping, read in a fixed reading frame from the start codon.

Gene structure

A gene is a section of DNA that codes for a functional product (usually a polypeptide, sometimes RNA). A typical eukaryotic gene contains:

RegionFunction
Promoter (upstream)Where RNA polymerase binds to start transcription; not transcribed
ExonsCoding sequences kept in mature mRNA
IntronsNon-coding sequences transcribed but removed (spliced out) before translation
Termination sequenceSignals the end of transcription

Prokaryotic genes usually lack introns; groups of genes may share one promoter and an operator (an operon: see gene regulation).

RNA polymerase reads the template strand (3′→5′) and builds mRNA 5′→3′. The mRNA is complementary to the template strand and has the same sequence as the coding strand, with U instead of T.

The template strand of part of a gene reads 3′ TAC GGA CTT ATC 5′. Give (a) the coding strand, (b) the mRNA, (c) the amino acid sequence (AUG = Met, CCU = Pro, GAA = Glu, UAG = stop).

(a) Complement of the template: 5′ ATG CCT GAA TAG 3′.

(b) mRNA = coding strand with U: 5′ AUG CCU GAA UAG 3′.

(c) Met – Pro – Glu, then stop (UAG codes for no amino acid, so the chain has three amino acids).

  • Codons are on mRNA; anticodons are on tRNA; “triplets” is the word for DNA base triplets.
  • Degenerate ≠ ambiguous. Several codons can code for one amino acid, but each codon codes for only one amino acid.
  • The mRNA matches the coding strand, not the template strand (apart from U/T).
  • Stop codons have no tRNA; release factors end translation.

Practice

Which feature is found in RNA but not DNA?

  1. Phosphate groups
  2. Uracil
  3. Guanine
  4. A sugar–phosphate backbone

RNA uses uracil instead of thymine. The others are in both.

If 20% of the bases in a double-stranded DNA sample are adenine, the percentage of guanine is

  1. 20%
  2. 40%
  3. 30%
  4. 60%

A = T = 20%, so A + T = 40% and G + C = 60%; G = C = 30%.

The genetic code is described as degenerate because

  1. some codons code for more than one amino acid
  2. it degrades over time
  3. it differs between species
  4. most amino acids are coded for by more than one codon

Several codons, one amino acid. A is the reverse and is false.

A coding strand reads 5′ ATG GCA TTC 3′. The corresponding mRNA reads

  1. 5′ AUG GCA UUC 3′
  2. 5′ UAC CGU AAG 3′
  3. 3′ UAC CGU AAG 5′
  4. 5′ TAC CGT AAG 3′

mRNA has the coding strand's sequence with U for T, in the same 5′→3′ direction.

A mature mRNA has 900 nucleotides between its start codon and stop codon (including the start codon, excluding the stop codon). The polypeptide has

  1. 900 amino acids
  2. 301 amino acids
  3. 300 amino acids
  4. 299 amino acids

\(\frac{900}{3} = 300\) codons, each coding for one amino acid (the start codon codes for methionine; the stop codon codes for none).

Which DNA region is transcribed but not present in mature mRNA?

  1. promoter
  2. intron
  3. exon
  4. start codon

Introns are transcribed into pre-mRNA and then spliced out. The promoter isn't transcribed at all.

Give three structural differences between DNA and RNA.

DNA contains deoxyribose, RNA contains ribose; DNA has thymine, RNA has uracil; DNA is double-stranded, RNA is usually single-stranded. (DNA is also much longer and more stable.)

Explain why the universal nature of the genetic code is essential for producing human insulin in bacteria.

Bacteria and humans read the same codons as the same amino acids. [1] So when the human insulin gene (as cDNA) is inserted into a bacterium, the bacterial ribosomes and tRNAs translate its mRNA into the same amino acid sequence. [1] The bacterium therefore produces a polypeptide identical in sequence to human insulin. [1]

A single base substitution changes the codon GAA to GAG. Both code for glutamic acid. (a) Name this type of mutation. (b) Which feature of the genetic code explains why it has no effect? (c) Could it still affect the organism? Explain.

(a) A silent (synonymous) point mutation. [1] (b) Degeneracy: more than one codon codes for the same amino acid. [1] (c) Usually not, since the protein's primary structure is unchanged; rarely, it may affect RNA processing or the rate of translation. [1]

A student writes that tRNA carries codons to the ribosome. Correct this statement.

tRNA carries a specific amino acid and has an anticodon, which pairs complementarily with a codon on the mRNA. Codons are on mRNA.

Summary

  • Nucleotide = phosphate + sugar + base; A–T (A–U in RNA), G–C; antiparallel strands.
  • mRNA carries the code; tRNA brings amino acids (anticodon); rRNA forms ribosomes.
  • The code is triplet, degenerate, universal and non-overlapping; AUG starts, UAA/UAG/UGA stop.
  • Gene: promoter, exons (kept), introns (removed), termination sequence.
